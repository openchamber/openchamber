Зібрати гостьову панель

@openchamber/sdk ставить сторонню панель на рейку OpenChamber. Панель — це HTML в iframe. З OpenChamber вона розмовляє через connectHost().

Це працює у вебі та на десктопі. VS Code і мобільний застосунок позначають каталог як unsupported. Вони iframe не вантажать.

Що віддаєте

  • package.json з блоком openchamber
  • panel/index.html
  • panel/main.js, класичний IIFE. Iframe не вантажить ESM.

oc-dev усе ще компілює panel/main.ts, коли віддає panel/main.js. Упакований OpenChamber і openchamber serve цього не роблять. Віддавайте IIFE.

Build a guest panel

Use @openchamber/sdk to put a third-party panel on the OpenChamber rail. The panel is HTML in an iframe. It talks to OpenChamber through connectHost().

This runs on web and desktop. VS Code and mobile mark the guest catalog unsupported. They do not load the iframe.

What you ship

  • a package.json that has an openchamber block
  • panel/index.html
  • panel/main.js, a classic IIFE. The iframe cannot load ESM.

oc-dev still compiles panel/main.ts when it serves panel/main.js. Packaged OpenChamber and openchamber serve will not. Ship the IIFE.

bun run --filter @openchamber/sdk bundle -- panel/main.ts panel/main.js

Як поставити, поки пишете

  1. Запустіть OpenChamber у вебі або на десктопі.
  2. Відкрийте Settings → Extensions.
  3. Додайте шлях до теки, локальний .zip або https git / zip URL.

На рейці має з'явитися ваша іконка. Клік — і вантажиться ваш HTML. Дві панелі не можуть мати той самий id.

Інсталяція з теки лишає ваш шлях. Zip або git URL копіюється в data dir як guests/{id}. У архіві мають бути package.json, panel/index.html, panel/main.js і задекларовані icon.svg / agent entry. Без node_modules і TypeScript.

Маніфест

Install it while you work

  1. Run OpenChamber on web or desktop.
  2. Open Settings → Extensions.
  3. Add a folder path, a local .zip, or an https git / zip URL.

The rail should show your icon. Click it and your HTML loads. Two panels cannot share the same id.

A folder install keeps your path. A zip or git URL is copied under the OpenChamber data dir as guests/{id}. Ship package.json, panel/index.html, panel/main.js, and any declared icon.svg / agent entry. Skip node_modules and TypeScript sources.

Manifest

{
  "name": "@acme/hello-panel",
  "openchamber": {
    "apiVersion": 1,
    "contributes": {
      "panel": {
        "id": "acme-hello",
        "name": "Hello",
        "icon": "window",
        "entry": "panel/index.html"
      },
      "attach": "dialog",
      "integration": {
        "name": "Acme",
        "description": "Tasks from Acme",
        "oauth": {
          "authorizeUrl": "https://acme.example/oauth/authorize",
          "tokenUrl": "https://acme.example/oauth/token",
          "apiOrigin": "https://api.acme.example"
        },
        "settings": [{ "id": "list-id", "label": "List ID" }]
      }
    }
  }
}

apiVersion — 1. Будь-яке інше значення — відмова.

engines.openchamber — опційно. 1.22.0 або >=1.22.0. Інсталяція відхиляється, якщо ця збірка OpenChamber старіша.

contributes.agent — опційно. Локальний процес на хості для Docker-сокетів тощо. Панель кличе agentRequest. Деталі в GUEST_AGENTS.md.

id — kebab-case. icon — ім'я Remixicon (RiWindowLine → window) або шлях до SVG у пакеті на кшталт icon.svg. URL і абсолютні шляхи не пройдуть parse. entry лишається всередині пакета.

  • true або "panel" додає рядок у меню +, який відкриває рейку
  • "dialog" відкриває вікно хоста навколо того самого iframe
  • пропустіть або поставте false — панель не з'явиться в тих меню

ready.surface — panel або dialog. integration малює картку в Settings → Integrations. Гість токен не бачить.

Перші рядки в панелі

apiVersion is 1. Any other value is a refusal.

engines.openchamber is optional. Use 1.22.0 or >=1.22.0. Install refuses when this OpenChamber build is older.

contributes.agent is optional. It names a host-spawned local process for Docker sockets and similar. The panel calls agentRequest. See GUEST_AGENTS.md.

id is kebab-case. icon is a Remixicon name (RiWindowLine becomes window) or a package SVG path like icon.svg. URLs and absolute paths fail parse. entry stays inside the package.

  • true or "panel" adds a + menu row that opens the rail
  • "dialog" opens a host window around the same iframe
  • omit it or set false and the panel stays off those menus

ready.surface is panel or dialog. integration draws a card at Settings → Integrations. The guest never sees the token.

Host API

The exact connectHost methods, limits, and error codes.

import { connectHost, HostRequestError } from "@openchamber/sdk";

const host = connectHost();

connectHost кидає HOST_UNAVAILABLE, коли немає window або скрипт не в iframe. dispose() відхиляє запити в польоті як HOST_UNAVAILABLE.

Ready і пізніші пуші

connectHost throws HOST_UNAVAILABLE when there is no window, or when the script is not in an iframe. dispose() rejects in-flight calls as HOST_UNAVAILABLE.

id is your identifier, not a GitHub number. kind is issue or pull. worktree: true asks the host to make a worktree first. The guest does not talk to git.

request

try {
  await host.request({ method: "GET", path: "/api/v2/user" });
} catch (error) {
  if (error instanceof HostRequestError && error.code === "DISCONNECTED") {
    await host.oauthStart();
  }
}

path починається з /, лишається на apiOrigin, без схеми. Тиша 20 секунд — HOST_TIMEOUT.path starts with /, stays on apiOrigin, no scheme. Silence for 20 seconds is HOST_TIMEOUT.

Linear і заморозка

host.provider: "linear" бере першостороннє підключення Linear. apiOrigin лише https://api.linear.app. Другого провайдера хоста на apiVersion 1 немає.

Зарезервовано, діри ще немає: issues.search / get, публічний OAuth-брокер.

Linear and the freeze

host.provider: "linear" reuses the first-party Linear connection. apiOrigin is https://api.linear.app only. Do not add a second host provider on apiVersion 1.

Reserved, no host hole yet: issues.search / get, a public OAuth broker.

UI-набір

Імпортуйте @openchamber/sdk/ui, якщо панель має виглядати як трекери хоста. Набір малює DOM. З провайдером він не розмовляє.

Набір можна пропустити і малювати власний DOM. Спершу applyHostReady.

UI kit

Import @openchamber/sdk/ui when you want the panel to look like the host trackers. The kit paints DOM. It does not talk to the provider.

You can skip the kit and draw your own DOM. Call applyHostReady first.

import { applyHostReady, mountIssuePage } from "@openchamber/sdk/ui";

host.onReady((ctx) => {
  applyHostReady(ctx, document.documentElement);
  mountIssuePage(document.querySelector("#root")!, {
    items: tasks,
    filters,
    onSelect: (item) => {
      void host.attach({
        providerId: "acme-hello",
        id: item.id,
        title: item.title,
        url: item.url ?? "",
      });
    },
  });
});
