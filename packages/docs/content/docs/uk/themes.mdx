# Теми

OpenChamber підтримує вбудовані теми та власні JSON-файли тем.

## Імпорт теми VS Code

Відкрийте **Налаштування → Вигляд → Імпортувати тему VS Code** для пошуку в Open VSX. Результати містять іконку, назву й автора. Виберіть пакет, порівняйте прев’ю кольорів та імпортуйте потрібні варіанти. Пакетний імпорт залишає поточну тему активною. Open VSX є окремим каталогом, тому теми лише з Microsoft Marketplace можуть бути відсутні.

Для локального `.json` або `.jsonc` до 512 KiB натисніть **Вибрати JSON-файл**. У desktop діалог починає з локального `~/.vscode/extensions`, якщо каталог існує. OpenChamber переносить кольори інтерфейсу, синтаксису й diff та вибирає тему файла з її світлим або темним режимом. Кошик біля імпортованої теми в дропдауні видаляє її з підключеного сервера. Видалення вибраної теми повертає стандартну тему відповідного режиму.

Тема зберігається на підключеному сервері OpenChamber, зокрема при імпорті з десктопного чи мобільного застосунку. Повторний імпорт того самого файлу не створює дубліката й не перезаписує тему, змінену на сервері. Розширення VS Code натомість використовує власну тему VS Code.

Якщо файл містить `include` або посилання на окремий файл токенів, виконайте **Developer: Generate Color Theme From Current Settings** у палітрі команд VS Code та імпортуйте отриманий JSON.

## Додати власну тему

1. Створіть директорію тем:

```bash
mkdir -p ~/.config/openchamber/themes
```

2. Додайте свій JSON-файл у цю директорію (наприклад, `my-theme.json`).
3. Відкрийте OpenChamber, потім перейдіть до **Settings -> Theme -> Reload themes**.
4. Оберіть свою тему зі спадного списку. Вона застосується одразу.

## Розташування тем

- macOS/Linux: `~/.config/openchamber/themes/`
