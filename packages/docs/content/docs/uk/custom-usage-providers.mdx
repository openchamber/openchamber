# Власні джерела використання

OpenChamber може використовувати локальну команду замість вбудованого отримання квот для наявного провайдера. Це корисно, коли плагін автентифікації, брокер облікових даних або пул акаунтів володіє даними про використання, які OpenChamber не може прочитати безпосередньо.

Створіть `usage-providers.json` у каталозі даних OpenChamber:

- macOS та Linux: `~/.config/openchamber/usage-providers.json`
- Власний каталог даних сервера: `$OPENCHAMBER_DATA_DIR/usage-providers.json`

Налаштуйте масив argv під ідентифікатором провайдера:

```json
{
  "version": 1,
  "commands": {
    "codex": ["/absolute/path/to/usage-helper", "limits", "--json"]
  }
}
```

У репозиторії є придатний до запуску референсний скрипт `scripts/example-usage-provider.mjs`. Ви можете вказати свою конфігурацію прямо на нього, щоб перевірити відображення кількох акаунтів:

```json
{
  "version": 1,
  "commands": {
    "codex": ["node", "/path/to/openchamber/scripts/example-usage-provider.mjs"]
  }
}
```

Використовуйте абсолютний шлях до виконуваного файлу, коли запускаєте OpenChamber поза терміналом, оскільки десктопні програми можуть не успадковувати `PATH` вашої оболонки.

Команда виконується без оболонки та отримує каталог активної сесії як робочий каталог. Вона має вивести один JSON-об'єкт у stdout:

```json
{
  "version": 1,
  "providerName": "Codex",
  "accounts": [
    {
      "id": "account-1",
      "label": "Work",
      "current": true,
      "available": true,
      "status": "Active",
      "planType": "plus",
      "credits": "5.00",
      "limits": [
        {
          "windowMinutes": 300,
          "usedPercent": 25,
          "resetAtMs": 1788993918000
        },
        {
          "windowMinutes": 10080,
          "usedPercent": 40,
          "resetAtMs": 1789490834000
        }
      ]
    }
  ]
}
```

Кожен акаунт також може надати замаскований `email` як допоміжний текст і `error`, коли несправний лише цей акаунт. `current` визначає акаунт, який використовується для згорнутого показу використання; недоступні акаунти ніколи не подаються як поточні.

Для команд діє тайм-аут 30 секунд і ліміт виводу 1 MiB. Конфігурація зберігається поза звичайними налаштуваннями OpenChamber, тому підключені клієнти не можуть додавати чи змінювати виконувані команди.
