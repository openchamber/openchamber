# Integrations

**Settings → Integrations** is where you sign in to the services OpenChamber works with. The sign-in is stored on the OpenChamber server, so web, desktop, and a paired phone share it.

## GitHub

Expand the **GitHub** card and choose **Connect GitHub** to sign in with a short device code. Once connected, OpenChamber can start sessions from issues and pull requests, attach them to messages, and open or update PRs. Everything GitHub can do is on [GitHub Issues & PRs](/github/).

## Linear

### Connect a workspace

1. Expand the **Linear** card and choose **Connect**.
2. Approve access in the browser tab that opens. The card shows **Waiting for Linear** until you do.

Connect another Linear organization with **Add workspace**. One workspace is current at a time: switch with **Switch to**, and **Disconnect** removes only the current one. Your project mapping stays.

### Browse issues

Linear issues live on the **Issues and PRs** board. Open it with the pull-request icon in the sidebar header, or press <kbd>⌘K</kbd> then <kbd>B</kbd> (<kbd>Ctrl+K</kbd> then <kbd>B</kbd> on Windows and Linux), and choose **Linear** at the top. The board lists the current workspace's issues and lets you:

- show one team or **All teams**
- switch the current workspace, when more than one is connected
- filter by status, by whose issues they are (**Assigned to me** or **Created by me**), and by priority, all at once, and search by title or identifier
- read an issue's description, comments, labels, and priority beside the list
- change its **Status**

### Start a session from an issue

- On the board, pick an issue and choose **Start in worktree…** for a fresh branch, or **New session** to work in the project as it is.
- In the **New Worktree** dialog, pick a Linear issue.

Either way the session opens with the issue attached to the message box, and you write the first message yourself. The board starts it in the project mapped to the issue's team, shown next to **Start in**; pick another project there if you need to. Map teams in the Linear card: **Default project** covers every team, and **Team projects** override it per team. Without a mapping, the board uses the project it showed last.

### Link an issue to a message

In the chat composer, open the **+** menu and choose **Linear**. The issue rides along with your next message as context, and the session's work status panel keeps a link back to it.

### Session comments

Turn on **Session comments** in the Linear card and a session started from an issue, or whose first message has the issue attached, posts a comment on that issue when it starts, finishes, or fails, each with a link that opens the session. Comments are only posted when this OpenChamber server has a public address, so the link works for everyone on the issue; on a local or private address nothing is posted.

## Install an integration

1. Open **Settings → Integrations**.
2. Find the integration and choose **Install**.
3. Restart OpenCode when asked — the provider appears after the restart.
4. Choose **Set up** and sign in. The models then appear in the chat model picker.

Integrations install for your user, so they work in every project. You can update or remove them from the same card at any time.

## Claude Code

Claude Code uses your Claude Pro or Max plan through the Claude Code CLI on your machine — no API keys.

1. Install the integration (above).
2. Choose **Set up** and sign in. If you don't have the Claude Code CLI yet, setup offers to install it first and then sign you in.

**How your Claude account stays safe:** this integration uses Anthropic's official Claude Agent SDK and your installed Claude Code CLI. It does not hijack OAuth, extract or replay browser tokens, impersonate an unsupported client, or bypass Anthropic's authentication flow. It stays on Anthropic's supported access path, so it does not carry the account-ban risk of token hijacking or unauthorized authentication workarounds.

## Update or remove

- **Update** installs the latest published version of the plugin.
- **Remove** deletes the plugin from your OpenCode config. The provider stops loading after OpenCode refreshes.

If a card says the entries need manual management, choose **Manage plugins** and clean up the duplicates there.

## Excalidraw

Excalidraw lets you draw in `.excalidraw` files and Obsidian `.excalidraw.md` drawings right in Files. It's an OpenChamber extension, listed under **OpenChamber extensions** on the same page.

1. Open **Settings → Integrations** and choose **Install** on the Excalidraw card. You can also open a drawing in Files and choose **Install** in the notice above it.
2. Open the drawing again. The canvas replaces the file's text, and Cmd/Ctrl+S, autosave, the source toggle, and fullscreen work as for any file.

The card updates the extension when a new version is out, turns it back on if you paused it, and removes it. Your drawings stay as they are when you remove it; they just open as text. Web and desktop only.
