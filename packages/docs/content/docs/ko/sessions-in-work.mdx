# 작업 중인 세션

사이드바 위쪽의 **작업 중** 영역에는 작업하고 있는 세션이 완료로 표시할 때까지 남습니다. 마지막으로 연 지 얼마나 지났든 마찬가지입니다. 프로젝트에는 지금까지의 모든 세션이 남아 있고, 작업 중에는 아직 끝내지 않은 것만 모입니다.

## 위치

**작업 중** 영역은 사이드바에서 채팅 아래, 프로젝트 또는 타임라인 위에 있습니다. 휴대폰에서도 세션 목록의 같은 자리에 있습니다.

작업 중인 세션은 프로젝트와 폴더에도, 타임라인의 프로젝트 아래에도 그대로 남으므로 두 곳에서 보입니다. 하위 세션도 함께 따라옵니다. 검색에서는 작업 중 영역에 한 번만 나옵니다.

트리 보기에서는 영역의 각 세션이 한 줄을 차지합니다. 제목, 상태, 시간이 표시되고, 풀 리퀘스트나 이슈가 있으면 색깔 표시가 붙습니다. 행에 마우스를 올리면 프로젝트, 브랜치, 링크가 보이고, 사이드바 표시 메뉴에서 **자세한 행**을 켜면 제목 아래에 표시됩니다. 목록 보기는 항상 두 줄입니다.

고정한 세션을 작업 중 위의 **고정됨** 영역에 따로 모으려면 같은 메뉴에서 **고정됨 섹션 표시**를 켜세요. 작업 중인 세션을 고정하면 고정됨에만 표시됩니다.

## 세션이 들어오는 방식

세션은 아래 설명처럼 직접 추적할 수 있고, **설정 → 세션 → 작업 중인 세션**의 **작업 중에 넣는 방식**으로 저절로 들어오게 할 수도 있습니다.

- **끄기**: 기본값입니다. 추적한 세션만 들어옵니다.
- **모든 메시지**: 세션에서 메시지를 보내면 들어옵니다. 완료로 표시한 세션은 새 메시지를 보내면 다시 들어옵니다.
- **Jev가 판단**: [분류 제공자](/ko/classification-providers/)를 설정하면 Jev가 보내는 메시지를 하나하나 읽고, 변경을 요청하거나 버그를 알리거나 곧 할 구체적인 변경을 논의할 때 세션을 작업 중으로 넣습니다. 질문, 설명, 조사는 해당되지 않습니다. 에이전트가 턴을 마치면 Jev가 한 번 더 살펴보므로, 답변을 보고서야 드러나는 작업도 잡아냅니다. 완료로 표시한 세션은 그 뒤에 보낸 메시지에서 Jev가 새 작업을 볼 때만 다시 들어옵니다. 분류 제공자가 없으면 Jev가 판단은 끄기처럼 동작합니다.

worktree 세션을 포함해 모든 프로젝트 세션이 해당됩니다.

이 설정이 생기기 전에 **작업 중인 세션 표시**를 직접 켜 두었다면, 그때까지의 방식인 **모든 메시지**로 시작합니다. 그렇지 않으면 끄기로 시작합니다.

채팅, 보관된 세션, 리뷰 세션, [예약된 작업](/ko/scheduled-tasks/)의 실행은 절대 들어오지 않습니다. 실행을 포크해서 이어서 작업하면 그 포크는 들어옵니다. 하위 세션은 혼자 들어오지 않고 상위 세션과 함께 따라옵니다.

## 직접 추적하고 완료하기

- **추적:** 세션에 마우스를 올리고 눈 아이콘을 누르거나, 세션 메뉴에서 **작업 중으로 추적**을 고릅니다.
- **완료:** 영역 안의 세션에 마우스를 올리고 체크를 누르거나, 메뉴에서 **완료로 표시**를 고릅니다.

휴대폰에서는 세션 행을 밀어서 같은 동작을 하거나 세션 메뉴를 쓰면 됩니다.

채팅에는 눈 아이콘이 없습니다. 그냥 대화이기 때문입니다.

### "이 작업은 완료된 것 같습니다."

[분류 제공자](/ko/classification-providers/)를 설정해 두면 Jev가 작업 중인 세션의 턴을 하나하나 확인합니다. 턴이 작업의 끝처럼 보이면(고맙다고 했거나, 커밋을 요청했거나, 잘 된다고 확인했을 때) Jev는 아무것도 닫지 않고 힌트를 남깁니다.

- 사이드바의 세션 행에 회색 체크
- 입력창 위에 띠: **이 작업은 완료된 것 같습니다.** 와 **완료로 표시** 버튼

Jev가 맞다면 **완료로 표시**를 누르세요. 아니라면 그냥 계속하면 됩니다. 힌트는 다음 메시지를 보내면 사라집니다. 분류 제공자가 없으면 힌트도 없고, 세션은 직접 완료로 표시합니다.

## 요약과 다음 메시지 제안

에이전트가 끝나고 세션이 1분 동안 조용하면, OpenChamber는 작은 모델로 두 가지를 쓸 수 있습니다([공급자, 모델, 에이전트](/ko/providers/) 참고).

- **요약:** 무엇을 했고 지금 어떤 상태인지 짧게 알려 주는 메모로, 마지막 답변 아래와 사이드바의 세션 툴팁에 표시됩니다
- **제안:** 다음에 보낼 법한 메시지로, 입력창 맨 위에 한 줄로 나타납니다. 클릭하면 입력창에 들어가며, 저절로 전송되지는 않습니다

Jev를 쓸 수 있으면 OpenChamber는 먼저 이번 턴에 이것들이 필요한지 Jev에게 묻습니다. 실제 작업 뒤의 "고마워요, 여기까지예요"에도 요약은 붙지만, 남은 일이 없으면 제안은 건너뛰고, 둘 다 쓸모없으면 작은 모델을 아예 호출하지 않습니다. Jev가 없으면 예전처럼 턴마다 둘 다 생성됩니다.

켜고 끄는 곳은 **설정 → 채팅 → 세션 지원**입니다.

## 설정

**설정 → 세션 → 작업 중인 세션**을 엽니다.

- **작업 중인 세션 표시**: 기본으로 켜져 있습니다. 끄면 기능 전체가 꺼져서 영역이 사라지고, 세션이 저절로 들어오지도 않습니다.
- **작업 중에 넣는 방식**: 끄기, 모든 메시지, Jev가 판단 중에서 고르며, 위에서 설명한 대로 동작합니다.

영역만 숨기려면 사이드바 보기 메뉴의 **작업 중 섹션 표시**를 사용하세요.

## 사용할 수 있는 곳

영역과 수동 추적·완료는 VS Code를 포함해 어디서나 동작합니다. 세션이 저절로 작업 중으로 들어오는 기능, "완료된 것 같습니다" 힌트, 요약용 Jev 필터는 OpenChamber 서버가 필요하므로 데스크톱 앱, 웹 앱, 휴대폰에서는 동작하지만 VS Code에서는 동작하지 않습니다. VS Code에서는 세션을 직접 추적합니다.
