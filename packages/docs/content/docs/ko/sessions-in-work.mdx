# 작업 중인 세션

질문, 조사, 간단한 실험은 금방 쌓이고, 실제로 뭔가를 고치고 있는 세션은 그 사이에 묻힙니다. **작업 중** 영역은 이런 세션을 사이드바의 한곳에 모아 둡니다. 세션은 완료라고 할 때까지 그곳에 남습니다.

이것이 "최근"과의 차이입니다. "최근"은 지난 이틀 동안 바뀐 것을 모두 보여 주고 저절로 바뀝니다. 오늘 아침 궁금해서 열어 본 세션은 거기 있지만, 월요일에 멈춰 둔 수정은 이미 사라졌습니다. "작업 중"은 마지막으로 연 지 얼마나 지났든, 아직 끝내지 않은 일의 목록입니다.

## 위치

**작업 중** 영역은 사이드바에서 채팅 아래, "최근"(Timeline 모드에서는 타임라인) 위에 있습니다. 휴대폰에서도 세션 목록의 같은 자리에 있습니다.

작업 중인 세션은 하위 세션과 함께 그곳으로 옮겨집니다. "최근", 타임라인, 프로젝트, 폴더에 두 번 나타나지 않습니다. 완료로 표시하면 원래 자리로 돌아갑니다.

## 직접 추적하고 완료하기

- **추적:** 세션에 마우스를 올리고 눈 아이콘을 누르거나, 세션 메뉴에서 **작업 중으로 추적**을 고릅니다.
- **완료:** 영역 안의 세션에 마우스를 올리고 체크를 누르거나, 메뉴에서 **완료로 표시**를 고릅니다.

휴대폰에서는 세션 행을 밀어서 같은 동작을 하거나 세션 메뉴를 쓰면 됩니다.

worktree 세션을 포함해 모든 프로젝트 세션이 작업 중이 될 수 있습니다. 하위 세션은 상위 세션과 함께 옮겨집니다. 채팅은 절대 들어가지 않습니다. 그냥 대화이므로 눈 아이콘도 없습니다.

## Jev에게 맡기기

[분류 제공자](/ko/classification-providers/)를 설정해 두면 세션을 직접 추적할 필요가 없습니다. Jev는 보내는 메시지를 모두 읽고, 다음과 같은 경우 세션을 작업 중으로 옮깁니다.

- 변경을 요청할 때
- 버그를 알릴 때
- 곧 할 구체적인 변경을 논의할 때

질문, 설명, 조사는 해당하지 않습니다. 에이전트가 턴을 마치면 Jev가 한 번 더 확인하므로, 답변을 보고서야 드러나는 작업도 잡아냅니다.

Jev는 세션을 작업 중으로 **넣기만** 합니다. 한번 완료로 표시한 세션은 그 뒤에 보낸 새 요청이 있어야만 다시 들어옵니다.

### "이 작업은 완료된 것 같습니다."

턴이 작업의 끝처럼 보이면(고맙다고 했거나, 커밋을 요청했거나, 잘 된다고 확인했을 때) Jev는 아무것도 닫지 않고 힌트를 남깁니다.

- 사이드바의 세션 행에 회색 체크
- 입력창 위에 띠: **이 작업은 완료된 것 같습니다.** 와 **완료로 표시** 버튼

Jev가 맞다면 **완료로 표시**를 누르세요. 아니라면 그냥 계속하면 됩니다. 힌트는 다음 메시지를 보내면 사라집니다.

## 요약과 다음 메시지 제안

에이전트가 끝나고 세션이 1분 동안 조용하면, OpenChamber는 작은 모델로 두 가지를 쓸 수 있습니다([공급자, 모델, 에이전트](/ko/providers/) 참고).

- **요약:** 무엇을 했고 지금 어떤 상태인지 짧게 알려 주는 메모로, 마지막 답변 아래와 사이드바의 세션 툴팁에 표시됩니다
- **제안:** 다음에 보낼 법한 메시지로, 입력창 맨 위에 한 줄로 나타납니다. 클릭하면 입력창에 들어가며, 저절로 전송되지는 않습니다

Jev를 쓸 수 있으면 OpenChamber는 먼저 이번 턴에 이것들이 필요한지 Jev에게 묻습니다. 실제 작업 뒤의 "고마워요, 여기까지예요"에도 요약은 붙지만, 남은 일이 없으면 제안은 건너뛰고, 둘 다 쓸모없으면 작은 모델을 아예 호출하지 않습니다. Jev가 없으면 예전처럼 턴마다 둘 다 생성됩니다.

켜고 끄는 곳은 **설정 → 채팅 → 세션 지원**입니다.

## 설정

**설정 → 세션 → 작업 중인 세션**을 엽니다.

- **작업 중인 세션 표시:** 영역 자체입니다. 끄면 세션은 늘 있던 자리에 남습니다
- **세션을 자동으로 작업 중으로 이동:** Jev가 하는 부분입니다. 끄면 직접 추적만 합니다

두 설정 모두 기본으로 켜져 있습니다.

## 사용할 수 있는 곳

영역과 수동 추적·완료는 VS Code를 포함해 어디서나 동작합니다. 자동 이동, "완료된 것 같습니다" 힌트, 요약용 Jev 필터는 OpenChamber 서버가 필요하므로 데스크톱 앱, 웹 앱, 휴대폰에서는 동작하지만 VS Code에서는 동작하지 않습니다.
