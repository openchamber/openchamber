# 작업 중인 세션

메시지를 보낸 세션은 그 작업을 사이드바 위쪽의 **작업 중** 영역에 넣고, 작업은 완료로 표시할 때까지 그곳에 남습니다. 마지막으로 연 지 얼마나 지났든 마찬가지입니다. 프로젝트에는 지금까지 한 모든 것이 남아 있고, 작업 중에는 아직 끝내지 않은 것만 모입니다.

## 작업이란

사이드바에는 개별 세션이 아니라 작업이 나열됩니다. 작업은 다음 중 하나입니다.

- **worktree**와 그 안의 모든 세션. 작업 이름이 붙은 한 행으로 표시됩니다([Worktree 세션](/ko/worktrees/) 참고).
- **프로젝트 폴더 자체에 있는 세션**과 그 아래에 중첩된, 그 세션에서 파생된 것들: 하위 에이전트, 리뷰, 남겨 둔 포크와 곁가지 질문, 에이전트가 대신 시작한 세션.

행을 클릭하면 열리고, 왼쪽 화살표를 누르면 그 아래 세션이 펼쳐집니다.

## 위치

**작업 중** 영역은 사이드바에서 채팅 아래, 프로젝트 또는 타임라인 위에 있습니다. 이 영역에 들어간 작업은 프로젝트에서 빠지므로 각 작업은 한 번만 보입니다. 프로젝트 아래에도 남겨 두려면 사이드바 표시 메뉴에서 **진행 중인 작업을 프로젝트 아래에도 표시**를 켜세요. 검색에서는 작업 중 영역에 한 번만 나옵니다.

각 작업은 한 줄을 차지합니다. 제목과 상태가 표시되고, 풀 리퀘스트나 이슈가 있으면 색깔 표시가 붙습니다. 행은 최근 활동 순으로 정렬되므로 날짜는 표시되지 않습니다. 행에 마우스를 올리면 프로젝트, 브랜치, 시간, 링크가 보이고, 표시 메뉴에서 **자세한 행**을 켜면 제목 아래에 표시됩니다. 자세한 행은 프로젝트 아래에도 적용되며, 작업 안의 세션은 계속 한 줄로 표시됩니다.

고정한 세션은 작업 중 위의 **고정됨** 영역에 따로 모입니다. 각 프로젝트 아래에만 두려면 같은 메뉴에서 **고정됨 섹션 표시**를 끄세요. 작업 중인 세션을 고정하면 고정됨에만 표시됩니다.

휴대폰의 세션 목록도 같고, 표시 메뉴도 같습니다. **자세한 행**을 끄지 않는 한 행은 두 줄로 표시되며, 마우스를 올릴 수 없으므로 작업을 펼치는 화살표가 항상 보입니다.

## 세션이 들어오는 방식

세션에서 메시지를 보내면 작업 중으로 들어옵니다. worktree 세션을 포함해 모든 프로젝트 세션이 해당됩니다. 새 worktree는 만드는 즉시 작업 중으로 들어오며, 그 안에 열린 초안을 아직 보내지 않았어도 마찬가지입니다.

완료로 표시한 세션은 새 메시지를 보내면 다시 들어옵니다.

채팅, 보관된 세션, 리뷰 세션, [예약된 작업](/ko/scheduled-tasks/)의 실행은 절대 들어오지 않습니다. 실행을 포크해서 이어서 작업하면 그 포크는 들어옵니다. 하위 에이전트는 상위 세션을 작업 중으로 넣지 않습니다.

## 작업 이름

작업 내용이 분명해지면 에이전트가 곧바로 "로그인 타임아웃 수정"처럼 몇 단어로 각 작업의 이름을 붙입니다. worktree는 이름을 브랜치 설명에 저장하므로 저장소를 어디서 열든 보입니다. 프로젝트 폴더의 세션은 그 이름을 제목으로 씁니다. 직접 이름을 바꾸면 그 이름이 유지됩니다. 에이전트는 직접 지은 작업 이름을 바꾸지 않습니다.

## 직접 추적하고 완료하기

- **추적:** 행에 마우스를 올리고 눈 아이콘을 누르거나, 세션 메뉴에서 **작업 중으로 추적**을 고릅니다.
- **완료:** 영역 안의 행에 마우스를 올리고 체크를 누르거나, 메뉴에서 **완료로 표시**를 고릅니다. 완료하면 작업 전체가 끝나며, 그 안에서 아직 작업 중이던 모든 세션이 함께 완료됩니다.

worktree를 완료로 표시하면 작업 중에서 빠지고 그 자리에 그대로 남습니다. 완료로 표시할 때 보관도 하려면 **설정 → 세션**에서 **완료로 표시하면 워크트리 보관**을 켜세요. 그러면 폴더는 사라지고, 세션과 변경, 브랜치는 보관함 페이지에 남아 언제든 복원할 수 있습니다. 그 안에서 아직 실행 중인 세션이 있으면 worktree는 남습니다.

휴대폰에서는 행을 옆으로 밀어서 같은 동작을 할 수 있습니다.

채팅에는 눈 아이콘이 없습니다. 그냥 대화이기 때문입니다.

### "이 작업은 완료된 것 같습니다."

[분류 제공자](/ko/classification-providers/)를 설정해 두면 Jev가 작업 중인 세션의 턴을 하나하나 확인합니다. 턴이 작업의 끝처럼 보이면(고맙다고 했거나, 커밋을 요청했거나, 잘 된다고 확인했을 때) Jev는 아무것도 닫지 않고 힌트를 남깁니다.

- 사이드바의 세션 행에 회색 체크
- 입력창 위에 띠: **이 작업은 완료된 것 같습니다.** 와 **완료로 표시** 버튼

Jev가 맞다면 **완료로 표시**를 누르세요. 아니라면 그냥 계속하면 됩니다. 힌트는 다음 메시지를 보내면 사라집니다. 분류 제공자가 없으면 힌트도 없고, 세션은 직접 완료로 표시합니다.

## 요약과 다음 메시지 제안

에이전트가 끝나고 세션이 1분 동안 조용하면, OpenChamber는 작은 모델로 두 가지를 쓸 수 있습니다([공급자, 모델, 에이전트](/ko/providers/) 참고).

- **요약:** 무엇을 했고 지금 어떤 상태인지 짧게 알려 주는 메모로, 마지막 답변 아래와 사이드바의 세션 툴팁에 표시됩니다
- **제안:** 다음에 보낼 법한 메시지로, 입력창 맨 위에 한 줄로 나타납니다. 클릭하면 입력창에 들어가며, 저절로 전송되지는 않습니다

Jev를 쓸 수 있으면 OpenChamber는 먼저 이번 턴에 이것들이 필요한지 Jev에게 묻습니다. 실제 작업 뒤의 "고마워요, 여기까지예요"에도 요약은 붙지만, 남은 일이 없으면 제안은 건너뛰고, 둘 다 쓸모없으면 작은 모델을 아예 호출하지 않습니다. Jev가 없으면 예전처럼 턴마다 둘 다 생성됩니다.

켜고 끄는 곳은 **설정 → 채팅 → 세션 지원**입니다.

## 설정

**설정 → 세션 → 작업 중인 세션**을 엽니다. 설정은 **작업 중인 세션 표시** 하나뿐이고 기본으로 켜져 있습니다. 끄면 기능 전체가 꺼집니다. 영역이 사라지고, 메시지를 보내도 세션이 작업 중으로 들어오지 않습니다.

영역만 숨기려면 사이드바 보기 메뉴의 **작업 중 섹션 표시**를 사용하세요.

## 사용할 수 있는 곳

영역과 수동 추적·완료는 VS Code를 포함해 어디서나 동작합니다. 메시지를 보낼 때 작업 중으로 넣는 기능, "완료된 것 같습니다" 힌트, 요약용 Jev 필터는 OpenChamber 서버가 필요하므로 데스크톱 앱, 웹 앱, 휴대폰에서는 동작하지만 VS Code에서는 동작하지 않습니다. VS Code에서는 세션을 직접 추적합니다.
