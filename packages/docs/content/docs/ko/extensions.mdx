# 확장

**설정 → 확장**에서 다른 사람이 만든 패널을 OpenChamber에 추가할 수 있습니다. 확장은 오른쪽 레일에 놓이는 작은 페이지로, 내장 패널 옆에 자리합니다. 다른 서비스의 데이터를 보여 주거나, 작업을 채팅에 첨부하거나, 허용하면 세션을 시작하고 프롬프트를 보내고 파일을 읽을 수 있습니다.

확장은 OpenChamber 웹과 데스크톱에서 동작합니다. VS Code와 모바일 앱은 아직 확장을 불러오지 않습니다. OpenCode 플러그인과는 다른 것입니다.

## 설치하기

1. **설정 → 확장**을 엽니다.
2. **폴더, ZIP 또는 URL** 칸에 다음 중 하나를 붙여 넣고 **추가**를 선택합니다:
   - 이 컴퓨터에 있는 폴더의 절대 경로
   - `.zip` 파일의 경로
   - git 저장소나 zip 파일로 가는 https 링크
3. 확장이 권한을 요청하면 대화 상자에 목록이 나옵니다. **허용하고 켜기**를 선택하거나, **제거**로 다시 빼냅니다.

`.zip`을 칸에 끌어다 놓거나 옆의 압축 파일 버튼으로 고를 수도 있습니다. 압축 파일은 OpenChamber 서버로 업로드되므로 원격 인스턴스에서도 동작합니다. 데스크톱에서는 폴더 버튼이 시스템 선택 창을 열고, 끌어다 놓은 폴더는 그 경로에서 설치됩니다.

확장의 아이콘이 레일에 나타납니다. 나타나지 않으면 [문제 해결](/troubleshooting/)을 보세요.

폴더로 설치하면 그 폴더에서 바로 실행되므로 확장을 개발하는 사람이 수정하고 다시 불러올 수 있습니다. zip이나 URL은 먼저 OpenChamber의 데이터 폴더로 복사되고, 원본 파일은 건드리지 않습니다.

## 확장이 할 수 있는 일

패널을 보여 주고 어떤 프로젝트와 세션이 열려 있는지 읽는 데는 권한이 필요 없습니다. 사용자를 대신해 행동하는 일에는 권한이 필요하고, 전체 목록은 설치할 때 한 번 보게 됩니다:

- **세션에 메시지 보내기**: 모델에 프롬프트를 작성해 보냅니다. 토큰을 사용하고 도구를 실행할 수 있습니다.
- **세션과 워크트리 만들기**: 현재 프로젝트에서.
- **프로젝트 파일 읽기 및 쓰기**: 열린 프로젝트의 모든 파일.
- **프로젝트 밖의 파일 읽기 및 쓰기**: 대화 상자에 적힌 위치만.
- **외부 서비스에 연결**: 설정 → 통합에서 연결한 계정으로.
- **세션의 대화 읽기**: 그 세션에서 확장의 작업을 실행할 때만.
- **로컬 서비스 실행**: 사용자 계정의 전체 권한을 가진 별도 프로그램. 작성자를 신뢰할 때만 허용하세요.

새 버전이 허용한 것보다 더 많은 권한을 요청하면 카드에 **승인 필요**와 **권한 검토** 버튼이 표시됩니다. 새 목록을 허용할 때까지 그 확장은 꺼진 상태로 남습니다.

## 어디에 나타나는지

레일의 패널 말고도 확장은 이미 쓰는 메뉴에 항목을 더할 수 있습니다. 채팅 메시지의 작업, 세션 메뉴, 채팅창 옆 + 메뉴, 그리고 아무것도 열지 않고 무언가를 첨부하는 `/task ABC-12` 같은 슬래시 명령입니다. 이 중 무엇을 제공할지는 확장이 정하며, 확장을 허용하기 전까지는 모두 꺼져 있습니다.

## 계정 연결하기

서비스와 통신하는 확장은 **설정 → 통합**의 **확장 계정** 아래에 카드가 생깁니다. 서비스에 따라 카드는 API 토큰, 사용자 이름과 토큰, 또는 로그인용 client id를 요청합니다. **연결**을 선택합니다. **연결 해제**는 저장된 토큰을 잊습니다. 확장이 선언한 추가 칸은 칸을 벗어날 때 자동으로 저장됩니다.

토큰은 OpenChamber 서버에 남습니다. 확장의 페이지는 토큰을 절대 보지 못합니다.

## 업데이트

git URL로 설치한 확장은 스스로 업데이트할 수 있습니다. **설정 → 확장**을 열면 각 확장을 최대 한 시간에 한 번 확인하고, **업데이트 확인**은 즉시 확인합니다. 더 새로운 버전이 있는 카드에는 **업데이트 가능** 표시와 **업데이트** 버튼이 나타납니다. 업데이트해도 권한, 계정, 설정은 그대로 유지되며, 새 버전이 더 많은 것을 요구하면 승인 대화 상자가 다시 나타납니다. 폴더나 zip으로 설치한 확장은 업데이트되지 않으니 직접 교체하세요.

설치할 때 git URL에 `#v1.2.0`이나 `#stable`을 붙이면 기본 브랜치 대신 태그나 브랜치를 따라갑니다.

## 일시 중지 또는 제거

각 카드에는 **사용 중** 스위치가 있습니다. 끄면 확장은 설치된 채로 남지만 패널이 숨겨지고 호출이 차단됩니다. **제거**는 zip이나 URL로 설치한 확장을 OpenChamber 데이터 폴더에서 지웁니다. 폴더로 설치한 경우 경로만 잊고, 폴더는 그대로 남습니다.
