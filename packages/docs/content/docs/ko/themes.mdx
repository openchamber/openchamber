# 테마

OpenChamber는 내장 테마와 사용자 정의 테마 JSON 파일을 지원합니다.

## VS Code 테마 가져오기

**설정 → 모양 → VS Code 테마 가져오기**에서 Open VSX를 검색하세요. 결과에는 아이콘, 이름, 작성자가 표시됩니다. 패키지를 선택하고 색상 미리보기를 비교한 뒤 원하는 변형을 가져오세요. 일괄 가져오기는 현재 테마를 유지합니다. Microsoft Marketplace에만 게시된 테마는 Open VSX에 없을 수 있습니다.

512 KiB 이하의 로컬 `.json` 또는 `.jsonc`에는 **JSON 파일 선택**을 사용하세요. 데스크톱에서는 `~/.vscode/extensions` 폴더가 있으면 그곳에서 시작합니다. 파일 가져오기는 UI, 구문, diff 색상을 변환하고 테마를 적용합니다. 드롭다운에서 가져온 테마 옆의 휴지통으로 연결된 서버에서 삭제할 수 있습니다. 선택된 테마를 삭제하면 해당 모드의 기본 테마로 돌아갑니다.

데스크톱이나 모바일에서 가져올 때도 테마는 연결된 OpenChamber 서버에 저장됩니다. 같은 파일을 다시 가져와도 중복이 생기지 않으며, 서버에서 편집한 테마를 덮어쓰지 않습니다. VS Code 확장 기능은 VS Code 자체 테마를 따릅니다.

파일에서 `include`를 사용하거나 별도의 토큰 파일을 참조한다면, VS Code 명령 팔레트에서 **Developer: Generate Color Theme From Current Settings**를 실행하고 생성된 JSON을 가져오세요.

## 사용자 정의 테마 추가

1. 테마 디렉터리를 만듭니다:

```bash
mkdir -p ~/.config/openchamber/themes
```

2. 해당 디렉터리에 JSON 파일을 추가합니다(예: `my-theme.json`).
3. OpenChamber를 열고 **Settings -> Theme -> Reload themes**로 이동합니다.
4. 드롭다운에서 테마를 선택합니다. 곧바로 적용됩니다.

## 테마 위치

- macOS/Linux: `~/.config/openchamber/themes/`
