# 채팅

채팅은 어떤 프로젝트에도 속하지 않는, 에이전트와의 평범한 대화입니다. 코드베이스와 상관없는 일에 쓰세요. FreeBSD용 KDE에 패치하는 방법, 정규식이 하는 일, 이메일 초안 같은 것들입니다. 에이전트는 임시 폴더에서 일하므로 저장소도 브랜치도 없고, 프로젝트의 맥락이 대화를 무겁게 하지도 않습니다.

## 채팅 시작하기

가장 빠른 방법은 사이드바의 **채팅** 섹션에 있는 **+**입니다. 휴대폰에서는 세션 목록 맨 위의 **새 채팅**이나 채팅의 **+**를 탭하세요.

**Mod+N**(macOS에서는 Cmd+N, 그 외에는 Ctrl+N)과 명령 팔레트의 **새 세션**은 마지막으로 쓴 쪽에서 새 세션을 엽니다. 마지막 새 세션이 채팅이었다면 채팅, 아니면 프로젝트입니다. 첫 메시지를 보내기 전이라면 채팅으로 바꿀 수 있습니다.

## 채팅의 위치

채팅은 사이드바 맨 위에 전용 섹션이 있으며, [작업 중](/ko/sessions-in-work/)과 프로젝트보다 위에 있습니다. 다른 세션처럼 최근 활동 순으로 정렬되고, 고정한 채팅은 위에 남습니다. Timeline 모드에서는 최근 채팅 세 개가 보이고, **세션 더 보기**로 나머지를 불러옵니다. 섹션은 다른 섹션처럼 접을 수 있습니다.

휴대폰에서는 세션 패널의 프로젝트 목록 위에 채팅이 있습니다.

## 채팅에서 할 수 있는 것과 없는 것

채팅마다 전용 빈 폴더가 있으므로, 에이전트는 그 안에서 파일을 만들고 고칠 수 있습니다. 스크립트, 간단한 프로토타입, 변환한 문서 같은 것들입니다. 채팅에 없는 것:

- git 상태, 브랜치, worktree
- 작업 중으로 옮기기(채팅은 [작업 중](/ko/sessions-in-work/)에 나타나지 않습니다)
- 새 세션에서 계획 실행하기
- Linear 이슈에서 시작하기

메모, 할 일, 계획은 동작합니다. 모든 채팅이 하나의 세트를 공유하며, 프로젝트와는 따로입니다.

채팅은 계속 채팅입니다. 끝난 채팅을 프로젝트로 옮기는 방법은 없습니다. 대화가 실제 작업으로 바뀌면 프로젝트에서 세션을 시작하고 쓸 만한 내용을 가져가세요.

## 보관과 삭제

목록에서 숨기려면 채팅을 보관합니다. 완전히 지우려면 삭제합니다. 다른 세션(포크나 하위 에이전트)이 그 폴더를 더 이상 쓰지 않으면 폴더도 함께 지워집니다.

## 폴더 위치

채팅 폴더는 `~/.config/openchamber/chats`에 있으며, 날짜마다 폴더가 하나씩 생깁니다. `OPENCHAMBER_DATA_DIR`로 OpenChamber 데이터를 옮겼다면 그 폴더 아래에 있습니다. 채팅을 다른 곳에 두려면 `OPENCHAMBER_CHATS_DIR`를 설정하세요. [환경 변수](/ko/environment/)를 참고하세요. OpenCode가 다른 사용자로 실행되어 홈 폴더를 읽을 수 없을 때 중요합니다.

> VS Code에는 채팅이 없습니다. 확장은 항상 열어 둔 폴더에서 일합니다.
