# 음성 모드

음성 모드를 사용하면 메시지를 받아쓰게 하고 응답을 소리내어 들을 수 있습니다. **Settings → OpenChamber → Voice**에서 켭니다.

## 응답을 소리내어 읽기(text-to-speech)

응답을 읽는 방식을 선택합니다.

- **browser** — 브라우저의 내장 음성, 설정 불필요
- **OpenAI** — OpenAI의 음성. API 키를 붙여넣고 음성을 선택합니다
- **OpenAI-compatible** — OpenAI 형식을 지원하는 모든 서비스. URL과, 필요하다면 API 키를 입력합니다
- **macOS say** — 내장 `say` 명령. 이를 지원하는 Mac에서 사용 가능

켜면 메시지에 재생 버튼이 생겨 소리내어 들을 수 있습니다.

## 메시지 받아쓰기(speech-to-text)

음성을 텍스트로 변환하는 방식을 선택합니다.

- **로컬**은 OpenChamber가 실행되는 컴퓨터에서 음성 모델을 실행합니다. 모델은 처음 받아쓰기할 때 다운로드되며, 오디오는 그 컴퓨터를 벗어나지 않습니다.
- **서버**는 오디오를 OpenAI 호환 변환 서비스로 보냅니다. URL과, 필요하다면 API 키를 입력합니다.

로컬 모델:

- **Parakeet v3**가 기본값입니다. 영어와 우크라이나어를 포함해 25개 유럽 언어를 지원하며 가장 빠릅니다. v3가 기본값이 되기 전에 Parakeet v2로 받아쓰기를 했다면 다른 모델을 선택할 때까지 v2가 유지됩니다.
- **Parakeet v2**는 영어만 지원합니다.
- **Whisper large-v3 turbo**는 99개 언어를 지원합니다. Parakeet보다 약 9배 느려서 긴 받아쓰기는 표시되기까지 몇 초가 걸립니다.
- **Qwen3-ASR 0.6B**는 중국어, 일본어, 한국어, 아랍어를 포함해 30개 언어를 지원합니다. 우크라이나어는 지원하지 않습니다.
- **Whisper tiny**는 다운로드 크기가 가장 작아 느린 컴퓨터에 적합합니다.

Whisper와 Qwen3-ASR 모델은 언어를 스스로 감지하므로, 짧은 문구에서는 잘못된 언어를 고를 수 있습니다. 모델 목록 아래의 **언어**에 `uk`나 `en` 같은 언어 코드를 입력하면 더 이상 추측하지 않습니다.

**잘못 들은 단어 고치기**를 켜면 받아쓰기를 멈춘 뒤 Small Model(설정 → 세션 → Small Model)이 텍스트를 다시 살펴봅니다. 음성 모델이 잘못 들은 단어를 바로잡고 "음" 같은 군말을 지웁니다. 이때 텍스트는 Small Model의 제공자로 전송되며 1, 2초 뒤에 나타납니다. Small Model이 없으면 텍스트는 들린 그대로 입력됩니다.

이 서비스들에 입력한 API key는 브라우저가 아니라 OpenChamber 서버에 보관됩니다. 키를 입력하고 Enter를 누르면 저장되고, 이후 입력란에 키가 저장되어 있다고 표시되며 ×로 삭제할 수 있습니다.

## 휴대폰 관련 참고 사항

휴대폰에서 응답을 소리내어 읽을 때는 OpenAI 또는 OpenAI-compatible 옵션이 가장 안정적입니다. 모바일 브라우저는 내장 음성을 제한합니다.
