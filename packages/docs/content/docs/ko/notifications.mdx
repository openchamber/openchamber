# 알림

알림은 화면을 지켜보지 않아도 무언가가 사용자의 주의를 필요로 할 때, 즉 세션이 완료되었거나, 오류가 발생했거나, 질문했거나, 무언가를 할 권한이 필요할 때 알려줍니다. **Settings → OpenChamber → Notifications**에서 설정합니다.

## 켜기

1. **Settings → OpenChamber → Notifications**를 엽니다.
2. 브라우저나 시스템이 요청하면 알림을 허용합니다.
3. 알림받고 싶은 내용을 선택합니다.
   - 세션 **완료**
   - 세션 **오류** 발생
   - 세션이 **질문**할 때
   - 세션이 **권한**을 필요로 할 때
   - **하위 작업** 완료

## 전달 방식

- **데스크톱**에서는 네이티브 시스템 알림을 받습니다
- **브라우저 또는 설치된 앱**에서는 웹 푸시 알림을 받으므로 탭이 백그라운드에 있어도 도착합니다

자동 수락으로 설정된 세션은 권한 알림으로 귀찮게 하지 않습니다.

앱 내 기록에서 목록에 항목이 들어올 때 소리를 켤 수 있습니다. 창이 뒤에 있어도 울립니다.

## 문구 맞춤 설정

각 알림 종류에는 에이전트 이름과 모델 같은 필드를 사용해 편집할 수 있는 제목과 메시지 템플릿이 있습니다. 또한 알림이 짧게 유지되도록 마지막 메시지를 얼마나 포함할지에 대한 제한도 있습니다.

## 앱 내 기록

헤더의 종 아이콘은 이 기기에 토스트와 세션 이벤트 목록을 남깁니다. 탭하기 전에 토스트가 사라져도 알림 센터에서는 읽지 않은 상태로 남습니다. 항목을 열거나 확인/복사를 누르면 읽음으로 표시됩니다. 항목은 직접 지우거나 만료될 때까지 유지됩니다. 모두 읽음으로 표시하면 아직 떠 있는 토스트도 닫습니다.

시스템 또는 푸시 알림을 클릭하면 세션 ID가 있을 때 해당 세션이 열립니다.

Settings → OpenChamber → Notifications에 앱 내 기록 섹션이 있습니다. 처음에는 켜져 있습니다. 목록을 끄면 종 아이콘이 숨겨집니다. 종류를 끄면 목록과 배지에서 숨겨집니다. 항목은 그대로 저장되므로 다시 켜면 돌아옵니다. 정보, 성공, 하위 작업은 처음부터 꺼져 있어 배지가 채워지지 않습니다. 하위 작업 OS 배너는 이벤트에 있는 별도 스위치입니다. 이벤트와 템플릿은 알림 전달 쪽에 남습니다.
