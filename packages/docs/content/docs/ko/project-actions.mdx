# 프로젝트 작업

프로젝트 액션은 한 번 저장해 두고 클릭으로 실행하는 셸 명령입니다. 개발 서버, 빌드, 테스트 실행 등이 해당됩니다. 각 프로젝트는 자체 목록을 유지합니다. **Settings → Projects → Project Actions**에서 설정합니다.

## 액션 추가하기

1. **Settings → Projects**를 열고 **Project Actions** 섹션을 찾습니다.
2. 액션을 추가하고 이름을 지정하고 아이콘을 선택하고 실행할 명령을 입력합니다.
3. 저장합니다.

명령이 특정 운영체제에서만 의미가 있다면 액션을 해당 운영체제로 제한할 수 있습니다.

## 액션 실행하기

채팅 오른쪽의 카드인 Work Status 패널의 **프로젝트** 섹션에 액션 줄이 있습니다. 액션을 누르면 실행되고, 다시 누르면 중지됩니다. 옆의 셰브론으로 다른 액션을 고를 수 있고, 그 메뉴의 **새 작업 추가**는 **설정 → 프로젝트**를 엽니다. 줄에는 마지막으로 고른 액션이 표시되고, 액션이 실행 중이면 그 액션이 표시됩니다. 실행에 미리보기 주소가 있으면 줄 옆의 지구본 버튼으로 그 주소를 엽니다.

키보드로는 macOS에서 **⌘⌥R**, Windows와 Linux에서 **Ctrl+Alt+R**을 눌러 프로젝트 작업 대화상자를 엽니다. 현재 프로젝트의 액션이 상태와 함께 나열됩니다. 화살표 키로 선택을 옮기고, Enter는 멈춰 있는 액션을 실행하거나 실행 중인 액션을 중지하며, Esc는 대화상자를 닫습니다. 검색 필드로 목록을 거를 수 있고, 맨 끝의 **작업 설정**은 프로젝트의 액션 설정을 엽니다. 대화상자는 Work Status 줄의 액션이 선택된 상태로 열리므로, 단축키에 이어 Enter를 누르면 마지막 실행을 반복합니다. 단축키는 **설정 → 단축키**의 **프로젝트 작업 열기**에서 바꿀 수 있습니다.

⌘P 또는 Ctrl+P로 여는 명령 팔레트에서 "실행"이나 액션 이름을 입력하면 **실행: dev**, **중지: dev** 같은 항목이 나옵니다. 팔레트의 **프로젝트 작업**은 대화상자를 엽니다.

각 액션은 세션 폴더의 터미널에서 실행됩니다. 세션이 worktree에 있으면 그 worktree이고, 메인 체크아웃에서 실행하도록 설정한 액션은 메인 체크아웃입니다. 출력을 볼 수 있도록 터미널이 열립니다. 프로젝트 액션은 데스크톱과 웹 앱에서 쓸 수 있습니다. VS Code, 휴대폰, Chats의 세션에는 없습니다.

## 개발 서버 자동 열기

서버를 시작하는 액션에 **auto-open URL**을 켭니다. OpenChamber가 출력에서 로컬 주소를 감시하다가 열기를 제안합니다. [Preview & Dev Servers](/ko/preview/)를 참고하세요. 데스크톱에서는 SSH 포트 포워딩을 통해 라우팅할 수도 있습니다.

서버 주소가 정해져 있다면 액션의 URL 필드에 입력하세요. `{worktree}`와 `{branch}`는 액션이 실행되는 체크아웃으로 바뀌므로 액션 하나를 모든 worktree에서 쓸 수 있습니다. [portless](https://github.com/vercel-labs/portless)를 쓰면 `https://{worktree}.myapp.localhost`가 `feature/auth` worktree에서는 `https://auth.myapp.localhost`를, 기본 체크아웃에서는 `https://myapp.localhost`를 엽니다. 필드가 아예 필요 없을 수도 있습니다. portless가 주소를 출력하면 OpenChamber는 그 뒤의 포트 대신 그 주소를 엽니다. 원격 인스턴스에 연결된 데스크톱에서는 터널을 통과하는 것이 루프백 포트뿐이라 대신 포트를 엽니다.
