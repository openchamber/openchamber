# 에이전트 페이지

에이전트는 채팅 안에 바로 페이지를 그릴 수 있습니다. 차트, 표, 다이어그램, 인터페이스 목업, 짧은 양식 같은 것입니다. 그 페이지에서 옵션을 고르라고 요청할 수 있고, 답이 다른 사람에게서 와야 할 때는 같은 페이지를 링크와 PIN으로 동료에게 보낼 수 있습니다.

## 페이지 요청하기

평소 말투로 에이전트에게 요청하세요. 예를 들어:

- "레이아웃 옵션 세 가지를 목업으로 보여 주고 하나를 고르게 해 줘."
- "테스트 결과를 차트로 보여 줘."
- "이 마이그레이션 중 어느 것을 먼저 실행할지 물어봐."

페이지는 파일에 접근할 수 없는 프레임 안에서 채팅에 나타납니다. **전체 화면으로 열기**로 크게 볼 수 있고, **HTML로 다운로드**로 사본을 저장할 수 있습니다.

## 페이지에서 답하기

에이전트가 페이지에서 무언가를 물으면 채팅에 **페이지에서 답변을 기다리는 중**이 표시됩니다. 옵션을 고르거나 필드를 채운 다음 페이지의 보내기 버튼을 누르세요. 에이전트가 답변을 받고, 페이지에는 선택한 내용이 표시됩니다.

- **거절**은 고르지 않겠다는 뜻을 에이전트에게 전합니다. 에이전트가 대신 고르지는 않습니다.
- 말로 답할 수도 있습니다. 채팅에 쓰면 에이전트가 메시지를 읽습니다.

### 나중에 답하기

에이전트가 항상 기다릴 필요는 없습니다. 페이지를 보여 주고 계속 작업할 수도 있습니다. 페이지는 답할 때까지 열려 있으며, 에이전트의 턴이 끝나거나 앱이 다시 시작되어도 남아 있습니다. 답변은 세션에 별도의 행으로 도착하고, 에이전트가 쉬고 있었다면 다시 움직이게 합니다.

## 동료와 페이지 공유하기

동료나 관리자처럼 다른 사람에게서 답을 받아야 할 때는 에이전트에게 그 사람에게 페이지를 보내 달라고 요청하세요:

- "Yulia와 Denis에게 이 두 디자인 중 어느 쪽이 좋은지 물어봐."

1. 에이전트가 사람마다 링크를 하나씩 만듭니다. 메시지 아래 카드에 각 이름과 함께 **링크 복사**와 **PIN 복사**가 표시됩니다.
2. 각 사람에게 링크와 PIN을 아무 메신저로 직접 보내세요.
3. 받은 사람은 브라우저에서 링크를 열고 PIN을 입력한 뒤 페이지에서 답합니다. 이를 위해 OpenChamber가 필요하지 않습니다.
4. 답변은 질문한 세션으로 돌아오고 알림이 표시됩니다. 에이전트가 답변을 읽고 작업을 이어 갑니다.

에이전트는 표와 차트가 있는 보고서처럼 읽기만 하는 페이지도 공유할 수 있습니다. 양식이 없고 답변도 돌아오지 않습니다.

카드에는 각 사람이 언제 페이지를 열었고 언제 답했는지 표시됩니다. 카드의 **열기**로 상대가 보는 그대로의 페이지를 볼 수 있으며, 직접 열어 본 것은 상대가 연 것으로 집계되지 않습니다.

### 공유 링크의 작동 방식

- 따로 켤 것은 없습니다. 누군가에게 링크를 보내기 전까지 페이지는 아무에게도 전달되지 않습니다.
- 각 사람은 한 번만 답할 수 있고, 그 답은 최종입니다.
- 링크는 최대 영업일 2일 동안 작동하며 토요일과 일요일은 세지 않습니다. 더 짧게 하려면 에이전트에게 요청하세요.
- 카드에서 사람별 메뉴의 **링크 취소**로 그 사람의 링크를 회수할 수 있습니다.
- PIN을 너무 많이 틀리면 링크가 잠깁니다.
- OpenChamber는 누가 답하는지 확인하지 않습니다. 링크와 PIN이 있으면 누구나 답할 수 있습니다. 카드에 보이는 이름은 에이전트에게 알려 준 이름입니다.
- 페이지와 답변은 암호화되어 전달됩니다. 공유 서비스는 암호화된 사본만 보관하고, 답변이 도착하면 삭제합니다. PIN 없는 링크로는 아무것도 열리지 않습니다.
- 페이지는 OpenChamber의 공유 서비스를 거치거나, [프라이빗 릴레이](/ko/private-relay/)에서 자체 릴레이를 설정했다면 그 릴레이를 거칩니다.

## 공유받은 페이지 열기

OpenChamber가 있으면 공유받은 페이지를 앱에서 열어 내 에이전트가 읽고 결정을 돕게 할 수 있습니다:

1. 링크를 채팅 입력창에 붙여 넣으세요. PIN 입력란이 있는 칩으로 바뀝니다.
2. PIN을 입력하고 질문을 써서 보내세요. 에이전트는 메시지와 함께 페이지 내용을 받으며, 이 내용은 다른 사람의 콘텐츠로 표시됩니다.
3. 메시지 아래의 **열기**를 누르면 페이지가 사이드 패널에, 휴대폰에서는 전체 화면으로 열립니다. 페이지 자체의 보내기 버튼으로 답하세요.

에이전트는 답을 제안할 수 있지만 보낼 수 있는 사람은 사용자뿐입니다. 링크와 PIN은 모델에 전달되지 않습니다.

사이드 패널의 **공유 페이지**에는 받은 모든 페이지가 최신순으로 상태와 함께 나열됩니다. 휴대폰에서는 작업 공간 서랍의 탭입니다. 열린 페이지에서 **채팅에 추가**를 누르면 작성 중인 메시지에 첨부됩니다.

## 켜고 끄기

에이전트 페이지는 기본으로 켜져 있습니다. 끄려면 **설정 → 일반 → OpenChamber 도구**를 열고 **차트와 목업**을 끄세요.

## 참고 사항

- 에이전트 페이지는 [에이전트 제어 도구](/ko/agent-control-tool/)처럼 OpenChamber 자체 OpenCode 서버가 필요합니다.
- VS Code 확장에서는 공유 링크가 일반 텍스트로 남고, 나중에 답하도록 요청받은 페이지는 답변 컨트롤 없이 표시됩니다. 데스크톱 앱이나 웹 앱에서 답하세요.
- 엔터프라이즈 모드에서는 조직 자체 릴레이를 통해서만 공유가 작동합니다. 릴레이가 없으면 에이전트에게 공유 기능이 아예 제공되지 않습니다. [보안](/ko/security/)을 참고하세요.
