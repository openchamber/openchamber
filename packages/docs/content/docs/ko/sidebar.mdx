# 사이드바

사이드바에는 위에서부터 **채팅**, 고정한 것이 있으면 **고정됨**, **작업 중**, 그리고 프로젝트가 차례로 표시됩니다. 모든 것을 시간순으로 한 목록에서 보려면 사이드바 표시 메뉴의 **세션**에서 **시간순**을 고르세요. **프로젝트별**을 고르면 프로젝트별 보기로 돌아갑니다.

## 한 행이 하나의 작업

- **프로젝트 폴더에 있는 세션**은 한 행입니다. 하위 에이전트, 자동 리뷰, 곁가지 질문처럼 그 세션에서 파생된 것은 왼쪽 화살표를 펼치면 그 아래에 있습니다. 단순한 포크는 별도의 행입니다.
- **worktree**는 프로젝트 아래의 한 행이고, 그 안의 모든 세션이 그 아래에 들어갑니다. 행을 클릭하면 그곳에서 마지막으로 작업한 세션이 열리고, 화살표를 클릭하면 모든 세션이 보입니다. [Worktree 세션](/ko/worktrees/)을 참고하세요.
- **격리 공간**도 worktree와 같은 방식으로 동작합니다.

## 행에 표시되는 것

행의 왼쪽을 보면 무엇인지 알 수 있습니다.

- 브랜치 아이콘: worktree
- 공간 아이콘: 격리 공간
- 아무것도 없거나 화살표: 프로젝트 폴더에 있는 세션

행의 오른쪽은 지금 무슨 일이 일어나는지 보여 줍니다. 실행 중, 새 답변, 또는 입력 대기입니다. 끝에 있는 색깔 표시는 작업이 따라가는 풀 리퀘스트나 이슈입니다.

## worktree 이름

worktree 행에는 작업 이름이 표시되며, 작업이 분명해지면 에이전트가 이름을 붙입니다. 그 전에는 브랜치가 표시됩니다. 직접 이름을 바꾸면 그 이름이 유지됩니다. 새 worktree로 옮긴 세션은 작업 이름을 그대로 가져갑니다.

worktree를 브랜치로 보려면 표시 메뉴에서 **worktree를 브랜치 이름으로 표시**를 켜세요. 브랜치가 행의 이름이 되고, 작업 이름은 자세한 행에서 그 아래로 이동합니다.

## 작업 중과 고정됨

**작업 중**에는 아직 끝내지 않은 작업이 모입니다. [작업 중인 세션](/ko/sessions-in-work/)을 참고하세요. 이곳의 작업은 프로젝트에서 빠지므로, 두 곳 모두에 두려면 **진행 중인 작업을 프로젝트 아래에도 표시**를 켜세요. **고정됨**에는 행 메뉴에서 고정한 세션과 worktree가 모입니다.

## 표시 메뉴

- **세션**: 프로젝트별 또는 시간순
- **프로젝트 정렬**: 수동, A → Z, Z → A 또는 최신순
- **채팅 섹션 표시**, **고정됨 섹션 표시**, **작업 중 섹션 표시**
- **진행 중인 작업을 프로젝트 아래에도 표시**
- **자세한 행**: 브랜치나 작업 이름, 풀 리퀘스트나 이슈, 목록에 여러 프로젝트가 섞여 있을 때는 프로젝트를 보여 주는 두 번째 줄
- **worktree를 브랜치 이름으로 표시**
- **모두 접기**와 **모두 펼치기**

긴 목록 끝에는 **더 보기**가 있습니다. **접기**를 누르면 다시 접힙니다.

## 휴대폰에서

목록과 메뉴는 같습니다. **자세한 행**을 끄지 않는 한 행은 두 줄로 표시되며, 행을 옆으로 밀면 동작이 나타납니다.

VS Code는 이 레이아웃 이전의 목록을 그대로 씁니다.
