# 설치

작업 방식에 맞는 앱을 고르세요.

- macOS, Windows, Linux용 데스크톱 앱
- CLI가 실행하는 웹 앱으로, 휴대폰 앱처럼 설치할 수 있습니다(PWA)
- VS Code 확장, Cursor·Windsurf·Trae에서도 사용 가능
- iPhone과 Android용 모바일 앱, 공개 베타

## 데스크톱

[다운로드 페이지](https://openchamber.dev/download/)나 [GitHub Releases](https://github.com/openchamber/openchamber/releases/latest)에서 최신 버전을 받아 여세요. Linux용은 `.deb`, `.rpm`, AppImage로 제공됩니다.

데스크톱 앱에는 [OpenCode](https://opencode.ai)(OpenChamber가 기반으로 하는 AI 코딩 에이전트)가 함께 들어 있어서 따로 설치할 것이 없습니다.

## 웹 + PWA

웹 앱을 실행하는 머신에는 [OpenCode](https://opencode.ai)와 Node.js 24.14 이상이 필요합니다.

```bash
curl -fsSL https://raw.githubusercontent.com/openchamber/openchamber/main/scripts/install.sh | bash
openchamber --ui-password be-creative-here
```

CLI가 출력한 URL(보통 `http://localhost:3000`)을 여세요. OpenChamber 세션 목록이 보이면 됩니다. 자주 쓰려면 브라우저 주소창의 "설치" 옵션으로 앱처럼 추가하세요.

## VS Code

[VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=fedaykindev.openchamber)에서 OpenChamber를 설치하세요. Cursor, Windsurf, Trae에서는 [Open VSX](https://open-vsx.org/extension/FedaykinDev/openchamber)에서 설치합니다. 확장을 쓰려면 [OpenCode](https://opencode.ai)가 설치되어 있어야 하며, 설치하면 사이드바에 OpenChamber 뷰가 열립니다.

## 모바일

TestFlight로 iPhone 앱을, 최신 릴리스에서 Android 앱을 설치한 뒤 컴퓨터와 페어링하세요. [모바일 앱 & PWA](/ko/mobile/)에서 두 단계를 모두 안내합니다.
