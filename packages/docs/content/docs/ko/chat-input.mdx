# 채팅 입력

채팅 상자는 몇 가지 기호를 알아봅니다. 하나를 입력하면 선택기가 열립니다. 항목을 고르거나 계속 입력해 걸러내세요. 기호는 단어의 시작에서만 인식되고, 명령은 메시지 맨 앞에 와야 합니다.

| 입력 | 선택 | 적용 위치 |
| --- | --- | --- |
| `/` | 명령 | 메시지 맨 앞 |
| `$` | 스킬 | 어디서나 |
| `#` | 스니펫 | 어디서나 |
| `@` | 파일 또는 에이전트 | 어디서나 |

가지고 있지 않은 것을 가리키는 기호는 그냥 일반 텍스트로 남습니다. `$5`는 그냥 금액이고 `a/b`는 그냥 경로입니다.

## Commands

명령은 `/review`처럼 슬래시로 실행하는 저장된 프롬프트입니다. **Settings → Commands**에서 관리합니다.

1. **Settings → Commands**를 열고 명령을 만듭니다.
2. 이름, 설명, 보낼 프롬프트 텍스트를 지정합니다.
3. 필요하다면 특정 에이전트나 모델에 고정합니다.
4. personal 또는 project 범위를 선택합니다.

채팅에서 메시지의 **첫** 글자로 `/`를 입력하면 명령이 나타나며, 그중 하나를 선택합니다. 텍스트에는 플레이스홀더를 사용할 수 있습니다.

- `$ARGUMENTS`: 명령 뒤에 입력한 내용
- `@filename`: 파일의 내용을 삽입
- `` !`command` ``: 셸 명령의 출력을 삽입

내장된 `init`과 `review` 명령은 초기화할 수 있지만 삭제할 수는 없습니다. OpenChamber에는 `/explore`, `/summary` 같은 명령도 있습니다. 전체 목록은 [Magic Prompts](/ko/magic-prompts/)를 참고하세요.

## 스킬

메시지 어디서나 `$`를 입력하면 스킬 선택기가 열립니다. 하나를 고르면 에이전트가 그 응답에 해당 스킬의 지침을 불러옵니다. 직접 만들려면 [스킬](/ko/skills/)을 참고하세요.

명령과 스킬은 선택기가 따로 있습니다. 맨 앞의 `/`는 스킬을 나열하지 않고, `$`는 명령을 나열하지 않습니다.

## Snippets

스니펫은 `#signoff`처럼 해시태그로 인라인에서 참조하는 재사용 가능한 텍스트입니다. **Settings → Snippets**에서 관리합니다.

1. **Settings → Snippets**를 열고 스니펫을 만듭니다.
2. 이름과 대체할 텍스트를 지정합니다. 트리거를 여러 개 두려면 별칭을 추가합니다.
3. personal 또는 project 범위를 선택합니다.

채팅에서 `#`를 입력하고 스니펫을 선택합니다. OpenChamber가 보내기 전에 전체 텍스트로 바꿔 넣습니다.

## 파일과 에이전트

`@`를 입력해 파일을 첨부하거나 다른 에이전트로 메시지를 실행합니다.

- `@src/index.ts` 같은 파일은 **+** 메뉴에서 고른 것과 같은 방식으로 메시지에 첨부됩니다. 이미지와 문서는 읽혀서 함께 전송됩니다.
- `@build` 같은 에이전트는 이 메시지를 그 에이전트로 실행합니다. 멘션이 없으면 composer에서 선택한 에이전트가 실행합니다.

## 파일과 컨텍스트 첨부

채팅 상자 옆의 **+** 메뉴는 파일 외에도 첨부합니다.

- 컴퓨터의 파일
- 저장소의 이슈와 풀 리퀘스트 (GitHub, GitLab, Gitea, Gerrit 중 프로젝트를 호스팅하는 곳)
- Linear가 연결되어 있으면 Linear 이슈
- 첨부를 제공하는 설치된 [확장](/ko/extensions/)의 작업

각 항목은 다음 메시지와 함께 컨텍스트로 전달됩니다. 무엇을 할지는 메시지가 정합니다. 이미지를 붙여넣거나 파일을 채팅 상자에 바로 끌어다 놓을 수도 있습니다.

## 셸 명령 실행

메시지를 `!`로 시작하면 OpenChamber가 이를 셸 명령으로 실행하며, 에이전트에는 아무것도 보내지 않습니다. **Esc**를 누르거나 빈 상자가 될 때까지 지우면 셸 모드를 벗어납니다.

## 키보드

- **Enter**는 전송하고 **Shift+Enter**는 새 줄을 시작합니다. **Settings → Chat**에서 서로 바꿀 수 있어, Enter는 줄을 바꾸고 **Ctrl/Cmd+Enter**가 전송합니다. Ctrl/Cmd+Enter는 항상 전송합니다.
- **ArrowUp**과 **ArrowDown**은 이전 메시지를 불러옵니다.
- 선택기가 열려 있으면 **Ctrl+N**과 **Ctrl+P**로 이동하고 **Enter**나 **Tab**으로 고르며 **Esc**로 닫습니다.

펼친 composer에서는 Enter가 항상 새 줄을 시작하고 **Ctrl/Cmd+Enter**가 전송합니다.

휴대폰에서는 Enter가 항상 새 줄을 시작합니다. 전송 버튼이나 **Ctrl/Cmd+Enter**로 전송합니다.
