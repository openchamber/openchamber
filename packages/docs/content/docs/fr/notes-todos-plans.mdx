# Notes, todos et plans de projet

Chaque projet a son propre espace de brouillon pour les notes, une todo list et les plans enregistrés. Ils appartiennent au projet, pas à une session particulière, donc ils restent disponibles lorsque vous passez d’une session à l’autre. Retrouvez-les dans l’onglet **Contexte** de la barre latérale droite (un onglet dédié sur mobile).

## Notes

Une zone de notes libre pour tout ce que vous voulez retenir sur le projet. Elle s’enregistre toute seule pendant que vous tapez.

## Todos

Une checklist simple. Ajoutez des éléments, cochez-les, réordonnez-les par glisser-déposer et supprimez ceux qui sont terminés.

Chaque todo possède un menu **envoyer** pour la confier à l’agent :

- l’envoyer à la session actuelle
- démarrer une nouvelle session avec elle
- démarrer une nouvelle [session worktree](/worktrees/) avec elle (uniquement si le projet est un dépôt git)

## Plans

Un endroit pour conserver des plans plus longs sous forme de fichiers enregistrés. Vous pouvez :

- importer un plan depuis un fichier Markdown ou texte
- ouvrir un plan pour le lire dans le panneau latéral
- supprimer les plans dont vous n’avez plus besoin

Vous devriez revenir dans l’onglet Contexte avec votre note enregistrée, votre todo cochée ou votre plan listé — c’est le signe que l’action a réussi.

Un agent peut lier une note ou une todo à un plan et faire dépendre une todo d’autres todos du même plan ; une todo sans plan n’a pas de dépendances. Il peut demander les todos prêtes, c’est-à-dire les todos non terminées dont toutes les dépendances sont terminées. Supprimer une todo la retire des dépendances des autres todos, et supprimer un plan détache ses notes et ses todos. Un agent peut aussi définir ou retirer la session liée à un plan.

## Notes et tâches dans le dépôt

Les notes et les tâches sont enregistrées dans les données d'OpenChamber sur cette machine. Pour les synchroniser avec Git, ouvrez **Settings → Projects**, choisissez le projet et activez **Garder les notes et tâches dans le dépôt** dans l'onglet General. Elles sont alors enregistrées dans `.openchamber/notes-todos.json` ; committez ce fichier comme n'importe quel autre. L'option ne vaut que pour cette machine : activez-la sur chaque machine qui doit utiliser le fichier.

Changer de réglage ne copie rien. Les notes et tâches d'avant reviennent quand vous désactivez l'option, et le fichier reste dans le dépôt. Les plans ne font pas partie du fichier ; pour partager un plan, déplacez-le dans le dossier des plans du dépôt. Si le fichier a un conflit Git, le panneau ne peut ni charger ni enregistrer les notes et tâches tant que vous ne l'avez pas corrigé.
