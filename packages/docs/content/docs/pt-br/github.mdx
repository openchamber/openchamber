# Issues e PRs do GitHub

Conecte sua conta do GitHub e o OpenChamber pode trazer issues e pull requests, iniciar uma sessão direto a partir de uma delas e abrir ou atualizar PRs para você.

## Conectar o GitHub

1. Abra **Settings → Integrations** e expanda o cartão **GitHub**.
2. Escolha **Connect GitHub**. O OpenChamber mostra um link e um código curto.
3. Abra o link, insira o código e aprove.

Quando estiver conectado, sua conta aparece no cartão. Você pode conectar mais de uma conta e alternar entre elas, ou desconectar a qualquer momento. Se a CLI `gh` estiver logada na mesma máquina, o OpenChamber pode usá-la como alternativa.

## Começar o trabalho a partir de uma issue ou PR

Quando você cria uma [sessão de worktree](/pt-br/worktrees/) com o GitHub conectado, pode iniciá-la a partir de uma issue ou de um pull request:

- escolha uma **issue** e o OpenChamber nomeia o branch a partir dela
- escolha um **pull request** e ele faz checkout do branch do PR; você pode incluir o diff do PR para que o agente tenha a mudança completa

A nova sessão abre com a issue ou o PR já anexado à caixa de mensagem. Nada é enviado por você: escolha o modelo e o agente, diga o que quer que seja feito e envie.

## Abrir e gerenciar pull requests

Pela aba **PR** na [visão de git](/pt-br/git/), você pode criar um pull request, atualizá-lo, marcar um rascunho como pronto ou fazer merge. O OpenChamber pode gerar o título e a descrição do PR a partir das suas mudanças.

## Vincule uma issue ou PR a uma mensagem

No compositor do chat, abra o menu **+** e escolha **GitHub**. Escolha uma ou mais issues ou pull requests: cada um acompanha sua próxima mensagem como contexto (um PR pode trazer seu diff), e o painel de status de trabalho da sessão mantém um link para ele. Anexar só adiciona contexto; é a sua mensagem que diz o que fazer com ele.
