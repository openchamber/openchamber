# Entrada do chat

A caixa de chat entende alguns símbolos. Digite um e um seletor se abre; escolha um item ou continue digitando para filtrá-lo. Um símbolo só conta no início de uma palavra, e um comando precisa iniciar a mensagem.

| Digite | Escolhe | Funciona |
| --- | --- | --- |
| `/` | um comando | logo no início da mensagem |
| `$` | uma skill | em qualquer lugar |
| `#` | um snippet | em qualquer lugar |
| `@` | um arquivo ou um agente | em qualquer lugar |

Um símbolo que não nomeia nada que você tenha continua texto comum: `$5` é só dinheiro e `a/b` é só um caminho.

## Comandos

Um comando é um prompt salvo que você executa com uma barra, como `/review`. Gerencie-os em **Settings → Commands**.

1. Abra **Settings → Commands** e crie um comando.
2. Dê a ele um nome, uma descrição e o texto do prompt que ele deve enviar.
3. Opcionalmente, fixe-o em um agente ou modelo específico.
4. Escolha o escopo personal ou project.

No chat, digite `/` como o **primeiro** caractere da mensagem para abrir os comandos e escolha um. Seu texto pode usar marcadores:

- `$ARGUMENTS`: o que você digitar depois do comando
- `@filename`: insere o conteúdo de um arquivo
- `` !`command` ``: insere a saída de um comando de shell

Os comandos integrados `init` e `review` podem ser redefinidos, mas não excluídos. O OpenChamber também inclui comandos como `/explore` e `/summary`; veja [Magic Prompts](/pt-br/magic-prompts/) para a lista completa.

## Skills

Digite `$` em qualquer lugar da mensagem para abrir o seletor de skills e escolha uma. O agente carrega as instruções dessa skill para a resposta. Veja [Skills](/pt-br/skills/) para escrever a sua.

Comandos e skills têm seletores separados, então uma `/` no início nunca lista skills e um `$` nunca lista comandos.

## Snippets

Um snippet é um texto reutilizável que você referencia inline com uma cerquilha, como `#signoff`. Gerencie-os em **Settings → Snippets**.

1. Abra **Settings → Snippets** e crie um snippet.
2. Dê a ele um nome e o texto que ele representa. Adicione aliases se quiser mais de um gatilho.
3. Escolha o escopo personal ou project.

No chat, digite `#` e escolha um snippet. O OpenChamber substitui pelo texto completo antes de enviar.

## Arquivos e agentes

Digite `@` para anexar um arquivo ou executar a mensagem com outro agente.

- Um arquivo, como `@src/index.ts`, é anexado à mensagem assim como escolhê-lo no menu **+**. Imagens e documentos são lidos e enviados com ela.
- Um agente, como `@build`, executa esta mensagem com esse agente. Sem menção, quem a executa é o agente selecionado no composer.

## Anexar arquivos e contexto

O menu **+** ao lado da caixa de chat anexa mais do que um arquivo:

- arquivos do seu computador
- issues e pull requests do seu repositório (GitHub, GitLab, Gitea, Forgejo ou Gerrit, onde quer que o projeto esteja hospedado)
- issues do Linear, quando o Linear está conectado
- tarefas de [extensões](/pt-br/extensions/) instaladas que oferecem anexar

Cada item viaja junto com sua próxima mensagem como contexto; sua mensagem decide o que fazer com ele. Você também pode colar uma imagem ou arrastar um arquivo direto para a caixa de chat.

## Executar um comando de shell

Comece a mensagem com `!` e o OpenChamber a executa como comando de shell, sem enviar nada ao agente. Pressione **Esc**, ou apague até a caixa ficar vazia, para sair do modo shell.

## Teclado

- **Enter** envia e **Shift+Enter** inicia uma nova linha. Em **Settings → Chat** você pode invertê-los, de modo que Enter quebra a linha e **Ctrl/Cmd+Enter** envia. Ctrl/Cmd+Enter sempre envia.
- **ArrowUp** e **ArrowDown** recuperam suas mensagens anteriores.
- Com um seletor aberto, **Ctrl+N** e **Ctrl+P** navegam por ele, **Enter** ou **Tab** escolhe e **Esc** o fecha.

No composer expandido, Enter sempre inicia uma nova linha e **Ctrl/Cmd+Enter** envia.

No celular, Enter sempre inicia uma nova linha. O botão de enviar ou **Ctrl/Cmd+Enter** envia.
