# Túneles de escritorio

La app de escritorio puede crear un túnel desde **Settings → OpenChamber → Tunnel**. No necesitas iniciar OpenChamber desde el CLI para este flujo.

## Instala un proveedor

OpenChamber inicia el CLI del proveedor en tu máquina. Instala primero el proveedor que quieras usar:

```bash
brew install cloudflared
brew install ngrok
```

Cloudflare usa `cloudflared`. Ngrok requiere una cuenta de ngrok y un authtoken del panel de ngrok:

```bash
ngrok config add-authtoken <your-ngrok-token>
```

Para Tailscale, instala la [app de Tailscale](https://tailscale.com/download) e inicia sesión.

## Inicia desde la app

1. Abre **Settings → OpenChamber → Tunnel**.
2. Elige **Cloudflare**, **Ngrok** o **Tailscale**.
3. Elige el tipo de túnel y selecciona **Iniciar túnel**.
4. Escanea el código QR generado desde tu teléfono.

Ngrok actualmente soporta quick tunnels. Cloudflare soporta quick tunnels y modos gestionados de Cloudflare. Tailscale ofrece **Serve**, que solo pueden abrir los dispositivos de tu tailnet, y **Funnel**, que puede abrir cualquiera en internet. Si Tailscale necesita primero que actives HTTPS o Funnel en tu tailnet, junto al error aparece el botón **Abrir página de aprobación**; aprueba allí e inicia de nuevo.

## Protección de acceso

Aunque la URL del proveedor sea pública, OpenChamber sigue protegiendo el acceso con su propio connect token. El enlace generado contiene un token de un solo uso, tiene TTL, y los enlaces antiguos sin usar se revocan cuando generas uno nuevo o detienes/reinicias el túnel.
