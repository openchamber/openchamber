# Identidades de Git

Una identidad de git es el nombre y el correo que llevan tus commits, y la forma en que un repositorio inicia sesión en su remoto. Si trabajas en repos personales y de trabajo, puedes guardar identidades y aplicar la correcta en cada repositorio. Gestiónalas en **Settings → Git**.

## Añade una identidad

1. Abre **Settings → Git** y elige **New**.
2. Introduce el **Nombre de usuario** y la **Dirección de correo electrónico** con los que harás commit.
3. Elige una **Autenticación**, es decir, cómo hace push y pull:
   - **Este equipo**: lo que ya usa Git en este equipo, como claves SSH, un gestor de credenciales o la CLI `gh`
   - **Cuenta**: la **Cuenta de control de código** que elijas, cualquier cuenta conectada en una tarjeta de host en [Integraciones](/es/integrations/), como GitHub, GitLab, Gitea, Forgejo o Gerrit. Los push van por HTTPS con el token de esa cuenta
   - **SSH**: una clave que OpenChamber guarda para esta identidad
   - **Anónimo**: lee repositorios públicos por HTTPS sin iniciar sesión, y no puede hacer push
4. Opcionalmente, dale un color y un icono para reconocerla fácilmente.

La identidad global de tu sistema también se muestra, como solo lectura.

En Gerrit, una identidad de cuenta inicia sesión en Git con tu usuario de Gerrit y la contraseña HTTP que conectaste. Una cuenta de GitHub Enterprise sirve issues y pull requests, pero clonar y hacer push ahí pasa por **Este equipo** o **SSH**.

## Aplica una identidad a un repo

Elige el botón de identidad arriba del [panel Git](/es/git/) y elige una. Las pantallas de añadir y clonar ofrecen la misma elección. Una identidad que no puede llegar al repositorio sigue en la lista, desactivada y con el motivo: una cuenta de otro host, una cuenta o **Anónimo** en un remoto SSH, o una clave SSH en un remoto HTTPS.

Al aplicar una identidad se escribe en la configuración **local** de git de ese repositorio, así que solo afecta a ese repo y tu ajuste global no cambia. Git en la terminal y la shell del agente también la usan. **Identidad del sistema** quita lo que escribió OpenChamber, y vuelve a responder tu propia configuración de Git.
