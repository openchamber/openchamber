# Проблемы и PR на GitHub

Подключите свой аккаунт GitHub — и OpenChamber сможет подтягивать проблемы и pull request, начинать сессию прямо из одного из них и открывать или обновлять PR за вас.

## Подключение GitHub

1. Откройте **Настройки → Интеграции** и разверните карточку **GitHub**.
2. Выберите **Подключить GitHub**. OpenChamber покажет ссылку и короткий код.
3. Откройте ссылку, введите код и подтвердите.

Когда подключение выполнено, ваш аккаунт отображается на карточке. Вы можете подключить несколько аккаунтов и переключаться между ними или отключиться в любой момент. Если в `gh` CLI выполнен вход на той же машине, OpenChamber может использовать его как запасной вариант.

## Начать работу из проблемы или PR

Когда вы создаёте [сессию worktree](/ru/worktrees/) с подключённым GitHub, вы можете выбрать **Начать с проблемы/PR на GitHub**:

- выберите **проблему**, и OpenChamber назовёт ветку в её честь и откроет сессию с проблемой и её комментариями в качестве первого сообщения
- выберите **pull request**, и он переключится на ветку PR; вы можете включить дифф PR, чтобы у агента было всё изменение целиком

Так вы сразу попадаете в сессию с уже загруженным контекстом.

## Открытие pull request и управление ими

На вкладке **PR** в [представлении git](/ru/git/) вы можете создать pull request, обновить его, отметить черновик как готовый или выполнить слияние. OpenChamber может сгенерировать заголовок и описание PR из ваших изменений.

## Привязка проблемы или PR к сообщению

В поле ввода чата выберите **Привязать проблему GitHub** или **Привязать PR GitHub**. Проблема или PR вместе с его диффом отправятся вместе с вашим следующим сообщением как контекст, а панель состояния работы сессии сохранит ссылку на них. В том же средстве выбора можно начать новую сессию, где проблема станет первым промптом.
