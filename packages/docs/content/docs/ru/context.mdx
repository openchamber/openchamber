# Контекст

Каждая модель может удерживать лишь определённый объём разговора одновременно — свой контекст. OpenChamber показывает, насколько он заполнен, чтобы вы понимали, когда сессия приближается к лимиту и ответ может начать терять более старые детали.

## Быстрый индикатор

Пока вы общаетесь, небольшой индикатор показывает процент использованного контекста. Он меняет цвет по мере заполнения:

- зелёный — много места
- жёлтый — заполняется (около трёх четвертей)
- красный — почти полный

Наведите на него (или коснитесь на мобильном), чтобы увидеть точное количество токенов.

## Полная панель контекста

Откройте вкладку **Контекст** в правой боковой панели, чтобы увидеть более полную картину текущей сессии:

- используемая модель и когда началась сессия
- общее количество токенов относительно лимита модели
- итоги по сообщениям и стоимости
- разбивка токенов последнего ответа
- примерное распределение того, что занимает контекст (ваши сообщения, сообщения агента, вывод инструментов)

Разбивка — это оценка, а не точный подсчёт; используйте её, чтобы понять, что заполняет окно, а не для выставления счетов.

## Что делать, когда он заполнен

Начинайте новую сессию для новой задачи, а не позволяйте одной сессии расти бесконечно. Более короткий контекст быстрее и помогает модели оставаться сосредоточенной.
