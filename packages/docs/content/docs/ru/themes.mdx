# Темы

OpenChamber поддерживает встроенные темы и собственные JSON-файлы тем.

## Импорт темы VS Code

Откройте **Настройки → Оформление → Импорт темы VS Code**, чтобы выполнить поиск по Open VSX. В результатах показаны значок, название и автор. Выберите пакет, сравните предпросмотры его цветов и импортируйте нужные варианты. Пакетный импорт сохраняет текущую тему активной. Open VSX — отдельный каталог; темы, опубликованные только в Microsoft Marketplace, могут не появиться.

Используйте **Выбрать JSON-файл** для локального файла `.json` или `.jsonc` размером до 512 КиБ. Десктоп открывает локальную папку `~/.vscode/extensions`, если она существует. OpenChamber преобразует цвета интерфейса, общей подсветки синтаксиса и диффов, а затем выбирает тему файла и светлый или тёмный режим. Значок корзины рядом с импортированной темой в выпадающем списке удаляет её с подключённого сервера. Удаление выбранной темы восстанавливает значение по умолчанию для этого режима.

Тема сохраняется на подключённом сервере OpenChamber, в том числе при импорте с десктопа или мобильного. Повторный импорт того же файла не создаёт дубликат и не перезаписывает тему, отредактированную на сервере. Расширение VS Code вместо этого следует собственной теме VS Code.

Если файл использует `include` или ссылается на отдельный файл токенов, выполните **Developer: Generate Color Theme From Current Settings** в палитре команд VS Code и импортируйте созданный JSON.

## Добавление своей темы

1. Создайте папку тем:

```bash
mkdir -p ~/.config/openchamber/themes
```

2. Добавьте в эту папку свой JSON-файл (например `my-theme.json`).
3. Откройте OpenChamber и перейдите в **Настройки -> Тема -> Перезагрузить темы**.
4. Выберите свою тему в выпадающем списке. Она применяется сразу же.

## Где лежит тема

- macOS/Linux: `~/.config/openchamber/themes/`
