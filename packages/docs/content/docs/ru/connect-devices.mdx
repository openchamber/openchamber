# Подключение устройства

Свяжите другое устройство — мобильное приложение, десктопное приложение или браузер на другой машине — со своим сервером OpenChamber, отсканировав одноразовый QR-код. Это рекомендуемый способ подключать устройства: не нужно открывать порты и вводить адреса.

## Как связать устройство

1. На машине, где запущен OpenChamber, откройте **Настройки → Удалённые экземпляры → Подключиться к этому серверу** и нажмите **Добавить устройство**.
2. Дайте устройству имя (например, *Мой iPhone*), чтобы потом его узнать.
3. Выберите, где вы будете использовать устройство:
   - **Только этот компьютер** — для приложений на этой же машине
   - **Только домашняя сеть** — подключается напрямую через ваш Wi-Fi; не работает вне этой сети
   - **Где угодно** — работает дома и вне дома; вне дома трафик идёт через [Private Relay](/ru/private-relay/), сквозной зашифрованный туннель, не требующий настройки
4. Нажмите **Создать QR-код**.
5. На другом устройстве отсканируйте код:
   - **мобильное приложение** — коснитесь **Сканировать QR-код** на экране подключения (или в списке экземпляров)
   - **десктопное приложение** — вместо этого скопируйте ссылку подключения и вставьте её в **Настройки → Удалённые экземпляры → Другие серверы OpenChamber → Импортировать ссылку**

Диалог закрывается сам, как только устройство подключается, и устройство появляется в списке с живым статусом. Вот и всё — устройства связаны.

## Почему это безопасно

- **QR-код одноразовый.** Он перестаёт работать, как только какое-то устройство его использовало, и сам истекает, если не был использован.
- **Каждое устройство получает свой токен.** Сканирование кода никогда не раскрывает ваш пароль UI, а токен одного устройства нельзя использовать, чтобы выдать себя за другое.
- **Контроль остаётся у вас.** Каждое связанное устройство показано в списке с именем, платформой и статусом подключения — любое можно отозвать в любой момент.
- **Трафик вне дома защищён сквозным шифрованием.** С опцией **Где угодно** трафик за пределами вашей сети идёт через [Private Relay](/ru/private-relay/), который не может прочитать то, что через него проходит.

## Управление связанными устройствами

**Настройки → Удалённые экземпляры → Подключиться к этому серверу** показывает каждое устройство, которое может добраться до этого сервера, с зелёной точкой, когда оно онлайн, и пометкой, подключено ли оно через локальную сеть или через relay.

- **Отозвать** мгновенно отключает устройство. Если передумаете — свяжите его снова новым QR-кодом.
- **Очистить отозванные** убирает лишнее из списка.

Одно и то же физическое устройство сохраняет одну запись, даже если позже подключится снова — дубликаты не накопятся.

## Подключение из командной строки

Если сервер работает headless (без открытого UI), создайте ссылку подключения из терминала на той машине.

Для устройства в той же сети:

```bash
openchamber connect-url --port 3000 --qr
```

Для устройства, которое должно подключаться **откуда угодно** — это равносильно выбору **Где угодно** в диалоге:

```bash
openchamber connect-url --relay --qr
```

Ссылка с `--relay` содержит оба маршрута, как и диалог: устройство подключается напрямую через вашу локальную сеть, когда может добраться до сервера, и переключается на [Private Relay](/ru/private-relay/), когда вы вне дома. Relay запускается сам: запущенный экземпляр подхватывает ссылку в течение минуты, остановленный — при следующем запуске.

> Прямой маршрут работает, только если сервер действительно слушает вашу сеть. По умолчанию OpenChamber слушает только саму машину — запустите его с `--lan`, чтобы он был доступен по Wi-Fi. Команда предупреждает вас (`[LAN_UNREACHABLE]`), когда прямым маршрутом ссылки не смогут воспользоваться другие устройства; ссылка с `--relay` тогда всё равно работает, просто всегда через relay.

Напечатанная ссылка и QR-код работают точно так же, как те, что из диалога настроек — одноразовые, с истечением срока, с возможностью отзыва.
