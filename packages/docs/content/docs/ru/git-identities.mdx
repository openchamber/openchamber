# Git-идентичности

Git-идентичность — это имя и email, которыми подписываются ваши коммиты. Если вы работаете и с личными, и с рабочими репозиториями, вы можете сохранить идентичности и применять нужную для каждого репозитория, вместо того чтобы полагаться на одну глобальную настройку. Управляйте ими в **Настройки → Git**.

## Добавление идентичности

1. Откройте **Настройки → Git** и выберите **Создать**.
2. Укажите **имя** и **email**, которыми коммитить.
3. Выберите, как она аутентифицируется на удалённом сервере:
   - **SSH** — укажите SSH-ключ
   - **token** — используйте сохранённые учётные данные для хоста
4. При желании задайте цвет и значок, чтобы её было легко найти.

Глобальная идентичность вашей системы тоже показана, только для чтения.

## Применение идентичности к репозиторию

Применение идентичности записывает её в **локальный** git-конфиг этого репозитория — это влияет только на этот репозиторий, а не на вашу глобальную настройку. SSH-идентичности также задают команду SSH для использования вашего ключа; token-идентичности настраивают хранилище учётных данных для хоста.

Вы можете импортировать идентичности, которые OpenChamber находит в ваших существующих git-учётных данных, и сохранить их как token-идентичности.
