# Документация OpenChamber

OpenChamber — это визуальная рабочая область вокруг OpenCode (AI-агента для программирования, который работает в вашем терминале). Он даёт экран, где можно наблюдать за этой работой и управлять ею, вместо того чтобы жить в командной строке.

Используйте эту документацию, чтобы:

- установить приложение, подходящее вашему способу работы
- безопасно открыть OpenChamber для удалённого использования
- настроить внешний вид и устранять типичные проблемы

## Для чего нужен OpenChamber

OpenChamber нужен для тех частей AI-программирования, которым полезен командный центр: ветвление сессий, просмотр диффов, управление терминалами, наблюдение за прогрессом инструментов, запуск действий проекта и сохранение всей картины перед глазами, пока агент работает.
