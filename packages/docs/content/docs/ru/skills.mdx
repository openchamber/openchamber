# Навыки

Навык — это многоразовый набор инструкций, который агент может подключить, когда он уместен, — например, «как мы пишем сообщения коммитов» или «наши соглашения по API». Управлять ими можно в **Настройки → Навыки**.

Чтобы установить готовые навыки вместо того, чтобы писать свои, см. [Каталог навыков](/ru/skills-catalog/).

## Создание навыка

1. Откройте **Настройки → Навыки**.
2. Создайте навык и дайте ему имя и короткое описание. По описанию агент решает, когда навык применим, поэтому делайте его конкретным.
3. Напишите инструкции. Добавьте вспомогательные файлы, если они нужны навыку.
4. Выберите, где он живёт:
   - **personal** — доступен в каждом проекте
   - **project** — доступен только в текущем проекте

## Использование навыка в чате

Введите `/` в середине сообщения, чтобы открыть выбор навыка, и выберите нужный. Агент подключает инструкции этого навыка для ответа.

`/` в самом начале сообщения вместо этого открывает [команды](/ru/commands-snippets/).
