# Удалённые экземпляры

Десктопное приложение может подключаться к OpenChamber, запущенному на другой машине, через SSH — рабочий сервер, облачная машина, домашняя лаборатория — и выводить его интерфейс на ваш экран так, будто он локальный. Настройте это в разделе **Настройки → Удалённые экземпляры**.

> Удалённые экземпляры — функция **только для десктопа**. В вебе или в VS Code подключайтесь к удалённому серверу с помощью переменных окружения из раздела [Сервер OpenCode](/ru/opencode-server/).

## Добавление удалённого экземпляра

1. Откройте **Настройки → Удалённые экземпляры** и добавьте один.
2. Укажите SSH-команду, которой вы обычно пользуетесь для доступа к машине, и короткое имя.
3. Выберите, как OpenChamber работает там:
   - **Запускать за меня** — OpenChamber сам устанавливается и запускается на удалённой машине
   - **Уже запущен** — подключиться к тому, что уже работает
4. Подключитесь.

OpenChamber проходит шаги — проверяет соединение, настраивает удалённую машину, запускает сервер и перенаправляет порт — и показывает, на каком из них он находится. Когда он доходит до **Готово**, удалённый интерфейс загружается локально.

## Учётные данные

Вы решаете, сохранять ли пароли SSH и интерфейса или вводить их каждый раз. Если соединение обрывается, OpenChamber сообщает, какой шаг не удался, чтобы вы могли это исправить — см. [Удалённый доступ](/ru/troubleshooting/remote-access/).

## Ссылки для подключения

Если на удалённой машине уже работает OpenChamber, самый простой способ подключить десктопное приложение — ссылка для сопряжения. В интерфейсе удалённого сервера откройте **Настройки → Удалённые экземпляры → Подключиться к этому серверу → Добавить устройство**, создайте ссылку и импортируйте её на своём десктопе в разделе **Настройки → Удалённые экземпляры → Другие серверы OpenChamber → Импортировать ссылку**. Полный порядок действий см. в разделе [Подключение устройства](/ru/connect-devices/).

Ссылка, созданная с параметром **Где угодно**, содержит и прямой адрес, и маршрут через [Private Relay](/ru/private-relay/): десктоп подключается напрямую, когда может дотянуться до сервера (та же сеть), и переходит на ретранслятор со сквозным шифрованием, когда вы не рядом. Статус рядом с каждым сохранённым сервером показывает, какой маршрут используется.

Ссылку также можно создать из терминала на удалённой машине:

```bash
openchamber connect-url --port 3000 --server http://your-host:3000 --qr
```

`connect-url` сначала запускает сервер, если на этом порту ничего не работает. Добавьте `--api-only` для сервера без интерфейса, `--lan`, чтобы при запуске привязаться к локальной сети, `--ui-password`, чтобы защитить доступ из браузера, и `--name`, чтобы задать имя сохранённого подключения. Добавьте `--relay` для ссылки, которая работает и вне локальной сети: устройство предпочитает прямое подключение, когда сервер доступен, и переходит на [Private Relay](/ru/private-relay/) — экземпляр поднимает ретранслятор сам.

Сгенерированная ссылка содержит одноразовый секрет сопряжения. После импорта устройство хранит собственный клиентский токен — отдельный от пароля интерфейса в браузере — который переживает перезапуски сервера, пока вы не отзовёте его на сервере, который его выдал.
