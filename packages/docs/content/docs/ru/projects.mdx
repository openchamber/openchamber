# Проекты

Проект — это папка на вашем компьютере, за которой следит OpenChamber, обычно одна кодовая база. Переключение проектов меняет папку, в которой работает агент, вместе с сессиями и настройками этого проекта.

## Добавление проекта

Добавить проект можно из нескольких мест:

- пункт **Добавить проект** в палитре команд
- кнопка **+** вверху боковой панели сессий
- браузер папок, когда вы выбираете каталог

Укажите папку, и OpenChamber запомнит её. Имя берётся из папки; вы можете изменить его позже.

## Переключение проектов

Выберите проект в боковой панели, чтобы сделать его активным. Всё — сессии, git, заметки — следует за открытым проектом.

## Сделайте проект узнаваемым

Откройте **Настройки → Проекты**, чтобы задать проекту своё имя, цвет или значок. OpenChamber пытается найти значок автоматически — см. [Значки проектов](/ru/project-icons/).

> В VS Code OpenChamber всегда использует открытую папку как единственный проект, поэтому добавлять или переключать нечего. Страница настроек проектов там скрыта.
