# Обновления

То, как вы обновляете OpenChamber, зависит от того, как вы его установили. В любом случае вы можете проверить текущую версию в разделе **Настройки → OpenChamber → О программе**.

## Десктопное приложение

Десктопное приложение проверяет обновления по релизам GitHub. Когда обновление доступно, OpenChamber сообщает вам о нём, скачивает его, когда вы выберете, и устанавливает при следующем перезапуске. Вы всегда всё контролируете — ничего не устанавливается без вашего согласия.

## Веб / CLI

Если вы установили CLI, обновите его из раздела **О программе** кнопками проверки и обновления или из терминала:

```bash
openchamber update
```

OpenChamber определяет, как он был установлен (npm, pnpm, yarn или bun), и запускает нужное обновление за вас.

## Сервер OpenCode

OpenChamber и OpenCode обновляются отдельно. Когда доступна новая версия OpenCode, OpenChamber предлагает обновить её и после этого перезапускает сервер. См. [Сервер OpenCode](/ru/opencode-server/), чтобы узнать, как управляется этот сервер.
