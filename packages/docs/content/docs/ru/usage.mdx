# Использование и квоты

Страница «Использование» показывает, сколько из плана каждого провайдера вы потратили, чтобы вы видели, насколько близко вы к лимиту. Откройте её в **Настройки → Использование**.

## Что вы видите

Для каждого подключённого провайдера OpenChamber показывает:

- сколько из текущего окна вы использовали, в виде полосы
- разбивку по моделям
- индикатор темпа, чтобы понять, успеете ли вы израсходовать лимит

Вы можете выбрать, какие провайдеры отображаются, и такая же сводка доступна из выпадающего меню в шапке приложения.

## Поддерживаемые провайдеры

Использование работает для провайдеров, которые публикуют квоту, в том числе Claude, Codex, GitHub Copilot, Google, OpenRouter, Kimi, NanoGPT, z.ai, Zhipu, MiniMax, Ollama Cloud и Wafer.

Провайдер показывает использование только после того, как вы вошли в него на странице [Провайдеры](/ru/providers/). Некоторым провайдерам нужен дополнительный шаг — например, Ollama Cloud читает файл сессии, который вы настраиваете отдельно. Если провайдер не показывает данных, обычно это означает, что не хватает этих дополнительных учётных данных.
