# Обзорный тур по изменениям

Дифф упорядочен по путям файлов, а это почти никогда не тот порядок, в котором изменение обретает смысл. Обзорный тур перестраивает его: связанные правки собираются в **шаги**, каждый шаг объясняет, что именно код теперь делает иначе, а сами шаги идут так, что каждый опирается на предыдущий.

Он объясняет и упорядочивает. Он не оценивает ваш код и не выносит вердиктов — для этого есть [Ревью](/ru/git/).

Откройте его иконкой **Обзорный тур** в правой панели или кнопкой **Обзор с ИИ** в панелях изменений и pull request. Обе лишь открывают панель; ничего не создаётся, пока вы не нажмёте **Создать обзорный тур**.

## Как помечается шаг

Каждый шаг называет, о чём он, объясняет это одним-двумя предложениями, а затем показывает именно тот код, который описывает. У некоторых шагов рядом с заголовком есть небольшая метка:

| Метка | Что она значит |
| --- | --- |
| **Ключевое изменение** | Этот шаг определяет остальную часть изменения или несёт большую часть его риска. Читайте его внимательно и первым. |
| **Контекст** | Вспомогательное изменение, включённое, чтобы остальное обрело смысл. Можно просмотреть по диагонали. |
| *(без метки)* | Обычный шаг в порядке чтения. |

Метка говорит о том, **куда направить внимание**, а не о качестве кода. Шаг никогда не помечается потому, что в нём нашли что-то неверное — обзорный тур не сообщает ни находок, ни степеней серьёзности, ни вердиктов. Если вы хотите, чтобы код оценили, это действие **Ревью** в разделе [Git и GitHub](/ru/git/).

Единственные метки, которые действительно сообщают о проблеме, — это **Устарело** и **Не охвачено**, и обе говорят об устаревании самого обзорного тура, а не о вашем коде — см. ниже.

## Что можно просмотреть

| Область | Что охватывает |
| --- | --- |
| Все незакоммиченные | Всё, что ещё не закоммичено: в индексе, вне индекса и новые файлы |
| В индексе | Только то, что попало бы в коммит прямо сейчас |
| Вне индекса | Рабочее дерево и новые файлы |
| Эта ветка | Каждый коммит этой ветки, которого нет в её базовой ветке |
| Pull request | Изменение в том виде, в каком оно есть на GitHub |

**Эта ветка** — это не «незапушенные коммиты», а всё, что ветка добавляет к своей базовой, запушено оно или нет. Поэтому после коммита, но до пуша, она и pull request намеренно расходятся: одна показывает, что сделали вы, другой — что сейчас видят рецензенты.

Каждая область хранится отдельно, поэтому переключение между ними ничего не теряет.

## Выбор модели

По умолчанию обзорные туры используют вашу малую модель. Выберите другую в разделе **Настройки → Сессии → Модель для обзора изменений** или для одного обзора — в заголовке панели; это полезно, когда изменение достаточно рискованное, чтобы отдать его более сильной модели.

В списке предлагаются только модели, умеющие выдавать структурированный вывод, потому что без него обзорный тур не собрать. Если модель слишком мала для этого диффа, создание отклоняется с пояснением, а не обрезает вход молча: обзорный тур, написанный по половине диффа, звучит уверенно и при этом ошибается.

Если открыть панель заново, будет показана модель, создавшая то, что вы видите, поэтому **Создать заново** повторит той же моделью, пока вы её не смените.

## Выбор языка

По умолчанию обзорные туры пишутся на языке вашего интерфейса. Селектор языка в заголовке панели начинает с него, и для одного обзора можно выбрать любой другой язык, на который переведён OpenChamber — пошаговое объяснение полезно только на языке, который вы читаете свободно.

Переводится только текст. Идентификаторы, пути к файлам и имена API остаются точно такими, как в вашем коде, поэтому то, что называет шаг, по-прежнему можно найти поиском.

Если на выбранном языке ещё ничего не создано, панель не пустеет, а продолжает показывать имеющийся обзорный тур и сообщает об этом. Нажмите **Создать обзорный тур**, чтобы получить его на новом языке.

## Стоимость и кэширование

Ничего не создаётся само. Создание запускается только по вашему запросу, и повторное создание тоже выполняется вручную.

Результаты кэшируются по точному содержимому диффа. Верните рабочее дерево в прежнее состояние — и прежний обзорный тур вернётся бесплатно, без обращения к модели. Язык и модель — часть этого ключа, поэтому каждая комбинация хранится отдельно: как только для диффа есть обзорные туры на двух языках, переключение между ними мгновенно и бесплатно.

Создание выполняется на сервере OpenChamber, а не во вкладке браузера. Перезагрузите страницу или закройте панель — оно продолжится; вернитесь, и результат будет ждать. Останавливает его только нажатие **Отмена**.

## Честность насчёт устаревания

Каждый шаг привязан к точному содержимому кода, который он описывает, поэтому панель может сообщить, когда этот код изменился:

- **Устаревшие шаги** — код, который описывал шаг, изменился или исчез. Обзорный тур всё равно показывается, с меткой, чтобы вы сами решили, создавать ли его заново.
- **Не охвачено** — изменения в текущем диффе, которые не описывает ни один шаг. Сюда входят правки, сделанные после создания, изменения, которые обзорный тур счёл рутинными, а также lock-файлы и другие сгенерированные файлы, которые намеренно не попадают на вход модели. Всё это перечислено в конце потока, чтобы ничего не исчезало молча.

Повторное создание не латает, а переписывает заново: прежний обзорный тур идёт в модель как контекст, поэтому точные части сохраняются, а всё заново привязывается к текущему коду.

## Примечания

- Комментировать можно любую строку в обзорном туре точно так же, как в представлении диффа; комментарии прикрепляются к полю ввода в чате.
- Доступно на настольной и планшетной ширине. Не предлагается в расширении для VS Code и в мобильном приложении.
- Для обзора pull request нужен подключённый аккаунт GitHub — см. [Проблемы и PR на GitHub](/ru/github/).
