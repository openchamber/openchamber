# Worktree и Git

Проблемы, которые возникают с [сессиями worktree](/ru/worktrees/) и [представлением Git](/ru/git/), и как их устранить.

## Worktree требует внимания

OpenChamber помечает worktree, когда что-то не так:

- **папка отсутствует** — папка worktree была удалена или перемещена за пределы OpenChamber; удалите сессию и создайте новый worktree
- **detached-ветка или ветка без коммитов** — worktree не на обычной ветке; переключите его на обычную ветку
- **слияние, rebase или cherry-pick в процессе** — операция осталась незавершённой; завершите или прервите её из представления Git

## Не удаётся создать worktree

- **ветка уже существует** — выберите другое имя ветки или используйте вариант с существующей веткой
- **имя уже используется** — выберите другое имя worktree

## Генерация коммита или PR не удаётся

Генерация сообщения коммита или описания PR выполняется в вашей активной сессии, поэтому нужна открытая сессия с выбранной рабочей моделью. Откройте или выберите сессию и попробуйте снова.

## Проблемы с путями SSH или Windows

- убедитесь, что SSH-ключ, который использует репозиторий, — это тот, что задан в вашей [идентичности Git](/ru/git-identities/)
- в Windows git использует пути в стиле Unix (например, `/c/Users/...`) — OpenChamber с этим справляется, но собственные пути к SSH-ключам должны иметь ту же форму
