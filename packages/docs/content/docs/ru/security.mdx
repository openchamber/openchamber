# Безопасность

OpenChamber даёт доступ к вашей машине и вашему коду, поэтому закройте его, прежде чем до него сможет добраться кто-то кроме вас. Эта страница рассказывает о пароле UI, passkeys и о том, что важно знать, прежде чем открывать OpenChamber в сеть.

## Задайте пароль UI

Запустите OpenChamber с паролем, и браузерный UI будет его запрашивать:

```bash
openchamber --ui-password be-creative-here
```

Также можно задать его переменной окружения `OPENCHAMBER_UI_PASSWORD` вместо того, чтобы указывать в командной строке. После входа OpenChamber какое-то время помнит устройство, чтобы не спрашивать каждый раз.

Всегда задавайте пароль, если до экземпляра может добраться кто-то ещё — особенно через [туннель](/ru/tunnels/) или публичный интернет.

## Passkeys

Когда пароль задан, вы можете добавить passkeys (Face ID, Touch ID, аппаратный ключ безопасности) для более быстрого входа. Добавьте их в **Настройки → OpenChamber → Passkeys**.

Passkeys привязаны к текущему паролю. Если вы измените или удалите пароль, сохранённые passkeys будут очищены, и вам придётся добавить их снова.

## Токены устройств

Устройства, связанные через [Подключение устройства](/ru/connect-devices/), аутентифицируются своими собственными токенами для каждого устройства, а не паролем UI. Ссылки для связывания одноразовые и истекают, если не были использованы; каждое связанное устройство показано в **Настройки → Удалённые экземпляры → Подключиться к этому серверу**, где вы можете отозвать любое из них в любой момент. Подключения вне дома идут через [Private Relay](/ru/private-relay/), который защищён сквозным шифрованием и не может прочитать ваш трафик.

## Прежде чем открывать его

- По умолчанию OpenChamber слушает только вашу собственную машину (`127.0.0.1`). Чтобы слушать шире, нужно намеренно это изменить, и сначала стоит задать пароль.
- Для своих устройств предпочитайте [связывание](/ru/connect-devices/) с [Private Relay](/ru/private-relay/) — наружу не открывается вообще ничего.
- Если вам нужен публичный URL, предпочитайте [туннель](/ru/tunnels/) или приватную сеть (например, VPN), а не открытие порта в интернет.
- Если вы ставите OpenChamber за свой HTTPS-сервер, см. [Reverse Proxy](/ru/reverse-proxy/).

## Связанное

- [Подключение устройства](/ru/connect-devices/) — одноразовое связывание и токены для каждого устройства
- [Private Relay](/ru/private-relay/) — доступ откуда угодно со сквозным шифрованием
- [Туннели](/ru/tunnels/) — откройте публичный URL, когда он нужен
- [Reverse Proxy](/ru/reverse-proxy/) — запустите OpenChamber за своим сервером
