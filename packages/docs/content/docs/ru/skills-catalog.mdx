# Каталог навыков

Каталог навыков позволяет устанавливать навыки, опубликованные другими людьми, вместо того чтобы писать свои. Откройте его в разделе **Настройки → Навыки → Каталог**.

О написании собственных навыков см. [Навыки](/ru/skills/).

## Установка навыка

1. Откройте каталог.
2. Просмотрите встроенные источники — например, репозиторий навыков Anthropic — или воспользуйтесь поиском.
3. Выберите навык и установите его.
4. Выберите, куда установить: для всего, что вы делаете, или только для текущего проекта.

Если навык с таким же именем уже существует, OpenChamber спросит, что делать: пропустить его, перезаписать или решать для каждого навыка отдельно.

## Добавление собственного источника

Вы можете добавить любой Git-репозиторий как источник, используя его имя `owner/repo` или полный Git-URL. Приватным репозиториям нужен настроенный на вашей машине доступ (SSH-ключ или сохранённые учётные данные); если источник не может пройти аутентификацию, каталог сообщит об этом, а не завершится молча.
