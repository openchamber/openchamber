# Туннели в десктопном приложении

Десктопное приложение может создать публичный туннель через **Настройки → OpenChamber → Туннель**. Для этого способа не нужно запускать OpenChamber из CLI.

## Установите провайдера

OpenChamber запускает CLI провайдера на вашей машине. Сначала установите провайдера, которым хотите пользоваться:

```bash
brew install cloudflared
brew install ngrok
```

Cloudflare использует `cloudflared`. Ngrok требует аккаунт ngrok и authtoken из панели ngrok:

```bash
ngrok config add-authtoken <your-ngrok-token>
```

## Запустите из приложения

1. Откройте **Настройки → OpenChamber → Туннель**.
2. Выберите **Cloudflare** или **Ngrok**.
3. Запустите быстрый туннель.
4. Отсканируйте созданный QR-код с телефона.

Ngrok сейчас поддерживает быстрые туннели. Cloudflare поддерживает быстрые туннели и управляемые режимы Cloudflare.

## Защита доступа

Даже когда сам URL провайдера публичный, OpenChamber всё равно защищает доступ своим токеном подключения. Созданная ссылка подключения содержит одноразовый токен, имеет срок жизни, а старые неиспользованные ссылки отзываются, когда вы создаёте новую или останавливаете/перезапускаете туннель.
