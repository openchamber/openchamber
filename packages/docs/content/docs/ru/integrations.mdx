# Интеграции

**Настройки → Интеграции** — здесь вы входите в сервисы, с которыми работает OpenChamber. Вход сохраняется на сервере OpenChamber, поэтому веб, десктоп и спаренный телефон используют его совместно.

## GitHub

Разверните карточку **GitHub** и выберите **Подключить GitHub**, чтобы войти по короткому коду устройства. После подключения OpenChamber может начинать сессии из issues и pull request, прикреплять их к сообщениям и открывать или обновлять PR. Всё, что умеет GitHub, описано на странице [GitHub Issues и PR](/ru/github/).

## Linear

### Подключение рабочей области

1. Разверните карточку **Linear** и выберите **Подключить**.
2. Подтвердите доступ во вкладке браузера, которая откроется. До этого карточка показывает **Ожидание Linear**.

Другую организацию Linear подключайте через **Добавить рабочую область**. Текущей одновременно является одна рабочая область: переключайтесь через **Переключиться на**, а **Отключить** отключает только текущую. Сопоставление проектов сохраняется.

### Просмотр issues

Как только рабочая область подключена, в правой панели контекста появляется раздел **Linear**. Он показывает issues текущей рабочей области и позволяет:

- фильтровать по статусу (**Backlog**, **To Do**, **In Progress**, **In Review**, **Done**, **Canceled**, **Duplicate**), исполнителю (**Anyone** или **Assigned to me**), команде и приоритету
- искать по названию, идентификатору или ссылке Linear
- открыть issue, чтобы прочитать её описание, комментарии, метки и приоритет
- изменить её **Статус** или нажать **Закрыть issue**
- переключить текущую **Рабочую область**

### Сессия из issue

- В панели Linear откройте issue и выберите **Начать сессию**. Кнопка остаётся внизу, пока issue прокручивается.
- В чате выберите **Новая сессия из issue Linear**, чтобы выбрать одну из списка, с опцией **Создать в worktree**, если нужна новая ветка.
- В диалоге **Новый Worktree** выберите **Начать из issue Linear**.

Сессия открывается в проекте, сопоставленном с командой issue, а сама issue становится первым промптом. Команды сопоставляются в карточке Linear: **Проект по умолчанию** действует для всех команд, а **Проекты команд** переопределяют его для отдельных команд. Для несопоставленной команды сначала попросят выбрать проект. Первое сообщение строится из волшебного промпта **Обзор issue**, который можно редактировать в **Настройки → Волшебные промпты → Linear**.

### Прикрепление issue к сообщению

В поле ввода чата выберите **Привязать issue Linear**. Issue пойдёт вместе с вашим следующим сообщением как контекст, а панель статуса работы сессии сохранит ссылку на неё.

### Комментарии к сессии

Включите **Комментарии к сессии** в карточке Linear, и сессия, начатая из issue, оставит комментарий к этой issue при старте, завершении или сбое — каждый со ссылкой, открывающей сессию. Комментарии публикуются только тогда, когда у этого сервера OpenChamber есть публичный адрес, чтобы ссылка работала для всех в issue; на локальном или приватном адресе ничего не публикуется.

## Установка интеграции

1. Откройте **Настройки → Интеграции**.
2. Найдите интеграцию и выберите **Установить**.
3. Перезапустите OpenCode, когда об этом попросят, — провайдер появится после перезапуска.
4. Выберите **Настроить** и войдите. После этого модели появятся в выборе моделей в чате.

Интеграции устанавливаются для вашего пользователя, поэтому работают во всех проектах. Обновить или удалить их можно в любое время из той же карточки.

## Claude Code

Claude Code использует вашу подписку Claude Pro или Max через Claude Code CLI на вашем компьютере — без API-ключей.

1. Установите интеграцию (выше).
2. Выберите **Настроить** и войдите. Если у вас ещё нет Claude Code CLI, программа установки сначала предложит его установить, а затем выполнит вход.

**Как защищён ваш аккаунт Claude:** эта интеграция использует официальный Claude Agent SDK от Anthropic и ваш установленный Claude Code CLI. Она не перехватывает OAuth, не извлекает и не воспроизводит токены браузера, не выдаёт себя за неподдерживаемый клиент и не обходит процесс аутентификации Anthropic. Она работает через поддерживаемый Anthropic путь доступа, поэтому не несёт риска блокировки аккаунта, связанного с перехватом токенов или несанкционированными обходами аутентификации.

## Обновление и удаление

- **Обновить** устанавливает последнюю опубликованную версию плагина.
- **Удалить** удаляет плагин из конфигурации OpenCode. Провайдер перестаёт загружаться после обновления OpenCode.

Если карточка сообщает, что записями нужно управлять вручную, выберите **Управление плагинами** и уберите дубликаты там.

## Excalidraw

Excalidraw позволяет рисовать в файлах `.excalidraw` и рисунках Obsidian `.excalidraw.md` прямо в Files. Это расширение OpenChamber, оно указано в разделе **Расширения OpenChamber** на той же странице.

1. Откройте **Настройки → Интеграции** и выберите **Установить** на карточке Excalidraw. Также можно открыть рисунок в Files и выбрать **Установить** в уведомлении над ним.
2. Откройте рисунок снова. Полотно заменяет текст файла, а Cmd/Ctrl+S, автосохранение, переключатель на исходный текст и полноэкранный режим работают как для любого файла.

Карточка обновляет расширение, когда выходит новая версия, снова включает его, если вы его приостановили, и удаляет его. При удалении ваши рисунки остаются как есть, они просто открываются как текст. Только в вебе и на десктопе.
