# Автоматическая маршрутизация моделей

Выберите **Авто** в выборе модели — и OpenChamber подберёт модель для каждого отправляемого промпта. Исправление опечатки уйдёт дешёвой и быстрой модели, а коварный баг — самой сильной. Какую модель использовать для какого типа задач, вы решаете один раз в настройках.

## Как включить

1. Убедитесь, что настроен [провайдер классификации](/ru/classification-providers/). Для Авто нужен Jev, чтобы сортировать промпты.
2. Откройте **Настройки → Маршрутизация** и установите флажок **Включить режим Авто**.
3. Выберите **Резервную модель** (и её уровень размышлений). До этого Авто остаётся скрытым.
4. Просмотрите категории ниже и задайте отдельную модель для тех, что вам важны.

Когда всё готово, страница покажет **Готово**. Выберите **Авто** в верхней части выбора модели в любой сессии.

## Категории

Каждый промпт попадает в одну категорию. Четыре встроены:

| Категория | Для чего |
| --- | --- |
| Trivial | механическая работа: переименования, опечатки, форматирование, комментарии, простые команды |
| Research | чтение и объяснение кода без его изменения |
| Implement | понятное изменение: функция с известной формой, тесты, исправление с известной причиной |
| Hard | баги с неизвестной причиной, проектирование и планирование, безопасность, авторизация, параллелизм, миграции, деньги |

Для каждой категории можно задать:

- **Модель:** пусто означает резервную модель
- **Размышления:** уровень размышлений для этой модели
- **Агент:** агент, выполняющий эти задачи; пусто сохраняет агента, выбранного в поле ввода

Jev сортирует промпты, читая названия и описания категорий, поэтому описания работают как инструкции. Скажите, что относится к категории, а что нет. Категории можно редактировать, отключать, удалять и добавлять, а встроенную — восстановить, если передумаете. Для Авто нужны как минимум две включённые категории.

## Что происходит, когда вы отправляете

1. OpenChamber отправляет Jev ваше сообщение и короткий фрагмент последних нескольких ходов.
2. Jev выбирает категорию и сообщает, насколько она уверена.
3. Сессия переключается на модель, уровень размышлений и агента этой категории, и ваше сообщение отправляется.

Каждое сообщение сортируется заново, поэтому сессия может перейти от дешёвой модели для быстрого вопроса к самой сильной для следующего запроса. Поле ввода продолжает показывать **Авто**, а элементы управления агентом и уровнем размышлений скрыты, потому что их определяет категория.

Резервная модель отвечает, когда:

- Jev недостаточно уверена (ниже 60% уверенности)
- Jev даёт сбой или отвечает дольше четырёх секунд
- у категории нет собственной модели

Выбор любой реальной модели в списке выводит сессию из Авто. Выберите **Авто** снова, чтобы вернуться. Также можно сделать Авто режимом по умолчанию для новых сессий в **Настройки → Сессии**.

## Где это работает

Авто работает на сервере OpenChamber: в десктопном приложении, в веб-приложении и на телефоне, подключённом к любому из них. В VS Code Авто не предлагается, потому что расширение общается с OpenCode напрямую.
