# Рабочие процессы Git и GitHub

В OpenChamber есть встроенный просмотр git, так что вы можете проверять изменения, коммитить и управлять ветками, не переключаясь на терминал. Откройте его на вкладке **Git** в правой боковой панели.

## Просмотр и коммит

Просмотр git делит ваши изменения на **staged** и **unstaged**:

- нажмите **+** у файла, чтобы проиндексировать его, или **−**, чтобы убрать из индекса
- проиндексируйте или уберите из индекса всё в группе сразу
- нажмите на файл, чтобы увидеть его дифф

Затем напишите сообщение коммита и закоммитьте. Вы можете поручить OpenChamber **сгенерировать сообщение коммита** из ваших проиндексированных изменений — он использует модель текущей сессии, поэтому вам нужна открытая сессия.

## Ветки и история

Просмотр git охватывает и повседневные остальные операции git:

- создание, переключение, переименование и удаление веток
- push, pull и fetch
- просмотр истории и диффов по каждому коммиту
- стэш и восстановление изменений

## Pull request

Подключите GitHub (см. [GitHub Issues и PR](/ru/github/)), и вкладка **PR** позволит открыть pull request, обновить его, отметить готовым или выполнить слияние — и сгенерировать его заголовок и описание так же, как сообщения коммитов.

## Работа с конфликтами

Если слияние, rebase или integrate наталкивается на конфликт, OpenChamber показывает, что застряло, и позволяет разрешить его — в том числе передать агенту.
