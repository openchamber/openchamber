# Быстрый старт

## Самый быстрый путь

1. Установите [OpenCode](https://opencode.ai).
2. Установите CLI OpenChamber (однострочная команда — в разделе [Установка](/ru/install/)).
3. Запустите `openchamber --ui-password be-creative-here`.
4. Откройте URL, который выводит CLI (обычно `http://localhost:3000`).
5. Чтобы пользоваться с телефона, запустите [туннель](/ru/tunnels/) и отсканируйте QR-код.

Вы должны увидеть в браузере список сессий OpenChamber. Если он загрузился, значит всё работает.

Используйте надёжный пароль интерфейса, особенно если собираетесь открыть приложение в интернет.

Если страница не загружается, проверьте раздел [Устранение неполадок](/ru/troubleshooting/).

## Какое приложение использовать?

- используйте **десктопное приложение** для повседневной работы на macOS
- используйте **веб-версию** для удалённого доступа и просмотра с телефона
- используйте **VS Code** для сессий прямо рядом с кодом
