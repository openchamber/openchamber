# Провайдеры, модели и агенты

Прежде чем OpenChamber сможет что-либо делать, к нему нужно подключить хотя бы одного AI-провайдера. Эта страница охватывает подключение провайдера, выбор модели и настройку агентов.

## Подключение провайдера

1. Откройте **Настройки → Провайдеры**.
2. Откройте меню **Добавить провайдера** и выберите провайдера, который ещё не подключён, или выберите **Другое / Своё** для эндпоинта, совместимого с OpenAI.
3. Войдите одним из двух способов, в зависимости от провайдера:
   - **API-ключ** — вставьте свой ключ и сохраните.
   - **Вход (device flow)** — OpenChamber показывает ссылку и короткий код. Откройте ссылку, введите код и подтвердите. OpenChamber завершит подключение сам.

### Свои и другие провайдеры

Для шлюзов, вузовских LLM, Ollama, LiteLLM и подобных API, совместимых с OpenAI:

1. Выберите **Другое / Своё** в списке провайдеров.
2. Укажите ID провайдера, отображаемое имя, базовый URL (`http://` или `https://`), API-ключ (или `{env:VAR_NAME}`) и хотя бы один id/имя модели.
3. При желании перечислите уровни рассуждений модели (например `low, medium, high`). Каждый уровень появляется в переключателе вариантов модели в чате, как и у встроенных провайдеров.
4. При желании добавьте заголовки запроса.
5. Сохраните — OpenChamber записывает блок провайдера в конфиг OpenCode и сохраняет ключ в auth OpenCode (если он задан буквально) или записывает ссылку `{env:VAR}`.
6. Чтобы изменить существующего своего провайдера, откройте его и выберите **Изменить**.

Своим провайдерам нужен API-ключ или `{env:VAR_NAME}`, чтобы они отображались как полностью подключённые. Без учётных данных модели могут появиться, но вызовы в чате будут падать.

Когда провайдер отображается как подключённый, его модели становятся доступны в чате.

Чтобы отключить, откройте провайдера и выберите удаление его входа.

## Выбор модели

Модель вы выбираете там, где работаете:

- в чате используйте переключатель моделей в строке сообщения, чтобы задать провайдера и модель для этой сессии
- для каждого агента задайте модель по умолчанию (ниже)

## Настройка агентов

Агент — это именованная настройка: модель, характер и то, что ему разрешено делать.

1. Откройте **Настройки → Агенты**.
2. Выберите агента или создайте нового.
3. Отредактируйте любое из:
   - **описание** — для чего предназначен агент
   - **модель** — его модель по умолчанию
   - **температура** — насколько креативны его ответы
   - **промпт** — постоянные инструкции, которых он всегда придерживается
   - **правила инструментов** — какими инструментами он может пользоваться

## Где хранятся ваши входы

Входы провайдеров хранит OpenCode, а не OpenChamber, поэтому они общие с CLI OpenCode. Если вы задаёте одного провайдера в нескольких местах, побеждает самая конкретная настройка: настройка для проекта переопределяет вашу личную.
