# Действия проекта

Действие проекта — это shell-команда, которую вы сохраняете один раз и запускаете кликом: ваш dev-сервер, сборка, прогон тестов. У каждого проекта свой список. Настройте их в **Настройки → Проекты → Действия проекта**.

## Добавление действия

1. Откройте **Настройки → Проекты** и найдите раздел **Действия проекта**.
2. Добавьте действие, дайте ему название, выберите иконку и введите команду для запуска.
3. Сохраните.

Вы можете ограничить действие определёнными операционными системами, если команда имеет смысл только на одной.

## Запуск действия

Действия живут в меню в верхней панели приложения. Нажмите на одно, и OpenChamber запустит его в терминале в папке вашего проекта, переключив вас на вид терминала, чтобы вы могли наблюдать за выводом. Остановите его из того же меню.

## Автооткрытие dev-сервера

Включите **auto-open URL** для действия, которое запускает сервер. OpenChamber следит за выводом на предмет локального адреса и предлагает открыть его — см. [Preview и dev-серверы](/ru/preview/). На десктопе вы также можете направить его через перенаправление порта SSH.
