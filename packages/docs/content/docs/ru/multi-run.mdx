# Multi-run

Multi-run запускает несколько сессий из одной формы — удобно, чтобы попробовать одну и ту же задачу с разными моделями и сравнить результаты. Откройте его кнопкой вверху боковой панели сессий.

## Запуск Multi-run

1. Откройте средство запуска Multi-run.
2. Выберите проект и назовите группу запусков.
3. Напишите промпт и выберите модели, с которыми его запустить.
4. Решите, **изолировать ли запуски**.
5. Запустите.

Каждая модель получает собственную сессию, и все они начинаются с вашего промпта.

## Изолированные запуски

Включите **изолировать запуски**, чтобы дать каждому запуску собственный [worktree](/ru/worktrees/) и ветку, так что они никогда не трогают одни и те же файлы. Для этого нужен git-репозиторий — для папок, которые им не являются, это отключается автоматически. Выберите ветку, от которой начинаются запуски.

Когда изоляция выключена, каждый запуск — это обычная сессия в папке проекта.

## Сравнение результатов

Каждый запуск — обычная сессия, которую можно открыть, прочитать и сохранить или отбросить. Если вы запустили их, чтобы сравнить подходы, просмотрите их рядом и продвиньте лучший.

Если один запуск не стартует, остальные всё равно запускаются — вы просто увидите меньше сессий, чем запрашивали.
