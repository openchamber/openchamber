# Заметки, задачи и планы проекта

У каждого проекта есть собственное место для заметок, списка задач и сохранённых планов. Они принадлежат проекту, а не какой-то отдельной сессии, поэтому сохраняются, когда вы переходите между сессиями. Найдите их на вкладке **Context** в правой боковой панели (отдельная вкладка на мобильном).

## Заметки

Свободное поле для заметок обо всём, что вы хотите помнить о проекте. Оно сохраняется само по мере набора.

## Задачи

Простой чек-лист. Добавляйте пункты, отмечайте их, меняйте порядок перетаскиванием и очищайте выполненные.

У каждой задачи есть меню **send**, чтобы вы могли передать её агенту:

- отправить её в текущую сессию
- начать с ней новую сессию
- начать с ней новую [сессию worktree](/ru/worktrees/) (только когда проект — это git-репозиторий)

## Планы

Место, где хранятся более длинные планы в виде сохранённых файлов. Вы можете:

- импортировать план из файла Markdown или текстового файла
- открыть план, чтобы прочитать его в боковой панели
- удалять планы, которые вам больше не нужны

Вы должны вернуться на вкладку Context с сохранённой заметкой, отмеченной задачей или добавленным в список планом — так вы понимаете, что всё сработало.

## Связанное

- [Сессии Worktree](/ru/worktrees/) — запускайте задачу в её собственной ветке
- [Проекты](/ru/projects/) — это принадлежит активному проекту
