# Мобильные приложения и PWA

У OpenChamber есть нативные приложения для iPhone и Android, так что вы можете следить за сессиями, отвечать агентам и управлять работой с телефона — дома по Wi-Fi или откуда угодно через [Private Relay](/ru/private-relay/).

## Установка приложения

- **iPhone/iPad** — присоединитесь к [бете в TestFlight](https://testflight.apple.com/join/5ek6GU1E)
- **Android** — скачайте APK из [последнего релиза](https://github.com/openchamber/openchamber/releases/latest)

## Подключение к серверу

1. На компьютере, где запущен OpenChamber, откройте **Настройки → Удалённые экземпляры → Подключиться к этому серверу** и нажмите **Добавить устройство**.
2. Выберите **Где угодно** (или **Только домашняя сеть**, если будете пользоваться телефоном только дома) и нажмите **Создать QR-код**.
3. В мобильном приложении нажмите **Сканировать QR-код** и наведите камеру на него.

Приложение подключается и запоминает сервер. QR-код одноразовый, и каждое устройство получает собственный отзываемый токен — см. [Подключение устройства](/ru/connect-devices/), чтобы узнать, как связывание остаётся безопасным.

Вы можете связать приложение с несколькими серверами и переключаться между ними в списке экземпляров; для каждого приложение показывает, доступен ли он и подключены ли вы через локальную сеть или через relay.

## PWA (установка из браузера)

Не хотите никакого магазина приложений? Веб-приложение устанавливается прямо из браузера:

- **десктопный браузер** — используйте пункт **Установить** в адресной строке
- **iPhone/iPad (Safari)** — Поделиться → **Добавить на экран «Домой»**
- **Android (Chrome)** — меню → **Установить приложение** / **Добавить на главный экран**

Чтобы добраться до PWA из-за пределов вашей сети, понадобится [туннель](/ru/tunnels/) и надёжный [пароль UI](/ru/security/) — нативные приложения делают это за вас через relay.

## Мобильные настройки

В разделе **Настройки → OpenChamber** несколько параметров настраивают мобильную и установленную версии — установленное имя приложения, ориентацию экрана и поведение экранной клавиатуры.
