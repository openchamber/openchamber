# Голосовой режим

Голосовой режим позволяет диктовать сообщения и слушать ответы, зачитанные вам вслух. Включите его в разделе **Настройки → OpenChamber → Голос**.

## Чтение ответов вслух (синтез речи)

Выберите, как озвучиваются ответы:

- **browser** — встроенные голоса вашего браузера, без настройки
- **OpenAI** — голоса OpenAI; вставьте свой API-ключ и выберите голос
- **OpenAI-compatible** — любой сервис, работающий в формате OpenAI; введите его URL и, если требуется, API-ключ
- **macOS say** — встроенная команда `say`, на Mac, где она есть

После включения у сообщений появляется кнопка воспроизведения, чтобы услышать их вслух.

## Диктовка сообщений (распознавание речи)

Выберите, как расшифровывается ваша речь:

- **browser** — встроенное распознавание вашего браузера, без настройки
- **server** — совместимый с OpenAI сервис расшифровки; введите его URL и, при необходимости, API-ключ
- **on-device** — речевая модель, работающая в вашем браузере и скачивающаяся при первом использовании

## Замечание для телефонов

Для чтения ответов вслух на телефоне надёжнее всего варианты OpenAI или OpenAI-compatible — мобильные браузеры ограничивают встроенные голоса.
