# MCP-серверы

MCP-сервер даёт вашим агентам дополнительные инструменты — например, поиск в базе данных, вызов API или чтение сервиса, которым вы пользуетесь. Добавляйте их в **Настройки → MCP**.

## Добавление сервера

1. Откройте **Настройки → MCP**.
2. Добавьте сервер и выберите его тип:
   - **локальный** — OpenChamber запускает команду на вашей машине. Вы указываете команду для запуска и, при необходимости, переменные окружения.
   - **удалённый** — OpenChamber подключается к URL, который размещает кто-то другой. Вы указываете URL и любые нужные заголовки (например, токен аутентификации).
3. Сохраните. Сервер включён по умолчанию; вы можете отключить его, не удаляя.

## Где это применяется

Выберите область при добавлении сервера:

- **личная** — доступна в каждом проекте
- **проектная** — доступна только в текущем проекте и сохраняется вместе с другими настройками проекта

Имена серверов используют строчные буквы, цифры, дефисы и подчёркивания.
