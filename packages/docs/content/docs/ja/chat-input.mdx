# チャット入力

チャット欄はいくつかの記号を理解します。1つ入力すると選択画面が開きます。項目を選ぶか、そのまま入力して絞り込みます。記号は単語の先頭でのみ意味を持ち、コマンドはメッセージの先頭にある必要があります。

| 入力 | 選ぶもの | 有効な位置 |
| --- | --- | --- |
| `/` | コマンド | メッセージの先頭 |
| `$` | スキル | どこでも |
| `#` | スニペット | どこでも |
| `@` | ファイルまたはエージェント | どこでも |

持っていないものを指す記号は普通のテキストのままです。`$5` はただの金額で、`a/b` はただのパスです。

## コマンド

コマンドは `/review` のようにスラッシュで実行する保存済みプロンプトです。**Settings → Commands** で管理します。

1. **Settings → Commands** を開き、コマンドを作成します。
2. 名前、説明、送信するプロンプト本文を入力します。
3. 必要なら特定のエージェントやモデルに固定します。
4. 個人用かプロジェクト用かのスコープを選びます。

チャットでは、メッセージの**最初**の文字として `/` を入力するとコマンドが表示されます。そこから選んでください。テキストにはプレースホルダーを使えます。

- `$ARGUMENTS`: コマンドの後に入力した内容
- `@filename`: ファイルの内容を差し込みます
- `` !`command` ``: シェルコマンドの出力を差し込みます

組み込みの `init` と `review` コマンドはリセットできますが、削除はできません。OpenChamber には `/explore` や `/summary` などのコマンドも含まれます。一覧は [Magic Prompts](/magic-prompts/) を参照してください。

## スキル

メッセージのどこかで `$` を入力するとスキル選択が開きます。1つ選ぶと、エージェントはその返信のためにそのスキルの指示を読み込みます。自作するには [スキル](/skills/) を参照してください。

コマンドとスキルは選択画面が別です。先頭の `/` がスキルを並べることはなく、`$` がコマンドを並べることもありません。

## スニペット

スニペットは `#signoff` のようなハッシュタグで本文中から参照する再利用可能なテキストです。**Settings → Snippets** で管理します。

1. **Settings → Snippets** を開き、スニペットを作成します。
2. 名前と、その名前が表すテキストを入力します。複数の呼び出し名が欲しい場合はエイリアスを追加します。
3. 個人用かプロジェクト用かのスコープを選びます。

チャットで `#` を入力してスニペットを選ぶと、OpenChamber が送信前に全文へ置き換えます。

## ファイルとエージェント

`@` を入力すると、ファイルを添付したり、別のエージェントでメッセージを実行したりできます。

- `@src/index.ts` のようなファイルは、**+** メニューから選んだときと同じようにメッセージに添付されます。画像とドキュメントは読み取られ、一緒に送信されます。
- `@build` のようなエージェントは、そのエージェントでこのメッセージを実行します。メンションがなければ、composer で選択中のエージェントが実行します。

## ファイルとコンテキストの添付

チャット欄の隣の **+** メニューはファイル以外も添付できます。

- パソコン内のファイル
- リポジトリの issue と pull request（GitHub、GitLab、Gitea、Gerrit のうち、プロジェクトをホストしているもの）
- Linear を接続している場合の Linear issue
- 添付を提供するインストール済み[拡張機能](/extensions/)のタスク

それぞれが次のメッセージにコンテキストとして付いてきます。どう扱うかはメッセージが決めます。画像を貼り付けたり、ファイルをチャット欄に直接ドロップしたりもできます。

## シェルコマンドを実行する

メッセージを `!` で始めると、OpenChamber はそれをシェルコマンドとして実行し、エージェントには何も送りません。**Esc** を押すか、空欄になるまで削除してシェルモードを抜けます。

## キーボード

- **Enter** は送信、**Shift+Enter** は改行です。**Settings → Chat** で入れ替えられ、Enter で改行、**Ctrl/Cmd+Enter** で送信になります。Ctrl/Cmd+Enter は常に送信します。
- **ArrowUp** と **ArrowDown** で以前のメッセージを呼び出せます。
- 選択画面が開いているときは **Ctrl+N** と **Ctrl+P** で移動、**Enter** または **Tab** で選択、**Esc** で閉じます。

展開した composer では、Enter は常に改行し、**Ctrl/Cmd+Enter** が送信します。

スマートフォンでは、Enter は常に改行します。送信ボタンまたは **Ctrl/Cmd+Enter** で送信します。
