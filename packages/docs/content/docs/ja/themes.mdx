# テーマ

OpenChamber は組み込みテーマとカスタムテーマ JSON ファイルに対応しています。

## VS Code テーマをインポートする

**設定 → 外観 → VS Code テーマをインポート**で Open VSX を検索できます。結果にはアイコン、名前、作者が表示されます。パッケージを選び、色のプレビューを比較して必要なバリエーションをインポートしてください。一括インポートでは現在のテーマを維持します。Microsoft Marketplace のみに公開されたテーマは Open VSX にない場合があります。

ローカルの 512 KiB 以下の `.json` または `.jsonc` には **JSON ファイルを選択**を使います。デスクトップでは `~/.vscode/extensions` があればそこから開きます。ファイルの UI、構文、差分の色を変換し、テーマを有効にします。ドロップダウンのインポート済みテーマ横のごみ箱で接続先サーバーから削除できます。選択中のテーマを削除すると、そのモードの既定テーマに戻ります。

テーマは、デスクトップやモバイルからのインポートでも接続先の OpenChamber サーバーに保存されます。同じファイルを再度インポートしても重複は作られず、サーバー上で編集されたテーマも上書きされません。VS Code 拡張機能は VS Code 自体のテーマに従います。

ファイルが `include` や別のトークンファイルを参照している場合は、VS Code のコマンドパレットで **Developer: Generate Color Theme From Current Settings** を実行し、生成された JSON をインポートしてください。

## カスタムテーマを追加する

1. テーマディレクトリを作成します。

```bash
mkdir -p ~/.config/openchamber/themes
```

2. そのディレクトリに JSON ファイルを追加します（例: `my-theme.json`）。
3. OpenChamber を開き、**Settings -> Theme -> Reload themes** に移動します。
4. ドロップダウンからテーマを選びます。すぐに適用されます。

## テーマの場所

- macOS/Linux: `~/.config/openchamber/themes/`

## 完全な JSON 形式リファレンス

メインリポジトリのドキュメントにある完全な形式ガイドを使ってください。

- [`docs/CUSTOM_THEMES.md`](https://github.com/openchamber/openchamber/blob/main/docs/CUSTOM_THEMES.md)
