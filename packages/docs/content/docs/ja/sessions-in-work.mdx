# 作業中のセッション

質問や調査、ちょっとした実験はすぐに溜まり、実際に何かを直しているセッションがその中に埋もれてしまいます。**作業中** ブロックは、そうしたセッションをサイドバーの 1 か所にまとめます。セッションは、あなたが完了と言うまでそこに残ります。

ここが「最近」との違いです。「最近」は直近 2 日間に変化したものをすべて表示し、自動で入れ替わります。今朝なんとなく開いたセッションはそこにあり、月曜日に中断した修正はもう消えています。「作業中」は、最後に開いたのがどれだけ前であっても、まだ終わっていないもののリストです。

## 場所

**作業中** ブロックはサイドバーの、チャットの下、「最近」（Timeline モードではタイムライン）の上にあります。スマートフォンでも、セッション一覧の同じ位置にあります。

作業中のセッションは、サブセッションと一緒にそこへ移ります。「最近」、タイムライン、プロジェクト、フォルダーに二重に表示されることはありません。完了にすると、元の場所に戻ります。

## 手動で追跡して完了にする

- **追跡する：** セッションにカーソルを合わせて目のアイコンを押すか、セッションメニューで **作業中として追跡** を選びます。
- **完了にする：** ブロック内のセッションにカーソルを合わせてチェックを押すか、メニューで **完了にする** を選びます。

スマートフォンでは、セッションの行をスワイプすると同じ操作ができます。セッションメニューも使えます。

worktree のセッションも含め、どのプロジェクトセッションでも作業中にできます。サブセッションは親セッションと一緒に移ります。チャットは作業中になりません。ただの会話なので、目のアイコンも表示されません。

## Jev に任せる

[分類プロバイダー](/ja/classification-providers/)を設定しておけば、セッションを自分で追跡する必要はありません。Jev は送信されたメッセージを毎回読み、次のような場合にセッションを作業中に移します。

- 変更を頼んだとき
- バグを報告したとき
- これから行う具体的な変更について話し合っているとき

質問、説明、調査は含まれません。エージェントがターンを終えたときにも Jev はもう一度確認するので、返答を見て初めてわかる作業も拾えます。

Jev が行うのは作業中に **入れる** ことだけです。一度完了にしたセッションは、そのあとに送った新しい依頼でしか戻ってきません。

### 「この作業は完了したようです。」

ターンが作業の終わりに見えるとき（お礼を言った、コミットを頼んだ、動いたと確認した）、Jev は何も閉じずにヒントを残します。

- サイドバーのセッション行に灰色のチェック
- 入力欄の上に帯：**この作業は完了したようです。** と **完了にする** ボタン

Jev の判断が正しければ **完了にする** を押してください。違っていれば、そのまま続けるだけで大丈夫です。ヒントは次のメッセージで消えます。

## 要約と次のメッセージの提案

エージェントが作業を終え、セッションが 1 分間静かになると、OpenChamber は小さなモデルを使って 2 つのものを書けます（[プロバイダー、モデル、エージェント](/ja/providers/)を参照）。

- **要約：** 何をしたか、いまどういう状態かを短くまとめたメモ。最後の返答の下と、サイドバーのセッションのツールチップに表示されます
- **提案：** あなたが次に送りそうなメッセージ。入力欄の上部に 1 行で表示され、クリックすると入力欄に入ります。勝手に送信されることはありません

Jev が使える場合、OpenChamber はまずそのターンにこれらが必要かを Jev に確認します。本格的な作業のあとの「ありがとう、以上です」には要約が付きますが、やることが残っていなければ提案は省かれ、どちらも役に立たないときは小さなモデルを呼び出しません。Jev がなければ、これまでどおりターンごとに両方が生成されます。

オン・オフは **設定 → チャット → セッション支援** で切り替えます。

## 設定

**設定 → セッション → 作業中のセッション** を開きます。

- **作業中のセッションを表示：** ブロックそのもの。オフにすると、セッションはいつもの場所に残ります
- **セッションを自動的に作業中にする：** Jev の部分。オフにすると手動でのみ追跡します

どちらも既定でオンです。

## 使える場所

ブロックと手動の追跡・完了は、VS Code を含むどこでも使えます。自動で作業中に移す機能、「完了したようです」のヒント、要約の Jev フィルターには OpenChamber サーバーが必要なので、デスクトップアプリ、Web アプリ、スマートフォンでは使えますが、VS Code では使えません。
