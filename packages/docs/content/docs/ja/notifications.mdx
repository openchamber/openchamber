# 通知

通知は、画面を見張っていなくても注意が必要なことを知らせます。セッションの完了、エラー、質問、何かを行うための権限要求などです。**Settings → OpenChamber → Notifications** で設定します。

## オンにする

1. **Settings → OpenChamber → Notifications** を開きます。
2. ブラウザまたはシステムが求めたら通知を許可します。
3. 何について通知を受けたいか選びます。
   - セッションが**完了**した
   - セッションで**エラー**が起きた
   - セッションが**質問**した
   - セッションが**権限**を必要としている
   - **サブタスク**が完了した

## 通知の届き方

- **デスクトップ**では、ネイティブのシステム通知を受け取ります
- **ブラウザまたはインストール済みアプリ**では、Web Push 通知を受け取るため、タブがバックグラウンドでも届きます

自動承認に設定されたセッションでは、権限通知で何度も邪魔されることはありません。

## サウンド

通知は短い音を鳴らすこともできます。ウィンドウを見なくても、向けとのセッションに気づけます。**Settings → OpenChamber → Notifications → 通知サウンド** で有効にし、セッション完了・入力待ち・許可リクエスト・エラーごとに音を選べます。

既定では、OpenChamber がバックグラウンドのときにだけ音が鳴ります。見ているウィンドウは目で分かっているためです。作業中にも鳴らしたい場合は、**再生するタイミング** を **常に** にしてください。

デスクトップではこの音でOSの通知音を置き換えるため、1つのイベントにつき音は1つだけです。通知サウンドをオフにしている場合、デスクトップの通知は音なしで届きます。

収録されている音は [OpenCode](https://github.com/sst/opencode) のアテンションパック由来です。

## 文言をカスタマイズする

通知の種類ごとに、エージェント名やモデルなどのフィールドを使ったタイトルとメッセージテンプレートを編集できます。直近メッセージをどれだけ含めるかにも上限があり、通知が短く保たれます。
