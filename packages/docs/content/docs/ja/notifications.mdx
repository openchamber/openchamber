# 通知

通知は、画面を見張っていなくても注意が必要なことを知らせます。セッションの完了、エラー、質問、何かを行うための権限要求などです。**Settings → OpenChamber → Notifications** で設定します。

## オンにする

1. **Settings → OpenChamber → Notifications** を開きます。
2. ブラウザまたはシステムが求めたら通知を許可します。
3. 何について通知を受けたいか選びます。
   - セッションが**完了**した
   - セッションで**エラー**が起きた
   - セッションが**質問**した
   - セッションが**権限**を必要としている
   - **サブタスク**が完了した

## 通知の届き方

- **デスクトップ**では、ネイティブのシステム通知を受け取ります
- **ブラウザまたはインストール済みアプリ**では、Web Push 通知を受け取るため、タブがバックグラウンドでも届きます

自動承認に設定されたセッションでは、権限通知で何度も邪魔されることはありません。

アプリ内の履歴で、一覧に項目が入ったときの音をオンにできます。ウィンドウが背面でも鳴ります。

## 文言をカスタマイズする

通知の種類ごとに、エージェント名やモデルなどのフィールドを使ったタイトルとメッセージテンプレートを編集できます。直近メッセージをどれだけ含めるかにも上限があり、通知が短く保たれます。

## アプリ内の履歴

ヘッダーのベルは、この端末にトーストとセッションイベントの一覧を残します。タップする前にトーストが消えても、センターでは未読のままです。行を開くか、OK やコピーを押すと既読になります。行は削除するか期限が来るまで残ります。「すべて既読」は表示中のトーストも閉じます。

システム通知やプッシュ通知をクリックすると、セッション ID がある場合はそのセッションが開きます。

Settings → OpenChamber → Notifications に「アプリ内の履歴」があります。最初はオンです。一覧をオフにするとベルが隠れます。種類のチェックを外すと一覧とバッジから隠れます。行は保存されたままなので、もう一度オンにすれば戻ります。情報、成功、サブタスクは最初からオフで、バッジが埋まりません。サブタスクの OS バナーはイベントの別スイッチのままです。イベントとテンプレートは配信側に残ります。
