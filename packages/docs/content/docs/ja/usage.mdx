# 使用量とクォータ

Usage ページでは、各プロバイダープランをどれだけ使ったかを確認でき、上限にどれだけ近いかが分かります。**Settings → Usage** から開きます。

## 表示されるもの

接続済みプロバイダーごとに、OpenChamber は次を表示します。

- 現在のウィンドウでどれだけ使ったかをバーで表示
- モデル別の内訳
- 使い切りそうなペースか分かる pace インジケーター

表示するプロバイダーは選べます。同じサマリーはアプリヘッダーのドロップダウンからも確認できます。

## 対応プロバイダー

Usage は、Claude、Codex、GitHub Copilot、Google、OpenRouter、Kimi、NanoGPT、z.ai、Zhipu、MiniMax、Ollama Cloud、Wafer など、クォータを公開しているプロバイダーで動作します。

プロバイダーの使用量は、[プロバイダー](/providers/) ページでサインインした後に表示されます。一部のプロバイダーには、Usage の設定で入力する専用の資格情報があります（exe.dev、Cursor、ZenMux の 3 つ）。プロバイダーにデータが表示されない場合、多くはその資格情報が不足しています。

[拡張機能](/extensions/) は独自の使用量プロバイダーを追加できます。そのカードは組み込みのプロバイダーの後ろに、拡張機能の名前とアイコンとともに並び、同じように動作します。拡張機能の権限ダイアログには、認証情報を読み取るプロバイダーが示されます。

## エージェントに読ませる

**設定 → 一般 → OpenChamber ツール** で **エージェントの使用量ツール** をオンにすると、エージェントも同じ数値を読めます。プロバイダーごとの期間、それぞれの使用量、リセット時刻です。長いタスクの前にエージェントに上限を確認させたり、[スケジュールタスク](/ja/scheduled-tasks/)でプランの状況を報告させたりできます。

エージェントにはこのページと同じ内容が見えますが、各プロバイダーでサインインしているアカウントは含まれません。確認のたびに、このページを開いたときと同じくプロバイダーへ改めて問い合わせます。このツールは既定でオフで、OpenChamber 自身の OpenCode サーバーを使うデスクトップ版と Web 版で動作します。
