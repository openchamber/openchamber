# サイドバー

サイドバーには上から順に **チャット**、ピン留めしたものがあれば **ピン留め**、**作業中**、そしてプロジェクトが並びます。すべてを時間順に 1 つのリストで見るには、サイドバーの表示メニューの **セッション** で **時間順** を選びます。**プロジェクト別** でプロジェクトごとの表示に戻ります。

## 1 行が 1 つの作業

- **プロジェクトのフォルダーにあるセッション** は 1 行です。サブエージェント、自動レビュー、脇道の質問など、そこから生まれたものは、左側の矢印を開いた下に入ります。単純なフォークは独立した 1 行になります。
- **worktree** はプロジェクトの下の 1 行で、その中のすべてのセッションがその下に入ります。行をクリックするとそこで最後に作業したセッションが開き、矢印をクリックするとすべて表示されます。[Worktree セッション](/ja/worktrees/)を参照してください。
- **隔離スペース** も worktree と同じように動作します。

## 1 行に表示されるもの

行の左側で種類がわかります。

- ブランチのアイコン: worktree
- スペースのアイコン: 隔離スペース
- 何もない、または矢印: プロジェクトのフォルダーにあるセッション

行の右側は今の状態を示します。実行中、新しい返信、または入力待ちです。末尾の色付きのマークは、その作業が追っているプルリクエストまたは issue です。

## worktree の名前

worktree の行にはタスク名が表示されます。タスク名は、タスクがはっきりした時点でエージェントが付けます。それまではブランチが表示されます。自分で名前を変えると、その名前が残ります。新しい worktree に移したセッションは、タスク名を持ったまま移ります。

worktree をブランチで見分けたいときは、表示メニューで **worktree をブランチ名で表示** をオンにします。ブランチが行の名前になり、タスク名は詳細な行でその下に移ります。

## 作業中とピン留め

**作業中** にはまだ終えていない作業が入ります。[作業中のセッション](/ja/sessions-in-work/)を参照してください。ここに入った作業はプロジェクトから外れるので、両方に表示するには **作業中の項目もプロジェクトの下に表示** をオンにします。**ピン留め** には、行のメニューからピン留めしたセッションと worktree が入ります。

## 表示メニュー

- **セッション**: プロジェクト別または時間順
- **プロジェクトを並べ替え**: 手動、A → Z、Z → A、新しい順
- **チャットセクションを表示**、**ピン留めセクションを表示**、**作業中セクションを表示**
- **作業中の項目もプロジェクトの下に表示**
- **詳細な行**: ブランチまたはタスク名、プルリクエストまたは issue、リストに複数のプロジェクトが混ざるときはプロジェクトを 2 行目に表示
- **worktree をブランチ名で表示**
- **すべて折りたたむ** と **すべて展開**

長いリストの最後には **さらに表示** があります。**表示を減らす** で元に戻ります。

## スマートフォン

リストもメニューも同じです。**詳細な行** をオフにしない限り行は 2 行で表示され、行を横にスワイプすると操作が表示されます。

VS Code はこのレイアウトより前のリストのままです。
