# 音声モード

音声モードでは、メッセージを音声入力し、返信を読み上げで聞けます。**Settings → OpenChamber → Voice** でオンにします。

## 返信の読み上げ（text-to-speech）

返信の読み上げ方法を選びます。

- **browser** — ブラウザ組み込みの音声。設定不要です
- **OpenAI** — OpenAI の音声。API キーを貼り付けて声を選びます
- **OpenAI-compatible** — OpenAI 形式で音声を返す任意のサービス。URL と、必要なら API キーを入力します
- **macOS say** — Mac にある組み込みの `say` コマンド

オンにすると、メッセージに再生ボタンが表示され、読み上げを聞けます。

## メッセージの音声入力（speech-to-text）

音声をどう文字起こしするか選びます。

- **ローカル** は、OpenChamber が動いているコンピューター上で音声モデルを実行します。モデルは初めて音声入力するときにダウンロードされ、音声はそのコンピューターから出ません。
- **サーバー** は、音声を OpenAI 互換の文字起こしサービスに送ります。URL と、必要なら API キーを入力します。

ローカルモデル：

- **Parakeet v3** が既定です。英語やウクライナ語を含む 25 のヨーロッパ言語に対応し、最も高速です。v3 が既定になる前に Parakeet v2 で音声入力していた場合は、別のモデルを選ぶまで v2 のままです。
- **Parakeet v2** は英語のみに対応します。
- **Whisper large-v3 turbo** は 99 言語に対応します。Parakeet より約 9 倍遅いため、長い音声入力は表示されるまで数秒かかります。
- **Qwen3-ASR 0.6B** は中国語、日本語、韓国語、アラビア語を含む 30 言語に対応します。ウクライナ語には対応していません。
- **Whisper tiny** はダウンロードサイズが最も小さく、低速なコンピューター向けです。

Whisper と Qwen3-ASR のモデルは言語を自動で判別するため、短いフレーズでは違う言語と判断することがあります。モデル一覧の下の **言語** に `uk` や `en` のような言語コードを入力すると、言語を推測しなくなります。

**聞き間違えた単語を修正** をオンにすると、音声入力を止めたあとで Small Model（設定 → セッション → Small Model）がテキストを見直します。音声モデルが聞き間違えた単語を置き換え、「えーと」のような言葉を取り除きます。このときテキストは Small Model のプロバイダーに送られ、1、2 秒後に表示されます。Small Model がない場合、テキストは認識されたまま挿入されます。

これらのサービス用に入力した API キーは、ブラウザーではなく OpenChamber サーバーが保管します。キーを入力して Enter を押すと保存され、欄には保存済みであることが表示されます。× で削除できます。

## スマートフォン向けの注意

スマートフォンで返信を読み上げる場合、OpenAI または OpenAI-compatible の選択肢が最も安定します。モバイルブラウザは組み込み音声に制限があります。
