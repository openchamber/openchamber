# チャット

チャットは、どのプロジェクトにも属さない、エージェントとの普通の会話です。コードベースとは関係のないことに使います。FreeBSD 向けに KDE にパッチを当てる方法、ある正規表現の意味、メールの下書きなどです。エージェントは使い捨てのフォルダーで作業するので、リポジトリもブランチもなく、プロジェクトの文脈が会話に入り込むこともありません。

## チャットを始める

いちばん手早いのは、サイドバーの **チャット** セクションの **+** です。スマートフォンでは、セッション一覧の上部にある **新しいチャット** か、チャットの **+** をタップします。

**Mod+N**（macOS では Cmd+N、それ以外では Ctrl+N）とコマンドパレットの **新しいセッション** は、最後に使った側で新しいセッションを開きます。最後に作った新しいセッションがチャットならチャット、そうでなければプロジェクトです。最初のメッセージを送る前なら、チャットに切り替えられます。

## チャットの場所

チャットにはサイドバーの最上部に専用のセクションがあり、[作業中](/ja/sessions-in-work/)とプロジェクトの上に表示されます。ほかのセッションと同じく新しい活動順に並び、ピン留めしたチャットは上に残ります。Timeline モードでは最新の 3 件が表示され、**さらにセッションを表示** で残りを読み込めます。セクションはほかと同じように折りたためます。

スマートフォンでは、セッションパネルのプロジェクト一覧の上にチャットがあります。

## チャットでできること、できないこと

チャットにはそれぞれ専用の空のフォルダーがあるので、エージェントはそこでファイルを作ったり編集したりできます。スクリプト、ちょっとしたプロトタイプ、変換したドキュメントなどです。チャットにないもの：

- git のステータス、ブランチ、worktree
- 作業中への移動（チャットが[作業中](/ja/sessions-in-work/)に表示されることはありません）
- 新しいセッションでの計画の実行
- Linear の Issue からの開始

メモ、Todo、計画は使えます。すべてのチャットで 1 つのセットを共有し、プロジェクトとは別になっています。

チャットはチャットのままです。終わったチャットをプロジェクトに移す方法はありません。会話が本格的な作業に変わったら、プロジェクトでセッションを始めて、役に立つ部分を持っていってください。

## アーカイブと削除

一覧から隠すにはチャットをアーカイブします。完全に消すには削除します。ほかのセッション（フォークやサブエージェント）がそのフォルダーを使っていなければ、フォルダーごと削除されます。

## フォルダーの場所

チャットのフォルダーは `~/.config/openchamber/chats` にあり、日付ごとに 1 つのフォルダーが作られます。`OPENCHAMBER_DATA_DIR` で OpenChamber のデータを移した場合は、そのフォルダーの下になります。チャットを別の場所に置くには `OPENCHAMBER_CHATS_DIR` を設定します。[環境変数](/ja/environment/)を参照してください。OpenCode が別のユーザーとして動いていて、ホームフォルダーを読めない場合に重要です。

> VS Code にはチャットがありません。拡張機能は常に、開いているフォルダーで作業します。
