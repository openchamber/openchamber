# 分類プロバイダー（Jev）

OpenChamber の機能の中には、動く前にすばやい判断が必要なものがあります。このコマンドは危険か、このプロンプトはどんな種類のタスクか、ユーザーはいま本格的な作業を始めたのか。こうした質問に答えるのが、TypeSafe の小さな判断モデル Jev です。このページでは、OpenChamber が Jev を使えるようにする方法を説明します。

Jev がコードを書いたり、チャットで返信したりすることはありません。返すのは判定だけで、OpenChamber がそれに従って動きます。OpenChamber が回答を待つのは最大 4 秒です。

## Jev を使う機能

| 機能 | Jev が答える質問 |
| --- | --- |
| [権限とセーフティネット](/ja/permissions/) | この操作を実行する前に、エージェントはあなたに確認すべきか？ |
| [自動モデルルーティング](/ja/auto-model-routing/) | このプロンプトはどのカテゴリに属するか？ |
| [作業中のセッション](/ja/sessions-in-work/) | いま本格的な作業を頼んだか？このターンで作業は終わりそうか？ |
| [要約と次のメッセージの提案](/ja/sessions-in-work/) | このターンのあとに要約や提案を生成する価値があるか？ |

プロバイダーがない場合、セーフティネットと Auto は表示されず、セッションはあなたが自分で移したときだけ作業中になります。要約と提案はフィルターなしでそのまま動きます。

## 設定する

Jev は自分でオンにするまでオフのままです。分類プロバイダーを選ばない限り、会話の内容がどこかへ送られることはありません。**設定 → プロバイダー → 分類プロバイダー** を開き、Jev へのリクエストの送り先を選びます。**オフ** のほかに、選択肢は 6 つです。

### OpenCode Zen プロモーション

期間限定で無料、キーは不要です。プロモーション期間中、OpenCode は OpenChamber が OpenCode Zen 経由で Jev を無料で使うことを認めています。

プロモーションが終わるとこの選択肢は消え、下のキーのどれかを持っていれば OpenChamber はそれに切り替えます。

### OpenCode Zen キー

OpenCode に保存された Zen の API キーを使い、料金は Zen の残高から支払われます。

1. **設定 → プロバイダー** を開き、**OpenCode Zen** プロバイダーに API キーを追加します（[プロバイダー、モデル、エージェント](/ja/providers/)を参照）。
2. **分類プロバイダー** に戻り、**OpenCode Zen キー** を選びます。

OpenCode アカウントでのサインインだけでは足りません。Jev に対して Zen が受け付けるのは API キーだけです。

### OpenRouter キー

OpenCode に保存された OpenRouter の API キーを使い、料金は OpenRouter アカウントに請求されます。OpenCode ですでに OpenRouter のモデルを使っているなら、設定は不要です。 環境変数 `OPENROUTER_API_KEY` のキーも使えます。両方ある場合は OpenCode に保存されたキーが優先されます。

1. **設定 → プロバイダー** を開き、**OpenRouter** プロバイダーに API キーを追加します。
2. **分類プロバイダー** に戻り、**OpenRouter キー** を選びます。

### Vercel AI Gateway キー

OpenCode に保存された AI Gateway の API キーを使い、料金は Vercel アカウントに請求されます。 環境変数 `AI_GATEWAY_API_KEY` のキーも使えます。両方ある場合は OpenCode に保存されたキーが優先されます。

1. **設定 → プロバイダー** を開き、**Vercel AI Gateway** プロバイダーに API キーを追加します。
2. **分類プロバイダー** に戻り、**Vercel AI Gateway キー** を選びます。

### TypeSafe API キー

ご自身の TypeSafe のキーとクォータを使います。

1. [TypeSafe](https://docs.typesafe.ai) で API キーを取得します。
2. **TypeSafe API キー** 欄に貼り付けて **保存** を押します。

キーを保存すると、そのキーが選択されます。キーは OpenChamber サーバー上の専用ファイルに置かれ、ブラウザーに送られることはありません。

### カスタムエンドポイント

TypeSafe の System One API に対応したサービスなら何でも使えます。セルフホストのゲートウェイ、社内プロキシ、ここに載っていないプロバイダーなどです。

1. **カスタムエンドポイント** で **エンドポイント URL** と **モデル**（例: `jev-latest`）を入力します。
2. サービスが必要とする場合は **API キー** を追加します。キーは `Bearer` トークンとして送られます。
3. **保存** を押します。

URL には、`/v1/systemone` で終わる完全なアドレス、`/v1` で終わる OpenAI 形式のベース URL、API のルート（`https://api.typesafe.ai` など）のどれでも貼り付けられます。OpenChamber が足りない部分を補い、実際に呼び出すアドレスを表示します。使えるのは `http` と `https` だけで、キーは URL に含めず専用の欄に入力します。

保存するとそのエンドポイントが選択されます。TypeSafe キーと同じく、エンドポイントとそのキーは OpenChamber サーバー上の専用ファイルに置かれ、キーがブラウザーに送られることはありません。

サーバーは環境変数からエンドポイントを受け取ることもできます。チーム向けに OpenChamber をセットアップするときに便利です。

```bash
OPENCHAMBER_JEV_URL=https://jev.example.com/v1
OPENCHAMBER_JEV_MODEL=jev-latest        # 任意。これが既定値です
OPENCHAMBER_JEV_API_KEY=...             # 任意
```

管理しているノート PC では、代わりにマシンの[ポリシーファイル](/ja/security/)の `jev` に同じエンドポイントを書きます。こちらが環境変数より優先されます。

どちらの場合も、設定に保存したエンドポイントは置き換えられ、設定にはそれが表示されますが誰も編集できません。[エンタープライズモード](/ja/security/)では、**オフ** 以外に許可される唯一の Jev の送り先で、既定で選択されます。

プロバイダーが使えるようになると、**設定 → プロバイダー** のカードに **準備完了** と表示されます。

## 選んだものが使えなくなったとき

選んだプロバイダーが使えない場合（プロモーションが終わった、キーが削除された）、OpenChamber はご自身のキーのうち使える最初の 1 つに切り替えます。順番は TypeSafe キー、次にカスタムエンドポイント、OpenRouter、Vercel AI Gateway、Zen キーです。プロモーションに切り替わることはなく、**オフ** はオフのままです。いまどれを使っているかはページに表示されます。

Jev が 1 回のリクエストで遅れたり失敗したりしても、何も壊れません。各機能はその場合の安全な動きを持っています。

- セーフティネットは、操作をあなたの判断待ちのままにします。
- Auto は、プロンプトをフォールバックモデルに送ります。
- 作業中のセッションはそのままです。
- 要約と提案は、Jev がない場合と同じように生成されます。

## Jev が見るもの

Jev が受け取るのは会話の短い抜粋です。あなたの最新のメッセージと、文脈として直前の最大 3 ターンで、それぞれ先頭の数百文字に切り詰められています。セーフティネットの場合は、確認対象の操作も OpenCode が記述したとおりに受け取ります。エージェントが実行しようとしているコマンドや、編集ならファイルと変更内容です。ファイル全体や画像を受け取ることはありません。

リクエストは、選んだ内容に応じて OpenChamber サーバーから OpenCode Zen、OpenRouter、Vercel AI Gateway、TypeSafe、カスタムエンドポイントのいずれか に直接送られます。

## 使える場所

Jev は OpenChamber サーバーで動くため、デスクトップアプリ、Web アプリ、そしてそのどちらかに接続したスマートフォンで使えます。VS Code 拡張機能は OpenCode と直接やり取りするため Jev はありません。セーフティネットも Auto もなく、セッションは手動でのみ作業中になります。
