# エージェントページ

エージェントはチャットの中にページを描けます。グラフ、表、図、インターフェースのモックアップ、短いフォームなどです。そのページで選択肢を選ぶよう頼むこともでき、回答が別の人から必要なときは、同じページをリンクと PIN でチームメイトに送れます。

## ページを頼む

普段の言葉でエージェントに頼みます。たとえば:

- 「3 つのレイアウト案をモックアップで見せて、1 つ選ばせて。」
- 「テスト結果をグラフにして。」
- 「これらのマイグレーションのどれを先に実行するか聞いて。」

ページはチャットの中に、あなたのファイルにアクセスできないフレームで表示されます。**全画面で開く** で大きく表示でき、**HTML としてダウンロード** でコピーを保存できます。

## ページで回答する

エージェントがページで何かを尋ねると、チャットに **ページでの回答を待っています** と表示されます。選択肢を選ぶかフィールドに入力し、ページの送信ボタンを押します。エージェントが回答を受け取り、ページにはあなたの選んだ内容が表示されます。

- **断る** は、選ばないことをエージェントに伝えます。エージェントが代わりに選ぶことはありません。
- 言葉で答えることもできます。チャットに書けば、エージェントがそのメッセージを読みます。

### あとで回答する

エージェントがいつもあなたを待つ必要はありません。ページを表示したまま作業を続けることもできます。ページはあなたが回答するまで開いたままで、エージェントのターンが終わってもアプリを再起動しても残ります。回答はセッションに独立した行として届き、エージェントが待機中なら再び動き出します。

## チームメイトとページを共有する

回答が同僚やマネージャーなど別の人から必要なときは、ページを送るようエージェントに頼みます:

- 「この 2 つのデザインのどちらがいいか、Yulia と Denis に聞いて。」

1. エージェントは 1 人につき 1 つのリンクを作ります。メッセージの下のカードに名前が並び、それぞれに **リンクをコピー** と **PIN をコピー** があります。
2. リンクと PIN を、好きなメッセンジャーで各自に自分で送ります。
3. 相手はブラウザでリンクを開き、PIN を入力してページで回答します。OpenChamber は必要ありません。
4. 回答は質問したセッションに戻り、あなたに通知が届きます。エージェントがそれを読んで作業を続けます。

エージェントは、表やグラフのあるレポートのような、相手が読むだけのページも共有できます。フォームはなく、回答は返ってきません。

カードには、各自がいつページを開き、いつ回答したかが表示されます。カードの **開く** で相手と同じ見た目のページを確認でき、あなたが開いても相手が開いたことにはなりません。

### 共有リンクの仕組み

- オンにする設定はありません。リンクを誰かに送るまで、ページは誰にも届きません。
- 1 人が回答できるのは 1 回だけで、その回答は確定です。
- リンクの有効期間は最大 2 営業日で、土曜と日曜は数えません。もっと短くしたいときはエージェントに頼んでください。
- カード上の相手のメニューにある **リンクを取り消す** で、その人のリンクを無効にできます。
- PIN を何度も間違えるとリンクがロックされます。
- OpenChamber は回答者が誰かを確認しません。リンクと PIN を持っていれば誰でも回答できます。カードの名前は、あなたがエージェントに伝えたものです。
- ページと回答は暗号化されて送られます。共有サービスが保持するのは暗号化されたコピーだけで、回答があなたに届くと削除されます。PIN のないリンクでは何も開けません。
- ページは OpenChamber の共有サービスを通るか、[プライベートリレー](/ja/private-relay/) で自分のリレーを設定していればそのリレーを通ります。

## 共有されたページを開く

OpenChamber があれば、共有されたページをアプリで開き、自分のエージェントに読ませて判断を手伝ってもらえます:

1. リンクをチャット入力欄に貼り付けます。PIN 欄の付いたチップに変わります。
2. PIN を入力し、質問を書いて送信します。エージェントはあなたのメッセージと一緒にページの内容を受け取り、それは他人の内容として扱われます。
3. メッセージの下の **開く** で、ページがサイドパネル (スマートフォンでは全画面) に表示されます。ページ自体の送信ボタンで回答します。

エージェントは回答を提案できますが、送信できるのはあなただけです。リンクと PIN がモデルに届くことはありません。

サイドパネルの **共有ページ** には、受け取ったすべてのページが新しい順に状態付きで並びます。スマートフォンではワークスペースのドロワーのタブです。開いているページの **チャットに追加** で、書いているメッセージにそのページを添付できます。

## オンとオフ

エージェントページはデフォルトでオンです。オフにするには **設定 → 一般 → OpenChamber ツール** を開き、**グラフとモックアップ** をオフにします。

## 注意点

- エージェントページには、[エージェント制御ツール](/ja/agent-control-tool/) と同じく OpenChamber 独自の OpenCode サーバーが必要です。
- VS Code 拡張機能では、共有リンクはただのテキストのままで、あとで回答するよう頼まれたページは回答用のコントロールなしで表示されます。デスクトップ版かウェブ版で回答してください。
- エンタープライズモードでは、共有は組織独自のリレーを通してのみ動きます。リレーがなければ、エージェントに共有の機能は提供されません。[セキュリティ](/ja/security/) を参照してください。
