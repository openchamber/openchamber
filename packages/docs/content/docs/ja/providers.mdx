# プロバイダー、モデル、エージェント

OpenChamber が何かを行うには、少なくとも 1 つの AI プロバイダーが接続されている必要があります。このページでは、プロバイダーの接続、モデルの選択、エージェントの調整について説明します。

## プロバイダーを接続する

1. **Settings → Providers** を開きます。
2. **Add provider** メニューを開き、まだ接続されていないプロバイダーを選びます。
3. プロバイダーに応じて、次のどちらかの方法でサインインします。
   - **API key** — キーを貼り付けて保存します。
   - **Sign-in (device flow)** — OpenChamber がリンクと短いコードを表示します。リンクを開き、コードを入力して承認します。OpenChamber が自動で接続を完了します。

プロバイダーが接続済みとして表示されると、そのモデルがチャットで使えるようになります。

切断するには、プロバイダーを開き、サインインを削除する操作を選びます。

## モデルを選ぶ

作業している場所でモデルを選びます。

- チャットでは、メッセージバーのモデルピッカーを使って、そのセッションのプロバイダーとモデルを設定します
- エージェントごとに、デフォルトモデルを設定します（下記）

## エージェントを設定する

エージェントは、名前付きの設定です。モデル、人格、許可された操作をまとめます。

1. **Settings → Agents** を開きます。
2. エージェントを選ぶか、新しく作成します。
3. 次の項目を編集できます。
   - **description** — エージェントの用途
   - **model** — デフォルトモデル
   - **temperature** — 回答の創造性
   - **prompt** — 常に従う固定指示
   - **tool rules** — 使用してよいツール

## Antigravity に作業を委任する

Antigravity CLI（`agy`）は、Google AI Plus、Pro、Ultra のサブスクリプションを使って、エージェントのために範囲を絞った作業を実行できます。チャットのプロバイダーではなく委任された作業者なので、そのモデルはモデル選択に表示されません。

1. OpenCode を実行しているマシンに Antigravity CLI をインストールし、`agy` を一度実行してサインインします。
2. **設定 → プロバイダー → Antigravity CLI** を開きます。インストール済みのバージョンと、アカウントで使えるモデルが表示されます。
3. 既定のモデルを選び、委任を有効にします。

エージェントは `agy` ツールを使えるようになり、チャットで `/agy` と入力して作業を渡せます。Antigravity はセッションのディレクトリで独自のツールと権限を使って作業し、委任したエージェントが結果を確認します。ヘッドレス実行では承認を表示できないため、承認が必要なツールは拒否され、結果にその内容が示されます。「確認せずにコマンドを実行」はオフで、コマンドは常に Antigravity のターミナルサンドボックス内に保たれます。

委任には OpenChamber が OpenCode を起動している必要があります。外部の OpenCode サーバーに接続している場合、ページはスイッチを無効にします。VS Code には OpenChamber サーバーがないため、Antigravity の設定もありません。

## サインイン情報の保存場所

プロバイダーのサインイン情報は OpenChamber ではなく OpenCode に保存されるため、OpenCode CLI と共有されます。同じプロバイダーを複数の場所で設定した場合、最も具体的な設定が優先されます。プロジェクトごとの設定は個人設定を上書きします。
