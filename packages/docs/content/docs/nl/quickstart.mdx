# Snel aan de slag

## De snelste manier

1. Installeer [OpenCode](https://opencode.ai).
2. Installeer de OpenChamber CLI. De opdracht hiervoor staat bij [Installeren](/nl/install/).
3. Voer `openchamber --ui-password be-creative-here` uit.
4. Open de URL die de CLI toont, meestal `http://localhost:3000`.
5. Wilt u uw telefoon gebruiken? Start dan een [tunnel](/nl/tunnels/) en scan de QR-code.

U hoort nu de sessielijst van OpenChamber in uw browser te zien. Als die laadt, kunt u beginnen.

Gebruik een sterk wachtwoord voor de interface, zeker als u de instantie via internet bereikbaar wilt maken.

Laadt de pagina niet? Kijk dan bij [Problemen oplossen](/nl/troubleshooting/).

## Welke app past bij mijn werk?

- gebruik **desktop** voor dagelijks werk op macOS
- gebruik **web** voor toegang op afstand en voor het beoordelen van werk op uw telefoon
- gebruik **VS Code** voor sessies direct naast uw code
