# Gebruik en limieten

De gebruikspagina toont hoeveel u van het abonnement bij elke provider hebt verbruikt en hoe dicht u bij een limiet zit. Open **Instellingen → Gebruik**.

## Wat ziet u?

Voor elke verbonden provider toont OpenChamber:

- een balk met het verbruik binnen de huidige periode
- een uitsplitsing per model
- een verbruiksindicator die laat zien of u in dit tempo uw limiet gaat bereiken

U kiest zelf welke providers worden getoond. Hetzelfde overzicht is beschikbaar in een uitklapmenu bovenaan de app.

## Ondersteunde providers

De functie werkt voor providers die hun gebruikslimieten beschikbaar stellen, waaronder Claude, Codex, GitHub Copilot, Google, OpenRouter, Kimi, NanoGPT, z.ai, Zhipu, MiniMax, Ollama Cloud en Wafer.

Het verbruik verschijnt pas nadat u zich bij de provider hebt aangemeld op de pagina [Providers](/nl/providers/). Sommige providers vereisen een eigen aanmeldgegeven, dat u in Gebruik invoert — exe.dev, Cursor en ZenMux. Als een provider geen gegevens toont, ontbreekt meestal dat aanmeldgegeven.

Een [extensie](/nl/extensions/) kan een eigen verbruiksprovider toevoegen. Haar kaart staat achter de ingebouwde providers, met de naam en het pictogram van de extensie, en werkt op dezelfde manier; de toestemmingsdialoog van de extensie noemt de providers waarvan zij de aanmeldgegevens leest.
