# Updates

Hoe u OpenChamber bijwerkt, hangt af van de installatie. Uw huidige versie vindt u altijd bij **Instellingen → OpenChamber → Over**.

## Desktopapp

De desktopapp controleert GitHub-releases op updates. Als er een beschikbaar is, krijgt u bericht. U kiest wanneer de update wordt gedownload; de installatie gebeurt bij de volgende herstart. Er wordt niets zonder uw toestemming geïnstalleerd.

## Web en CLI

Hebt u de CLI geïnstalleerd, gebruik dan de controle- en updateknoppen bij **Over**, of voer in de terminal uit:

```bash
openchamber update
```

OpenChamber herkent of het met npm, pnpm, yarn of bun is geïnstalleerd en voert de juiste update uit.

## De OpenCode-server

OpenChamber en OpenCode worden afzonderlijk bijgewerkt. Bij een nieuwe OpenCode-versie biedt OpenChamber aan die te installeren en daarna de server te herstarten. Zie [OpenCode-server](/nl/opencode-server/) voor het beheer daarvan.
