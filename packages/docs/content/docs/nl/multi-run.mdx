# Parallelle runs

Met parallelle runs start u meerdere sessies vanuit één formulier. Dat is handig om dezelfde taak met verschillende modellen te proberen en de resultaten te vergelijken. Open het startvenster via de knop bovenaan de sessiezijbalk.

## Parallelle runs starten

1. Open het startvenster voor parallelle runs.
2. Kies het project en geef de groep runs een naam.
3. Schrijf de prompt en kies de modellen die haar uitvoeren.
4. Kies of u de **runs wilt isoleren**.
5. Start de runs.

Elk model krijgt een eigen sessie. Alle sessies beginnen met uw prompt.

## Geïsoleerde runs

Schakel **Runs isoleren** in om elke run een eigen [worktree](/nl/worktrees/) en branch te geven. Zo bewerken ze nooit dezelfde bestanden. Dit vereist een Git-repository. Bij andere mappen wordt de optie automatisch uitgeschakeld. Kies ook de branch waarop de runs moeten beginnen.

Zonder isolatie is elke run een gewone sessie in de projectmap.

## Resultaten vergelijken

Elke run is een normale sessie die u kunt openen, lezen, behouden of weggooien. Als u verschillende aanpakken wilt vergelijken, beoordeelt u de resultaten naast elkaar en gaat u verder met de beste.

Als één run niet kan starten, starten de andere wel. U ziet dan minder sessies dan u had gevraagd.
