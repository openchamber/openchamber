# MCP-servers

Een MCP-server geeft uw agents extra tools, bijvoorbeeld om een database te doorzoeken, een API aan te roepen of gegevens uit een dienst te lezen. Voeg servers toe bij **Instellingen → MCP**.

## Een server toevoegen

1. Open **Instellingen → MCP**.
2. Voeg een server toe en kies het type:
   - **lokaal:** OpenChamber voert een opdracht op uw computer uit. U geeft de opdracht en eventueel omgevingsvariabelen op.
   - **remote:** OpenChamber verbindt met een URL die elders wordt gehost. U geeft de URL en benodigde headers op, bijvoorbeeld een authenticatietoken.
3. Sla de server op. Deze staat standaard aan. U kunt hem uitschakelen zonder hem te verwijderen.

## Waar geldt de server?

Kies bij het toevoegen het bereik:

- **persoonlijk:** beschikbaar in elk project
- **project:** alleen beschikbaar in het huidige project en opgeslagen bij de overige projectinstellingen

Servernamen mogen kleine letters, cijfers, koppeltekens en underscores bevatten.
