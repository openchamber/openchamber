# Context

Elk model kan maar een beperkte hoeveelheid gespreksinhoud tegelijk verwerken: de context. OpenChamber laat zien hoe vol die is. Zo merkt u wanneer een sessie de limiet nadert en oudere details mogelijk niet meer in antwoorden worden meegenomen.

## De contextmeter

Tijdens het chatten toont een kleine meter het gebruikte percentage. De kleur verandert naarmate de context voller wordt:

- groen: er is nog veel ruimte
- geel: de context raakt vol, rond driekwart van de limiet
- rood: de context is bijna vol

Beweeg de aanwijzer over de meter, of tik erop op uw telefoon, om de precieze aantallen tokens te zien.

## Het volledige contextpaneel

Open het tabblad **Context** in de rechterzijbalk voor meer informatie over de huidige sessie:

- het gebruikte model en de begintijd van de sessie
- het totale aantal tokens ten opzichte van de modellimiet
- het aantal berichten en de totale kosten
- een uitsplitsing van de tokens in het laatste antwoord
- een schatting van de ruimte die uw berichten, agentberichten en tooluitvoer innemen

Die uitsplitsing is een schatting, geen exacte telling. Gebruik haar om te zien wat de context vult, niet om kosten te berekenen.

## Wat te doen als de context vol is

Begin voor een nieuwe taak een nieuwe sessie, in plaats van één sessie eindeloos te laten groeien. Een kortere context werkt sneller en helpt het model bij de taak te blijven.
