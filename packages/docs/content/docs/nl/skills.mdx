# Skills

Een skill is een herbruikbare set instructies die een agent kan laden wanneer die relevant is, bijvoorbeeld 'zo schrijven we commitberichten' of 'onze API-afspraken'. U beheert skills bij **Instellingen → Skills**.

Wilt u kant-en-klare skills installeren in plaats van zelf schrijven? Zie [Skillcatalogus](/nl/skills-catalog/).

## Een skill maken

1. Open **Instellingen → Skills**.
2. Maak een skill en geef deze een naam en een korte beschrijving. De agent gebruikt die beschrijving om te bepalen wanneer de skill van toepassing is, dus wees concreet.
3. Schrijf de instructies. Voeg ondersteunende bestanden toe als de skill die nodig heeft.
4. Kies waar de skill beschikbaar is:
   - **persoonlijk:** in elk project
   - **project:** alleen in het huidige project

## Een skill in de chat gebruiken

Typ `$` ergens in een bericht, ook aan het begin, om de skillkiezer te openen en kies een skill. De agent laadt de instructies voor het antwoord.

Een `/` helemaal aan het begin opent [opdrachten](/nl/commands-snippets/); daar staan geen skills tussen.
