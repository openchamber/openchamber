# Updates

How you update Sharpie depends on how you installed it. In every case you can check your current version at **Settings → Sharpie → About**.

## Desktop app

The desktop app checks for updates against GitHub releases. When one is available, Sharpie tells you, downloads it when you choose, and installs it on the next restart. You're always in control — nothing installs without your say-so.

## Web / CLI

If you installed the CLI, update it from **About** with the check and update buttons, or from the terminal:

```bash
openchamber update
```

Sharpie detects how it was installed (npm, pnpm, yarn, or bun) and runs the right update for you.

## The OpenCode server

Sharpie and OpenCode update separately. When a new OpenCode version is available, Sharpie offers to update it and restarts the server afterward. See [OpenCode Server](/opencode-server/) for how that server is managed.
