# Nutzung & Kontingente

Die Seite Nutzung zeigt, wie viel du von den Tarifen der einzelnen Provider bereits verbraucht hast, damit du sehen kannst, wie nah du an einem Limit bist. Du öffnest sie unter **Einstellungen → Nutzung**.

## Was du siehst

Für jeden verbundenen Provider zeigt OpenChamber:

- wie viel des aktuellen Zeitfensters du bereits genutzt hast, als Balken
- eine Aufschlüsselung nach Modell
- einen Tempoindikator, damit du siehst, ob du rechtzeitig am Limit ankommen wirst

Du kannst auswählen, welche Provider angezeigt werden, und dieselbe Zusammenfassung ist auch über ein Dropdown in der App-Kopfzeile verfügbar.

## Unterstützte Provider

Die Nutzung funktioniert für die Provider, die ein Kontingent veröffentlichen, darunter Claude, Codex, GitHub Copilot, Google, OpenRouter, Kimi, NanoGPT, z.ai, Zhipu, MiniMax, Ollama Cloud und Wafer.

Ein Anbieter zeigt Nutzung erst dann an, wenn du dich auf der [Seite „Anbieter“](/providers/) dort angemeldet hast. Einige Anbieter brauchen eine eigene Anmeldeinformation, die du in den Nutzung-Einstellungen eingibst — exe.dev, Cursor und ZenMux sind die drei. Wenn ein Anbieter keine Daten anzeigt, fehlt meist diese Anmeldeinformation.

Eine [Erweiterung](/extensions/) kann einen eigenen Nutzungsanbieter hinzufügen. Ihre Karte steht hinter den eingebauten, mit Name und Symbol der Erweiterung, und funktioniert genauso; der Berechtigungsdialog der Erweiterung nennt die Anbieter, deren Zugangsdaten sie liest.

## Agenten mitlesen lassen

Schalte **Nutzungs-Tool für Agenten** unter **Einstellungen → Allgemein → OpenChamber-Werkzeuge** ein, dann lesen Agenten dieselben Zahlen: die Zeitfenster jedes Providers, wie viel davon verbraucht ist und wann sie zurückgesetzt werden. Lass einen Agenten vor einer langen Aufgabe ein Limit prüfen oder eine [geplante Aufgabe](/de/scheduled-tasks/) berichten, wie es um deine Tarife steht.

Der Agent sieht, was diese Seite zeigt, ohne das Konto, mit dem jeder Provider angemeldet ist. Jede Prüfung fragt deine Provider erneut, genau wie das Öffnen dieser Seite. Das Tool ist standardmäßig aus und funktioniert in Desktop- und Web-Installationen, die den eigenen OpenCode-Server von OpenChamber nutzen.
