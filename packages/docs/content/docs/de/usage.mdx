# Nutzung & Kontingente

Die Seite Nutzung zeigt, wie viel du von den Tarifen der einzelnen Provider bereits verbraucht hast, damit du sehen kannst, wie nah du an einem Limit bist. Du öffnest sie unter **Einstellungen → Nutzung**.

## Was du siehst

Für jeden verbundenen Provider zeigt OpenChamber:

- wie viel des aktuellen Zeitfensters du bereits genutzt hast, als Balken
- eine Aufschlüsselung nach Modell
- einen Tempoindikator, damit du siehst, ob du rechtzeitig am Limit ankommen wirst

Du kannst auswählen, welche Provider angezeigt werden, und dieselbe Zusammenfassung ist auch über ein Dropdown in der App-Kopfzeile verfügbar.

## Unterstützte Provider

Die Nutzung funktioniert für die Provider, die ein Kontingent veröffentlichen, darunter Claude, Codex, GitHub Copilot, Google, OpenRouter, Kimi, NanoGPT, z.ai, Zhipu, MiniMax, Ollama Cloud, Wafer und Sub2API.

Ein Anbieter zeigt Nutzung erst dann an, wenn du dich auf der [Seite „Anbieter“](/providers/) dort angemeldet hast. Einige Anbieter brauchen noch einen zusätzlichen Schritt — Ollama Cloud liest zum Beispiel eine Sitzungsdatei, die du separat einrichtest. Wenn ein Anbieter keine Daten anzeigt, fehlt meist diese zusätzliche Anmeldeinformation.

Für Sub2API verbinde auf der Provider-Seite einen OpenAI-kompatiblen Custom-Provider mit der ID `sub2api` (beliebige Base-URL und Modelle für den Chat). Die Nutzung fragt dann `GET <baseUrl>/v1/usage` mit dem API-Schlüssel dieses Providers ab und zeigt je nach Schlüssel Kontingent, Abo oder Wallet-Guthaben sowie optionale 30-Tage-Modellstatistik.
