# GitHub Issues & PRs

Verbinde dein GitHub-Konto und OpenChamber kann Issues und Pull Requests einlesen, direkt daraus eine Sitzung starten und PRs für dich öffnen oder aktualisieren.

## GitHub verbinden

1. Öffne **Einstellungen → Integrationen** und klappe die Karte **GitHub** auf.
2. Wähle **Connect GitHub**. OpenChamber zeigt einen Link und einen kurzen Code an.
3. Öffne den Link, gib den Code ein und bestätige.

Wenn die Verbindung steht, erscheint dein Konto auf der Karte. Du kannst mehr als ein Konto verbinden und zwischen ihnen wechseln oder dich jederzeit trennen. Ist die `gh`-CLI auf demselben Rechner angemeldet, kann OpenChamber sie als Fallback nutzen.

## Arbeit aus einem Issue oder PR starten

Wenn du mit verbundenem GitHub eine [Worktree-Sitzung](/worktrees/) erstellst, kannst du sie aus einem Issue oder einem Pull Request starten:

- wähle ein **issue** und OpenChamber benennt den Branch danach
- wähle einen **pull request** und OpenChamber checkt den Branch des PR aus; du kannst den Diff des PR einbeziehen, damit der Agent die komplette Änderung hat

Die neue Sitzung öffnet sich mit dem Issue oder PR bereits im Nachrichtenfeld angehängt. Gesendet wird nichts automatisch: Wähle Modell und Agent, schreib, was getan werden soll, und schick es ab.

## Pull Requests öffnen und verwalten

Im **PR**-Tab der [Git-Ansicht](/git/) kannst du einen Pull Request erstellen, aktualisieren, einen Entwurf als bereit markieren oder mergen. OpenChamber kann den PR-Titel und die Beschreibung aus deinen Änderungen generieren.

## Issue oder PR an eine Nachricht hängen

Öffne im Chat-Composer das Menü **+** und wähle **GitHub**. Wähle ein oder mehrere Issues oder Pull Requests: Jedes geht als Kontext mit deiner nächsten Nachricht mit (ein PR kann seinen Diff mitbringen), und das Arbeitsstatus-Panel der Session behält einen Link darauf. Das Anhängen liefert nur Kontext; was damit passieren soll, sagt deine Nachricht.
