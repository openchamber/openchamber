# Sprachmodus

Mit dem Sprachmodus kannst du Nachrichten diktieren und dir Antworten vorlesen lassen. Schalte ihn unter **Einstellungen → OpenChamber → Sprache** ein.

## Antworten vorlesen lassen (Text-zu-Sprache)

Wähle aus, wie Antworten gesprochen werden:

- **Browser** — die integrierten Stimmen deines Browsers, keine Einrichtung nötig
- **OpenAI** — die Stimmen von OpenAI; füge deinen API-Schlüssel ein und wähle eine Stimme
- **OpenAI-kompatibel** — jeder Dienst, der das OpenAI-Format unterstützt; gib seine URL und, falls nötig, einen API-Schlüssel an
- **macOS say** — der eingebaute `say`-Befehl, auf Macs mit dieser Funktion

Sobald es aktiviert ist, erscheint bei Nachrichten eine Abspieltaste, mit der du sie vorlesen lassen kannst.

## Nachrichten diktieren (Sprache-zu-Text)

Wähle aus, wie deine Sprache transkribiert wird:

- **Browser** — die integrierte Spracherkennung deines Browsers, keine Einrichtung nötig
- **Server** — ein OpenAI-kompatibler Transkriptionsdienst; gib seine URL und, falls nötig, einen API-Schlüssel an
- **Gerätebasiert** — ein Sprachmodell, das in deinem Browser läuft und beim ersten Verwenden heruntergeladen wird

## Hinweis für Telefone

Beim Vorlesen auf einem Telefon sind die Optionen OpenAI oder OpenAI-kompatibel am zuverlässigsten — mobile Browser begrenzen die integrierten Stimmen.
