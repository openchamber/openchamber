# Erweiterungen

Unter **Einstellungen → Erweiterungen** fügst du OpenChamber Panels hinzu, die andere Leute gebaut haben. Eine Erweiterung ist eine kleine Seite in der rechten Leiste, neben den eingebauten Panels. Sie kann dir Daten aus einem anderen Dienst zeigen, eine Aufgabe an den Chat anhängen und, wenn du es erlaubst, Sitzungen starten, Prompts senden oder Dateien lesen.

Erweiterungen laufen in OpenChamber Web und Desktop. VS Code und die Mobile-App laden sie noch nicht. Sie sind nicht dasselbe wie OpenCode-Plugins.

## Eine Erweiterung installieren

1. Öffne **Einstellungen → Erweiterungen**.
2. Füge eines davon in das Feld **Ordner, ZIP oder URL** ein und wähle **Hinzufügen**:
   - den absoluten Pfad eines Ordners auf diesem Computer
   - den Pfad einer `.zip`-Datei
   - einen https-Link zu einem Git-Repository oder einer Zip-Datei
3. Wenn die Erweiterung Berechtigungen anfragt, listet ein Dialog sie auf. Wähle **Erlauben und aktivieren** oder **Entfernen**, um sie wieder zu entfernen.

Auf dem Desktop öffnen die Ordner- und Archiv-Schaltflächen neben dem Feld eine native Dateiauswahl, statt dass du einen Pfad tippst.

Das Symbol der Erweiterung erscheint in der Leiste. Falls nicht, sieh unter [Fehlerbehebung](/troubleshooting/) nach.

Eine Installation aus einem Ordner läuft direkt aus diesem Ordner, sodass jemand, der eine Erweiterung entwickelt, bearbeiten und neu laden kann. Eine Zip-Datei oder eine URL wird zuerst in den Datenordner von OpenChamber kopiert; die Originaldatei bleibt unberührt.

## Was eine Erweiterung darf

Ein Panel anzeigen und lesen, welches Projekt und welche Sitzung offen sind, braucht keine Berechtigung. Alles, was in deinem Namen handelt, braucht eine, und du siehst die ganze Liste einmal, bei der Installation:

- **Nachrichten an deine Sitzungen senden**: Prompts schreiben und an das Modell senden, was Tokens verbraucht.
- **Sitzungen und Worktrees anlegen**: neue Sitzungen im aktuellen Projekt starten.
- **Dateien im offenen Projekt lesen und schreiben**.
- **Dateien außerhalb des Projekts lesen und schreiben**: nur die genauen Orte, die die Erweiterung im Dialog auflistet.
- **Mit externen Diensten verbinden**: die eigene API mit einem Konto aufrufen, das du verbindest.
- **Den Gesprächsverlauf einer Sitzung lesen, wenn du ihre Aktion ausführst**: die Erweiterung erhält jede Nachricht dieser Sitzung, aber nur, wenn du ihre Aktion aus dem Sitzungsmenü wählst.
- **Lokalen Dienst ausführen**: ein separates Programm auf diesem Computer mit den Rechten deines Benutzerkontos starten. Erlaube das nur Erweiterungen, denen du vertraust; die deklarierten Berechtigungen beschreiben die Absicht, sie schränken nicht ein.

Wenn eine neuere Version mehr verlangt, als du erlaubt hast, zeigt die Karte **Freigabe nötig** und eine Schaltfläche **Berechtigungen prüfen**. Bis du die neue Liste erlaubst, bleibt die Erweiterung aus.

## Wo sie auftaucht

Neben ihrem Panel in der Leiste kann eine Erweiterung Einträge in Menüs ergänzen, die du ohnehin benutzt: die Aktionen an einer Chat-Nachricht, das Menü einer Sitzung, das +-Menü neben dem Chatfeld und Slash-Befehle wie `/task ABC-12`, die etwas anhängen, ohne etwas zu öffnen. Die Erweiterung entscheidet, welche davon sie anbietet; alle bleiben aus, bis du die Erweiterung erlaubst.

## Ihr Konto verbinden

Eine Erweiterung, die mit einem Dienst spricht, bekommt eine Karte unter **Einstellungen → Integrationen** im Abschnitt **Erweiterungskonten**. Je nach Dienst fragt die Karte nach einem API-Token, nach Benutzername und Token oder nach einer Client-ID für einen Anmeldeablauf. Wähle **Verbinden**; **Trennen** vergisst den gespeicherten Token. Zusätzliche Felder, die die Erweiterung deklariert, speichern sich von selbst, sobald du sie verlässt.

Der Token bleibt auf dem OpenChamber-Server. Die Seite der Erweiterung sieht ihn nie.

## Pausieren oder entfernen

Jede Karte hat einen Schalter **Aktiviert**. Aus lässt die Erweiterung installiert, versteckt aber ihr Panel und blockiert ihre Aufrufe. **Entfernen** löscht eine Zip- oder URL-Installation aus dem Datenordner von OpenChamber; bei einer Ordner-Installation vergisst es nur den Pfad, dein Ordner bleibt.
