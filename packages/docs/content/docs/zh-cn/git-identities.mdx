# Git 身份

git 身份是你的提交所带的姓名和邮箱，也是仓库登录远程仓库的方式。如果你在个人仓库和工作仓库之间往返，你可以保存多个身份并为每个仓库应用正确的那个。在 **Settings → Git** 中管理它们。

## 添加身份

1. 打开 **Settings → Git** 并选择 **New**。
2. 输入用于提交的 **用户名** 和 **邮箱地址**。
3. 选择 **认证方式**，也就是它如何推送和拉取：
   - **本机**：这台机器上的 Git 已经在用的方式，例如 SSH 密钥、凭证管理器或 `gh` CLI
   - **账户**：你选择的 **源代码管理账户**，可以是 [集成](/zh-cn/integrations/) 中任一托管服务卡片上连接的账号，例如 GitHub、GitLab、Gitea、Forgejo 或 Gerrit；推送通过 HTTPS 使用该账号的令牌
   - **SSH**：OpenChamber 为这个身份保存的密钥
   - **匿名**：不登录，通过 HTTPS 读取公开仓库，不能推送
4. 可选地给它一个颜色和图标，以便易于识别。

你系统的全局身份也会显示，为只读。

在 Gerrit 上，账户身份用你的 Gerrit 用户名和已连接的 HTTP 密码登录 Git。GitHub Enterprise 账号可用于 issue 和拉取请求，但在那里克隆和推送要通过 **本机** 或 **SSH**。

## 为仓库应用身份

选择 [Git 面板](/zh-cn/git/) 顶部的身份按钮并选一个。添加和克隆界面也提供同样的选择。无法访问该仓库的身份会留在列表中，处于停用状态并附上原因：其他托管服务上的账户、SSH 远程上的账户或 **匿名**，或者 HTTPS 远程上的 SSH 密钥。

应用身份会将它写入该仓库的 **local** git 配置，所以只影响该仓库，你的全局设置保持不变。终端里的 Git 和智能体的 shell 也会使用它。**系统身份** 会移除 OpenChamber 写入的内容，让你自己的 Git 配置重新生效。

## SSH 密钥密码短语

对于加密的 SSH 密钥，请在查找 `~/.ssh` 前输入可选的密码短语，然后确认指纹并添加密钥。OpenChamber 会保持密钥的加密状态，并将密码短语保存到 OpenCode 的凭据存储中。已保存的密码短语仅用于应用内的 Git 操作。终端或代理执行的 Git 命令不会读取它，因此加密的托管密钥无法通过该路径进行身份验证。
