# 聊天输入

聊天输入框认识几个符号。输入其中一个就会打开选择器；选择一个条目，或继续输入来筛选。符号只在词首生效，而命令必须位于消息开头。

| 输入 | 选择 | 生效位置 |
| --- | --- | --- |
| `/` | 命令 | 消息的最开头 |
| `$` | 技能 | 任意位置 |
| `#` | 代码片段 | 任意位置 |
| `@` | 文件或智能体 | 任意位置 |

不指向你已有条目的符号会保持为普通文本：`$5` 只是金额，`a/b` 只是路径。

## 命令

命令是你用斜杠运行的已保存提示词，比如 `/review`。在 **Settings → Commands** 中管理它们。

1. 打开 **Settings → Commands** 并创建一个命令。
2. 给它一个名称、一段描述，以及它应发送的提示词文本。
3. 可选地将它固定到特定的智能体或模型。
4. 选择个人或项目范围。

在聊天中，将 `/` 作为消息的**第一个**字符即可调出命令，然后选择一个。你的文本可以使用占位符：

- `$ARGUMENTS`: 你在命令后输入的任何内容
- `@filename`: 插入某个文件的内容
- `` !`command` ``: 插入某个 shell 命令的输出

内置的 `init` 和 `review` 命令可以重置，但不能删除。OpenChamber 还内置了 `/explore`、`/summary` 等命令；完整列表见 [Magic Prompts](/zh-cn/magic-prompts/)。

## 技能

在消息的任意位置输入 `$` 即可打开技能选择器，然后选择一个。智能体会为该回复加载该技能的指令。要自己编写技能，见 [技能](/zh-cn/skills/)。

命令和技能有各自独立的选择器，所以开头的 `/` 不会列出技能，`$` 也不会列出命令。

## 代码片段

代码片段是你用井号在行内引用的可复用文本，比如 `#signoff`。在 **Settings → Snippets** 中管理它们。

1. 打开 **Settings → Snippets** 并创建一个代码片段。
2. 给它一个名称以及它所代表的文本。如果你想要多个触发词，可以添加别名。
3. 选择个人或项目范围。

在聊天中，输入 `#` 并选择一个代码片段。OpenChamber 会在发送前替换为完整文本。

## 文件和智能体

输入 `@` 可以附加文件，或用其他智能体运行这条消息。

- 文件，例如 `@src/index.ts`，会像从 **+** 菜单中选择一样附加到消息。图片和文档会被读取并随之发送。
- 智能体，例如 `@build`，会用该智能体运行这条消息。没有提及智能体时，由 composer 中选中的那个运行。

## 添加文件和上下文

聊天框旁的 **+** 菜单不仅能附加文件：

- 你电脑上的文件
- 你仓库中的 issue 和 pull request（GitHub、GitLab、Gitea 或 Gerrit，取决于项目托管在哪里）
- 连接 Linear 后的 Linear issue
- 已安装[扩展](/zh-cn/extensions/)提供附加的任务

每一项都会作为上下文随你的下一条消息一起发出；你的消息决定如何使用它。你也可以粘贴图片，或把文件直接拖到聊天框上。

## 运行 shell 命令

以 `!` 开头，OpenChamber 会把它当作 shell 命令运行，不会发送给智能体。按 **Esc**，或一直删除到空输入框，即可退出 shell 模式。

## 键盘

- **Enter** 发送，**Shift+Enter** 换行。在 **Settings → Chat** 中可以互换，让 Enter 换行、**Ctrl/Cmd+Enter** 发送。Ctrl/Cmd+Enter 始终发送。
- **ArrowUp** 和 **ArrowDown** 可以调出你之前的消息。
- 选择器打开时，**Ctrl+N** 和 **Ctrl+P** 在其中移动，**Enter** 或 **Tab** 选中，**Esc** 关闭。

在展开的 composer 中，Enter 始终换行，**Ctrl/Cmd+Enter** 发送。

在手机上，Enter 始终换行。点击发送按钮或按 **Ctrl/Cmd+Enter** 发送。
