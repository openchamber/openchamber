# 侧边栏

侧边栏从上到下依次显示 **聊天**、你置顶过内容时出现的 **已置顶**、**进行中**，然后是你的项目。要在一个按时间排列的列表中查看所有内容，在侧边栏显示菜单的 **会话** 下选择 **按时间**。选择 **按项目** 会恢复按项目显示。

## 一行就是一项工作

- **项目文件夹中的会话** 占一行。由它衍生出的内容，例如子智能体、自动审查和旁支提问，收在左侧的箭头下面。普通的分叉单独占一行。
- **worktree** 在所属项目下占一行，它的所有会话都在它下面。点击该行会打开你最后在那里工作的会话，点击箭头可以看到全部会话。参见 [Worktree 会话](/zh-cn/worktrees/)。
- **隔离空间** 的工作方式与 worktree 相同。

## 一行显示什么

行的左侧显示它是什么：

- 分支图标：worktree
- 空间图标：隔离空间
- 没有图标或显示箭头：项目文件夹中的会话

行的右侧显示当前状态：正在运行、有新回复或在等你。末尾的彩色标记是这项工作跟踪的拉取请求或 issue。

## Worktree 名称

worktree 行显示任务名称，任务明确后由智能体命名。在此之前显示分支。你自己重命名后，你起的名字会保留。移入新 worktree 的会话会带上它的任务名称。

如果想按分支查看 worktree，在显示菜单中打开 **按分支命名 worktree**。分支会成为行的名称，任务名称在详细行中移到它下面。

## 进行中和已置顶

**进行中** 收纳你还没做完的工作；参见 [进行中的会话](/zh-cn/sessions-in-work/)。进入这里的工作会离开所属项目，如果想在两处都显示，打开 **在项目下也显示进行中的工作**。**已置顶** 收纳你从行菜单中置顶的会话和 worktree。

## 显示菜单

- **会话**：按项目或按时间
- **排序项目**：手动、A → Z、Z → A 或最新
- **显示聊天分区**、**显示已置顶部分**、**显示进行中部分**
- **在项目下也显示进行中的工作**
- **详细行**：第二行显示分支或任务名称、拉取请求或 issue，列表混合多个项目时还显示项目
- **按分支命名 worktree**
- **全部折叠** 和 **全部展开**

长列表末尾有 **显示更多**。**收起** 会把它折回去。

## 在手机上

列表和菜单都一样。除非关闭 **详细行**，每行都显示为两行；把行向一侧滑动即可看到它的操作。

VS Code 保留这套布局之前的列表。
