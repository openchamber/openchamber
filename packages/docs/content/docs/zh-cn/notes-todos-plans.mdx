# 项目笔记、待办与计划

每个项目都有自己的草稿空间，用于存放笔记、待办列表和已保存的计划。它们属于项目，而不属于任何单个会话，因此当你在会话之间切换时它们会一直保留。在右侧边栏的 **Context** 标签页中可以找到它们（在移动端是一个专用标签页）。

## 笔记

一个自由格式的笔记框，用于记录任何你想记住的关于项目的内容。它会在你输入时自动保存。

## 待办

一个简单的清单。添加条目、勾选完成、通过拖动重新排序，并清除已完成的条目。

每个待办都有一个 **send** 菜单，让你可以把它交给智能体：

- 发送到当前会话
- 用它开启一个新会话
- 用它开启一个新的 [worktree 会话](/zh-cn/worktrees/)（仅当项目是 git 仓库时）

## 计划

一个用于将较长的计划保存为文件的地方。你可以：

- 从 Markdown 或文本文件导入计划
- 打开一个计划在侧面板中阅读
- 删除你不再需要的计划

完成后你应该会回到 Context 标签页，并看到笔记已保存、待办已勾选或计划已列出 — 这就是它生效的标志。

智能体可以把笔记或待办关联到计划，并让一个待办依赖同一计划中的其他待办；没有计划的待办不能有依赖。它可以查询就绪的待办，即尚未完成且所有依赖都已完成的待办。删除待办时，它会从依赖它的待办中移除；删除计划时，会解除其笔记和待办的关联。智能体还可以设置或清除与计划关联的会话。

## 把笔记和待办放进仓库

笔记和待办保存在这台机器上 OpenChamber 自己的数据里。要通过 Git 同步它们，打开 **Settings → Projects**，选择项目，在 General 标签页打开 **将笔记和待办事项保存在仓库中**。之后它们会保存在 `.openchamber/notes-todos.json` 中，像其他文件一样提交即可。这个选项只对这台机器生效，所以每台要使用该文件的机器都要打开它。

切换不会复制任何内容。关闭选项后，之前的笔记和待办会回来，文件仍留在仓库中。计划不在这个文件里；要共享计划，请把它移到仓库的计划文件夹。如果文件有 Git 冲突，在你修好文件之前，面板无法加载或保存笔记和待办。
