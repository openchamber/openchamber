# 提供商、模型与智能体

在 OpenChamber 能做任何事之前，它至少需要连接一个 AI 提供商。本页介绍如何连接提供商、选择模型以及定制智能体。

## 连接提供商

1. 打开 **Settings → Providers**。
2. 打开 **Add provider** 菜单，选择一个尚未连接的提供商。
3. 根据提供商的不同，通过以下两种方式之一登录：
   - **API 密钥** — 粘贴你的密钥并保存。
   - **登录（设备流程）** — OpenChamber 会显示一个链接和一个短码。打开链接，输入短码并批准。OpenChamber 会自行完成连接。

当提供商显示为已连接时，它的模型就会在聊天中可用。

要断开连接，请打开该提供商并选择移除其登录。

## 选择模型

你在工作的地方选择模型：

- 在聊天中，使用消息栏中的模型选择器为该会话设置提供商和模型
- 按智能体设置默认模型（见下文）

## 设置智能体

智能体是一个命名的配置 — 包括一个模型、一种个性，以及它被允许做的事。

1. 打开 **Settings → Agents**。
2. 选择一个智能体，或创建一个新的。
3. 编辑以下任意项：
   - **description** — 该智能体的用途
   - **model** — 它的默认模型
   - **temperature** — 它的回答有多有创造性
   - **prompt** — 它始终遵循的固定指令
   - **tool rules** — 它可以使用哪些工具

## 将工作委派给 Antigravity

Antigravity CLI（`agy`）可以使用你的 Google AI Plus、Pro 或 Ultra 订阅为代理执行范围明确的任务。它是被委派的执行者，不是聊天提供商，因此其模型不会出现在模型选择器中。

1. 在运行 OpenCode 的机器上安装 Antigravity CLI，并运行一次 `agy` 以登录。
2. 打开 **设置 → 提供商 → Antigravity CLI**。页面显示已安装的版本以及你的账户可用的模型。
3. 选择默认模型并启用委派。

代理会获得 `agy` 工具，你也可以在聊天中输入 `/agy` 来交付任务。Antigravity 在会话目录中使用自己的工具和权限工作；委派的代理会检查结果。无界面运行无法显示批准提示，因此需要批准的工具会被拒绝，结果会说明是哪一个。"不经询问运行命令"默认关闭。启用后，沙箱内的命令将自动运行。如果沙箱不可用，需要批准的命令将被拒绝。CLI 的允许和拒绝规则仍然适用。

委派需要由 OpenChamber 启动 OpenCode。当 OpenChamber 连接到外部 OpenCode 服务器时，页面会禁用开关。VS Code 没有 OpenChamber 服务器，因此也没有 Antigravity 设置。

## 你的登录信息存储在哪里

提供商登录信息由 OpenCode 存储，而非 OpenChamber，因此它们与 OpenCode CLI 共享。如果你在多个地方设置了同一个提供商，最具体的设置会生效：按项目的设置会覆盖你的个人设置。
