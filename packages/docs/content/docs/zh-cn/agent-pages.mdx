# 智能体页面

智能体可以直接在聊天中绘制页面：图表、表格、示意图、界面原型或简短的表单。它可以请你在页面上选择一个选项；当答案需要来自其他人时，它还能通过链接和 PIN 把同一个页面发给同事。

## 请求页面

用平常的话告诉智能体即可。例如：

- “把三个布局方案做成原型给我看，让我选一个。”
- “把测试结果做成图表。”
- “问我这几个迁移先运行哪一个。”

页面会显示在聊天中的一个框架里，这个框架无法访问你的文件。**全屏打开** 可以放大查看，**下载为 HTML** 可以保存一份副本。

## 在页面上作答

当智能体在页面上向你提问时，聊天中会显示 **正在等待你在页面上作答**。选择一个选项或填写字段，然后按页面上的发送按钮。智能体会收到你的回答，页面会显示你的选择。

- **拒绝** 会告诉智能体你不打算选择。它不会替你选。
- 你也可以用文字回答：在聊天中输入，智能体会读取你的消息。

### 稍后作答

智能体不一定要等你。它可以展示页面后继续工作。页面会一直保持打开，直到你作答，即使智能体的这一轮结束或应用重启也不会消失。你的回答会作为单独的一行出现在会话中，如果智能体处于空闲状态，还会让它重新开始工作。

## 与同事共享页面

当答案需要来自其他人，比如同事或经理时，请智能体把页面发给他们：

- “问问 Yulia 和 Denis 更喜欢这两个设计中的哪一个。”

1. 智能体为每个人生成一个链接。它的消息下方会出现一张卡片，列出每个名字，并附有 **复制链接** 和 **复制 PIN**。
2. 你自己通过任意聊天工具把链接和 PIN 发给每个人。
3. 对方在浏览器中打开链接，输入 PIN，然后在页面上作答。他们不需要 OpenChamber。
4. 他们的回答会回到发起提问的会话，并向你发送通知。智能体读取回答后继续工作。

智能体也可以共享只供阅读的页面，例如带表格和图表的报告。这种页面没有表单，也不会有回答返回。

卡片会显示每个人何时打开了页面、何时作答。卡片中的 **打开** 会按对方看到的样子显示页面，你自己查看不会算作对方已打开。

### 共享链接如何运作

- 无需开启任何设置：在你把链接发给某人之前，页面不会到达任何人。
- 每个人只能回答一次，回答即为最终结果。
- 链接最多有效两个工作日，周六和周日不计入。如果需要更短的时间，请告诉智能体。
- 在卡片上某个人的菜单中选择 **取消链接**，即可撤回此人的链接。
- PIN 输错次数过多会锁定链接。
- OpenChamber 不会核实回答者是谁：任何拥有链接和 PIN 的人都能回答。卡片上的名字是你告诉智能体的那个名字。
- 页面和回答都以加密形式传输。共享服务只保存加密副本，并在回答送达你之后将其删除。没有 PIN 的链接打不开任何内容。
- 页面通过 OpenChamber 的共享服务传输；如果你在 [私密中继](/zh-cn/private-relay/) 中设置了自己的中继，则通过你的中继传输。

## 打开别人共享给你的页面

有了 OpenChamber，你可以在应用中打开共享页面，让你自己的智能体阅读它并帮你做决定：

1. 把链接粘贴到聊天输入框中。它会变成一个带 PIN 输入框的标签。
2. 输入 PIN，写下你的问题并发送。智能体会随你的消息一起收到页面内容，并标记为他人的内容。
3. 在你的消息下方，**打开** 会在侧边面板中显示页面，在手机上则全屏显示。用页面自己的发送按钮作答。

智能体可以建议一个回答，但只有你能发送。链接和 PIN 永远不会到达模型。

侧边面板中的 **共享页面** 按从新到旧列出你收到的所有页面及其状态。在手机上，它是工作区抽屉中的一个标签页。在打开的页面上点 **添加到聊天**，即可把它附加到你正在写的消息中。

## 开启或关闭

智能体页面默认开启。要关闭它，打开 **设置 → 通用 → OpenChamber 工具**，关闭 **图表和原型**。

## 注意事项

- 与 [智能体控制工具](/zh-cn/agent-control-tool/) 一样，智能体页面需要 OpenChamber 自己的 OpenCode 服务器。
- 在 VS Code 扩展中，共享链接保持为纯文本，智能体请你稍后作答的页面会显示为不带作答控件的样子。请在桌面版或网页版中作答。
- 在企业模式下，共享只能通过你所在组织自己的中继进行。没有中继时，智能体根本不会获得共享功能。请参阅 [安全](/zh-cn/security/)。
