# 聊天

聊天是与智能体的普通对话，不属于任何项目。它适合那些和你的代码库无关的事情：怎么给 FreeBSD 上的 KDE 打补丁、某个正则表达式是什么意思、一封邮件的草稿。智能体在一个临时文件夹里工作，没有仓库，没有分支，你的项目上下文也不会拖累这段对话。

## 开始聊天

最直接的方式是点侧边栏 **聊天** 分区上的 **+**。在手机上，点会话列表顶部的 **新会话**，或聊天分区的 **+**。

**Mod+N**（macOS 上是 Cmd+N，其他系统是 Ctrl+N）和命令面板中的 **新建会话** 会在你上次使用的那一侧打开新会话：如果你上一次新建的是聊天，就打开聊天，否则打开你的项目。在发送第一条消息之前，你可以把它切换到聊天。

## 聊天在哪里

聊天在侧边栏顶部有自己的分区，位于[进行中](/zh-cn/sessions-in-work/)和你的项目之上。它们和其他会话一样按最近活动排序，置顶的聊天保持在最上面。在 Timeline 模式下，分区显示最近的三个聊天，**显示更多会话** 可以加载其余的。这个分区和其他分区一样可以折叠。

在手机上，聊天位于会话面板中项目列表的上方。

## 聊天能做什么，不能做什么

每个聊天都有自己的空文件夹，所以智能体仍然可以在里面创建和编辑文件：一个脚本、一个快速原型、一份转换好的文档。聊天没有的：

- git 状态、分支或 worktree
- 移入进行中：聊天永远不会出现在[进行中](/zh-cn/sessions-in-work/)
- 在新会话中实施计划
- 从 Linear issue 开始

笔记、待办和计划都能用。所有聊天共用一套，与你的项目分开。

聊天始终是聊天。没有办法把已经结束的聊天移到项目里；如果一段对话变成了真正的工作，就在项目里开一个会话，把有用的内容带过去。

## 归档和删除

归档聊天可以把它从列表中隐藏。删除聊天会把它彻底移除；当没有其他会话（分叉或子智能体）再使用它的文件夹时，文件夹也会一起删除。

## 文件夹在哪里

聊天文件夹位于 `~/.config/openchamber/chats`，每天一个带日期的文件夹。如果你用 `OPENCHAMBER_DATA_DIR` 移动过 OpenChamber 的数据，它们就在那个文件夹下。要把聊天放到别处，请设置 `OPENCHAMBER_CHATS_DIR`；参见[环境变量](/zh-cn/environment/)。当 OpenCode 以其他用户身份运行、无法读取你的主目录时，这一点很重要。

> VS Code 中没有聊天。扩展始终在你打开的文件夹中工作。
