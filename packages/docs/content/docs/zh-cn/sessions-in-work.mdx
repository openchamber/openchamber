# 进行中的会话

你发过消息的每个会话都会把它所属的工作放进侧边栏顶部的 **进行中** 区块，工作会一直留在那里，直到你把它标记为完成，不管你上次打开它是多久以前。项目里保存着你做过的一切；进行中只收纳你还没做完的事。

## 什么是工作

侧边栏列出的是工作，而不是单个会话。一项工作是以下两者之一：

- **一个 worktree** 及其中的所有会话，显示为一行，标题是任务名称（参见 [Worktree 会话](/zh-cn/worktrees/)），或
- **项目自身文件夹中的一个会话**，由它衍生出的内容嵌套在下面：它的子智能体、它的审查、你保留的分叉和旁支提问，以及它的智能体为你启动的会话。

点击该行即可打开；点击左侧的箭头可展开其下的会话。

## 在哪里

**进行中** 区块位于侧边栏中，在聊天下方、你的项目或时间线上方。进入这里的工作会离开所属项目，所以每项工作只显示一次。如果也想让它留在所属项目下，在侧边栏的显示菜单中打开 **在项目下也显示进行中的工作**。搜索只列出它一次，在进行中区块里。

每项工作只占一行：标题及其状态；有拉取请求或 issue 时还会显示一个彩色标记。各行按最近的活动排序，所以不显示日期。把鼠标悬停在行上可以看到项目、分支、时间和链接，也可以在显示菜单中打开 **详细行**，让它们显示在标题下方。详细行在你的项目下同样生效；工作内部的会话仍然只占一行。

置顶的会话会放在进行中上方单独的 **已置顶** 区块里；如果只想让它们留在各自的项目下，在同一个菜单中关闭 **显示已置顶部分**。置顶且进行中的会话只会列在已置顶中。

手机上的会话列表也一样，显示菜单也相同。除非关闭 **详细行**，每行都显示为两行；由于无法悬停，展开工作的箭头会一直显示。

## 会话如何进入

在会话中发送一条消息，它就会进入进行中。任何项目会话都是如此，包括 worktree 里的会话。新建的 worktree 一创建就会进入进行中，此时其中打开的草稿还没有发送。

你标记为完成的会话，在你再发送一条新消息时会回来。

聊天、已归档的会话、审查会话以及[定时任务](/zh-cn/scheduled-tasks/)的运行永远不会进入；如果你分叉某次运行来继续处理，分叉出的会话会进入。子智能体永远不会把它的父会话放入进行中。

## 任务名称

任务一明确，智能体就会用几个词按任务给每项工作命名，比如"修复登录超时"。worktree 把名称保存在分支描述中，所以无论在哪里打开这个仓库都能看到；项目文件夹中的会话则把名称用作标题。你自己重命名后，你的名称会保留：智能体永远不会重命名你命名过的任务。

## 手动跟踪和完成会话

- **跟踪：** 把鼠标悬停在行上，点眼睛图标，或在会话菜单中选择 **作为进行中跟踪**。
- **完成：** 把鼠标悬停在区块里的行上，点对勾，或在菜单中选择 **标记为完成**。完成会结束整项工作：其中所有仍在进行中的会话。

对 worktree 标记完成时，它会离开进行中，并留在原处。如果也想在标记完成时归档它，请在 **设置 → 会话** 中开启 **将工作树标记为完成时归档**：文件夹会被移除，它的会话、更改和分支会留在归档页面中，随时可以还原。如果其中还有会话在运行，worktree 会保留。

在手机上，把行向一侧滑动就能找到同样的操作。

聊天没有眼睛图标：它们只是普通对话。

### "这项工作看起来已完成。"

设置好[分类提供方](/zh-cn/classification-providers/)后，Jev 会检查进行中会话的每一轮。当某一轮看起来像是工作的收尾（你道了谢、让它提交、确认一切正常），Jev 不会关闭任何东西，而是留下提示：

- 侧边栏的会话行上出现一个灰色对勾
- 输入框上方出现一条横栏：**这项工作看起来已完成。** 以及 **标记为完成** 按钮

如果 Jev 判断得对，就点 **标记为完成**。如果不对，继续工作就好：你发出下一条消息时提示就会消失。没有分类提供方时不会出现提示，由你自己把会话标记为完成。

## 摘要和下一条消息建议

智能体完成工作、会话安静一分钟后，OpenChamber 可以用你的小模型写两样东西（参见[提供商、模型与智能体](/zh-cn/providers/)）：

- **摘要：** 简短提醒做了什么、目前进展到哪一步，显示在最后一条回复下方，以及侧边栏中该会话的悬停提示里
- **建议：** 你接下来很可能发送的消息，以一行的形式出现在输入框顶部；点击会把文字放进输入框，它永远不会自己发送

有 Jev 时，OpenChamber 会先问它这一轮是否需要这两样东西。真正的工作之后，一句简单的"谢谢，就这样"仍然会得到摘要；但没什么可做时会跳过建议，两者都没用时根本不会调用小模型。没有 Jev 时，两者照旧在每一轮之后生成。

在 **设置 → 聊天 → 会话辅助** 中开启或关闭它们。

## 设置

打开 **设置 → 会话 → 进行中的会话**。这里只有一项设置 **显示进行中的会话**，默认开启。关闭后整个功能都会关闭：没有区块，发送消息也不再把会话放入进行中。

如果只想隐藏区块，请使用侧边栏显示菜单中的 **显示进行中部分**。

## 在哪里可用

区块以及手动跟踪和完成在任何地方都能用，包括 VS Code。发送消息时自动放入进行中、"看起来已完成"的提示和摘要的 Jev 过滤需要 OpenChamber 服务器，因此在桌面应用、网页应用和手机上可用，在 VS Code 中不可用。在 VS Code 中，会话只能手动跟踪。
