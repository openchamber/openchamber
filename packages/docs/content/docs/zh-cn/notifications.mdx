# 通知

通知会在有事情需要你关注时告诉你，这样你就不必盯着屏幕 — 会话完成了、遇到错误、提出了问题，或需要权限来做某件事。在 **Settings → OpenChamber → Notifications** 中设置它们。

## 开启它们

1. 打开 **Settings → OpenChamber → Notifications**。
2. 当你的浏览器或系统询问时，允许通知。
3. 选择你想被告知哪些事项：
   - 会话**完成**
   - 会话遇到**错误**
   - 会话**提出问题**
   - 会话需要**权限**
   - **子任务**完成

## 它们如何送达你

- 在**桌面端**，你会收到原生系统通知
- 在**浏览器或已安装的应用**中，你会收到网页推送通知，因此即使标签页在后台它们也能送达

设置为自动接受的会话不会用权限通知来打扰你。

## 声音

通知还可以发出提示音，让你在不盯着窗口的情况下也知道有会话需要你。在 **设置 → OpenChamber → 通知 → 通知声音** 中开启，并为每种事件选择声音——会话完成、需要输入、请求授权或错误。

默认只有在 OpenChamber 处于后台时才播放声音，因为正在看的窗口你本来就能看到。如果工作时也想要提示音，把 **播放时机** 设为 **始终**。

在桌面端，该提示音会取代操作系统的通知铃声，因此一个事件只发出一个声音。关闭通知声音后，桌面通知会静音送达。

内置音效来自 [OpenCode](https://github.com/sst/opencode) 的 attention 音效包。

## 自定义措辞

每种通知都有一个标题和消息模板，你可以编辑它们，使用诸如智能体名称和模型之类的字段。还有一个对最后一条消息包含多少内容的限制，以使通知保持简短。
