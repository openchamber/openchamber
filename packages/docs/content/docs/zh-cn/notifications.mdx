# 通知

通知会在有事情需要你关注时告诉你，这样你就不必盯着屏幕 — 会话完成了、遇到错误、提出了问题，或需要权限来做某件事。在 **Settings → OpenChamber → Notifications** 中设置它们。

## 开启它们

1. 打开 **Settings → OpenChamber → Notifications**。
2. 当你的浏览器或系统询问时，允许通知。
3. 选择你想被告知哪些事项：
   - 会话**完成**
   - 会话遇到**错误**
   - 会话**提出问题**
   - 会话需要**权限**
   - **子任务**完成

## 它们如何送达你

- 在**桌面端**，你会收到原生系统通知
- 在**浏览器或已安装的应用**中，你会收到网页推送通知，因此即使标签页在后台它们也能送达

设置为自动接受的会话不会用权限通知来打扰你。

应用内记录里可以在条目进入列表时开声音，窗口在后台时也会响。

## 自定义措辞

每种通知都有一个标题和消息模板，你可以编辑它们，使用诸如智能体名称和模型之类的字段。还有一个对最后一条消息包含多少内容的限制，以使通知保持简短。

## 应用内记录

标题栏的铃铛会在本机保留提示和会话事件的列表。如果提示在你点开前消失，它在通知中心仍是未读。打开一行，或点确定/复制，会标为已读。条目会一直留到你删掉或过期。「全部标为已读」也会关掉还在屏幕上的提示。

点击系统或推送通知时，如果带有会话 id，会打开对应会话。

Settings → OpenChamber → Notifications 里有「应用内记录」。默认是开的。关掉整个列表会隐藏铃铛。取消某一类，就会从列表和角标里隐藏。条目仍会保存，再打开就会回来。信息、成功和子任务默认关闭，避免角标被占满。子任务的系统横幅仍在「事件」里单独开关。事件和模板仍跟投递在一起。
